## 2. 冻结生成定义（草案；冻结身份后不调参数）

对数亮度 `L(u,t)=a*sigmoid((r_px-d(u,theta(t)))/sigma)`，a=1.4、sigma=0.6px，背景常数取0。`theta(t)=0.35+b+omega*(t−T)`，T=0.05s，真实当前偏置b=0.12rad；仅三种冻结速度omega∈{0.15,1.0,3.0}rad/s。状态偏置b与速度分开，目标不是把时间当深度。

理想像素记忆初始reference=`L(u,0)−phase_u`，phase_u=C/4、C=0.2；亮度触到reference±C发(x,y,t,p)，reference累加pC。无refractory、噪声、漏报或光照变化。不用均匀dt找触阈。对每像素v、rho=||v||、alpha=atan2(v)，按theta−alpha=kπ、π/2+kπ，以及rho≥length时±acos(length/rho)+2kπ解析分段。这覆盖线段投影h=0/length的分支、距离驻点及cusp；每段亮度单调或恒定，保留前段reference，逐一穷尽reference±C所有crossing并二分到机器精度。每段端点和四分点单调检查只能核实现，完备性来自上述解析分段而非采样；若不一致即停。所有输出t∈(0,T)，T端点排除；单调区间触阈穷尽同时检查没有漏报的区间内阈值违例。零速度另作空观测正控制。

## 3. 从真实生成事件构造观测方程

每像素事件按时序编号，`s_i=sum_{k<=i}p_k`。观测等式为

`r_i(b,omega,a,C,phase)=L(u_i,t_i)−L(u_i,0)+phase_{u_i}−C*s_i`。

事件像素与timestamp来自生成器，不能替成候选link投影、不能在零运动时snap到预测表面。几何只参与亮度预测；没有路由构造能自行提高对齐。依靠候选自己设定的J或confidence不算独立真值。

在固定观察行上计算解析线段距离与亮度导数，并用两个步长的中心差分交叉核验，明确这是**观测等式的条件局部Jacobian，非完整事件似然/Fisher**。忽略非触发区间和可见性切换会损失约束；局部非零敏感度不证明全局唯一，局部零也不推出整个传感器没有信息。

按嵌套nuisance模型分别记录b方向在其他列span外的分量：

1. 速度未知，a/C/phase已知；
2. 速度、全局contrast a和全局threshold C未知，phase已知且固定数值0.05，不随候选C变化；
3. 再放开每个有事件像素的独立phase；先按pixel中心化，再对其余nuisance列投影；
4. 速度、contrast、每像素phase和每像素threshold均未知；对每像素的常数列与累计极性列先剔除，再处理其余列。

报告全部事件与每像素首次事件子集，保留全部零支持/退化行，不选有利速度或像素。首次事件且每像素phase自由时，所有事件等式可被对应phase的一阶变化吸收，这是应出现的代数边界；它没有包括no-event删失不等式，不得夸大为全传感不可辨识。

## 4. 必需合同与固定停止规则

- 生成真值代回全部事件的max|r|≤1e−12，times严格递增到像素顺序约定且满足t<T；极性为±1。
- 零运动且phase严格处于阈内，应无事件；不将此单例升级为“空事件必静止”。
- 中心差分步长h=1e−5与h/2，参数按rad、rad/s、无量纲a/C；解析J与h/2差分、h与h/2差分、degree使用同物理步长后的差分，各max绝对差≤1e−4。另解析检测t_i或0时刻在线段内部cross≈0或tip距离≈0（固定1e−10px）的cusp，发现即停，不以中心差分相等掩盖不可微、不删行继续。
- SVD前统一物理列尺度：b=0.01rad、omega=0.1rad/s、a=0.1、C/phase=0.02；不做逐列norm归一化、不将微小gauge余项放大。合法单位换算rad↔degree以链式法则还原同一物理列，差分使用同物理步长；同一物理0.01rad方向的投影残差norm相对差≤1e−8（零分母用绝对1e−10）；共同重排行与pixel身份的norm也应满足此门。
- phase自由的首次事件子集，投影后b方向norm≤1e−10；复制完全相同观察行不应改变数学秩，norm随重复加权的增长不命名独立信息增加。数值秩阈值为max(1e−11,1e−9*s_max)，不得依据输出更换阈值。nuisance与joint矩阵各自记录实际s_max及门；不同相对截断下两数值秩之差不解释为严格新信息秩。复制行若恰跨绝对floor而失败，只能记数值合同不稳定并停，不否定物理复制不变性。
