## 1. 各方向的机制提炼

### 1.1 事件流 GNN 主线（本仓库 S36 的谱系）

| 工作 | 处理方式 | 对本仓库的含义 |
|---|---|---|
| AEGNN (CVPR'22, uzh-rpg) | 事件=节点，时空半径图，SplineConv 把**相对位置**写进滤波器；异步=只重算新事件触及的 K-hop 子图 | S36 的直接参照。`dp=(dx,dy,dt)` 边特征是 SplineConv 的廉价等价物 |
| EvGNN (2024, 加速器) | 因果邻接 + 事件队列近邻搜索 + 层并行，16 µs/事件 | 证明**因果边**是异步部署的先决条件——S36 已按此构图 |
| DAGr (Nature 2024, "Low-latency automotive vision") | 帧 CNN 提稠密上下文 + 异步 GNN 处理事件；**CNN 特征按事件像素取样挂到节点上** | 与本仓库"渲染值挂到事件节点"同构。稠密先验作为**节点值**融合是发表过的正确形态；先验不改图结构 |
| EGSST / eGSMV (2025) | 多图/Transformer 增强时间依赖 | 池化读出是共同短板，注意力读出是共同演化方向 |

**第一性原理**：事件的价值在稀疏性与时间分辨率；GNN 的价值在保住这两者的同时提供空间聚合。
图结构必须由数据本身决定（(x,y,t) 近邻），外部先验只能以**值**的形式进入——这正是本仓库用 KEG
的 0.910 回路增益买来的教训（`docs/GNN_ARMS_ARCHIVE_20260828.md`），文献与之独立地收敛到同一设计。

### 1.2 事件相机手部 mesh / 位姿

| 工作 | 机制 | 对本仓库的含义 |
|---|---|---|
| EventHands (ICCV'21) | LNES + ResNet 回归 MANO 参数 | 本仓库 dense 线的起点 |
| EvHandPose (TPAMI'24) | 手部**流表示**解决运动歧义；Pose-to-IWE：把 MANO 手的**边缘**投到事件对齐（对比度最大化 + 手缘约束）做弱监督 | 模型-事件对应**不需要完整 mask+depth 渲染**在文献里有先例——但它出现在 loss 侧且只用边缘 |
| EvRGBHand (CVPR'24) | 事件+RGB 互补，跨时间/空间/信息维度融合 | 稠密模态提供事件缺的前景语义 |
| Ev2Hands (3DV'24) | 事件当**点云**（PointNet 系）+ 注意力，双手歧义用特征级注意力 | 事件=点/节点的处理与 S36 同路线 |
| EventEgoHands (2025) | 手部分割模块滤背景事件 | 背景事件是一等公民问题；本仓库用低事件率域随机化 + zero-event gate 处理 |

**第一性原理**：事件只报告边缘运动，手是低纹理物体 ⇒ 单包事件欠定，必须有状态先验（递推）或
时间聚合（流）补全。先验与事件的**对应机制**是这个方向的核心自由度：渲染比较（EventHands 系）、
边缘对齐（EvHandPose）、分割门控（EventEgoHands）都是它的实例。角度 1 问的正是"对应机制可否
不经光栅化"——文献没有直接答案，值得实测。

### 1.3 检测 / 双目 / 光流 / 深度（事件）

- **EMatch (ICCV'25) / EventMatch (2024)**：把光流与双目统一成**特征相似度匹配**问题，共享表示、
  分任务头。第一性原理：事件的时间维（流）与空间维（视差）是同一个对应问题的两个切面。
- **IED²S (ICCV'25)**：训练期用强度图向事件分支**蒸馏**稠密结构，推理期纯事件——稠密先验可以只
  活在训练里。对本仓库：渲染通道若在角度 1 被证伪，蒸馏是"保精度去渲染"的备选路径（推理去渲染、
  训练留渲染教师，本仓库已有 DISTILL_WEIGHT 基础设施）。
- **DAGr (Nature'24)**：检测侧同 1.1；帧给上下文、事件给低延迟更新，这与"渲染给上下文、事件给
  增量"的递推手部跟踪同构。

### 1.4 Scene Flow / Motion Segmentation / Ego-motion

- **对比度最大化（CMax）家族**（Shiba et al. TPAMI'24 统一光流/深度/自运动；变分迭代 CMax
  CVPRW'25 做运动分割；Out of the Room 3DV'24 泛化动态分割）。第一性原理：**把假设的运动模型
  作用在事件上，检查事件是否被"对齐锐化"**——模型-事件对应不需要渲染图像，只需要能把模型变换
  作用到事件坐标上。这是角度 1 的最强文献旁证：CMax 的 IWE 本质上就是"参数化模型 ↔ 原始事件"
  的直接对应。
- 运动分割的共识：先补偿主导运动（自运动），残差即独立运动——对应本仓库"prev 解释掉的事件 vs
  解释不掉的事件"的读法，`g_surf` 通道给的就是逐事件的"可被 prev 解释度"。

### 1.5 VO / SLAM / 3D Tracking

- **DEVO (3DV'24) → Stereo-DEVO / DEIO (2025)**：稀疏 **patch 跟踪** + 循环光流 + 可微 BA。
  第一性原理：不要处理所有事件，**选择性地跟踪模型锚定的稀疏局部区域**并在优化层融合。
  对本仓库：读出侧"每个关节只看自己邻域的事件"与 patch 思想同构（角度 2）。

### 1.6 点集上的读出（readout）设计 —— 角度 2 的直接文献

| 工作 | 机制 |
|---|---|
| DAPT (AAAI'25, LiDAR HPE) | 可学习**关节 anchor/query** 在多密度层级与点特征交换信息（MDE），1D heatmap 解码 |
| EgoPoseFormer (ECCV'24) | 两阶段：全局池化 MLP 出**粗位姿提案** → 逐关节 query token 用**投影后的关节位置**引导 deformable attention 在特征图上取局部证据，输出精修偏移 |
| GBT (2023) / HOI-LiDAR (2026) | 逐关节 query 交叉注意力读出成为点云位姿的标准解 |

**第一性原理**：全局池化把 O(N) 个节点压成 1 个向量，空间细节在读出处死亡；解法是让**每个输出
量拥有自己的查询**，只聚合与它相关的节点。EgoPoseFormer 的粗提案≈本仓库的 `prev`（递推先验），
其投影引导注意力≈"用 prev 的 FK 关节决定每个关节头读哪些事件"。**状态在读出侧进入是文献与
本仓库设计法则（州值/读出可用状态，结构不可用）的交点。**

## 2. 三个角度的判定

### 角度 1：MANO FK 与事件流直接对应，去掉 mask/depth 渲染（曾为 S37，实现已清除）

**判定：机制上可行。** 依据：CMax 家族证明模型-事件对应不需要图像化；DAGr
证明先验作为节点值融合正确；EvHandPose 证明手模型的**几何**（边缘）而非**图像**足以构成对应。

S37 的做法（代码已于 2026-09-06 清除，此处只留设计）：每个采样节点得到 4 个解析值，替代原
来光栅化后取样的 `sil`/`inv` 两通道：

| 通道 | 定义 | 对应的渲染面 |
|---|---|---|
| `g_surf` | exp(−d/8px)，d=到 778 个投影顶点的最近距离 | `sil`（软化 + 带梯度方向） |
| `invz·g_surf` | 最近 8 个顶点的 min-z 归一化逆深度 × g_surf | `inv`（min-z 代替 z-buffer 前表面） |
| `g_skel` | exp(−d/16px)，d=到 21 个投影关节的最近距离 | 渲染从未提供的骨架内部结构 |
| `invz·g_skel` | 该关节逆深度 × g_skel | 同上 |

工程要点：特征只在编码器将要 gather 的 ≤`ENCODER_MAX_NODES` 个节点上计算（子采样确定性，
两处调用同行），否则训练批的 (N×778) 距离阵在千万级事件下不可行；采样索引两两互异 ⇒ scatter
确定性。`no_grad`，状态只做条件化。

**已知的不可越线**：`sil` 的二值性是"事件是否被 prev 解释"的最锐读数；解析软化换来梯度方向，
代价是锐度。两者谁赢由选点协议裁决，不由直觉裁决。

历史：S37 在 5 受试者线上训过一次（2026-08-30；精度门槛过、延迟门槛否），只凭精度采纳后于 09-04
以三条理由撤回（GT prev 几何捷径、延迟未降、方法定位）；2026-09-06 在 zgz 协议下重跑过一次，
同日按用户指令作废并连同代码清除，不保留数字（`docs/FAILURE_AND_CLEANUP_LEDGER.md`）。

### 角度 2：池化+解码头改为 LBS 引导（未实测候选）

**判定：机制上最对症，风险最清楚。** S36 的瓶颈已被测量定位在读出：`probe_s36_nodes` 把节点数
从 512 提到 4096，递推 RA 只动 0.09 mm——信息死在 mean+max 池化，不死在采样。文献（1.6 节）的
标准解正是逐关节 query 读出，且 EgoPoseFormer 的"投影引导"与本仓库"状态可以在读出侧进入"的
设计法则重合。

必须绕开的本仓库前科：
1. **KSGN（§9，hand_data51 线）**：LBS 语义关节头作为**加性旁路**被判惰性——梯度走直连路，旁路
  贡献 0.16 mm。⇒ 逐关节读出必须是该关节局部参数的**唯一通路**（S10 active head 已是此结构：
  `joint_heads[k]` 是 45D 局部位姿的唯一出口，改的只是它的**输入**从全局池化换成关节局部池化）。
2. **KEG（回路增益 0.910）**：状态引导的是**读出聚合权重**，不是消息传递结构——EdgeConv 的图
  仍由 (x,y,t) 决定。且必须保留一条全局池化通路给 root_head/兜底，关节局部读出零初始化门控，
  从"纯全局"连续形变到"全局+局部"，训练自己决定用多少。
3. **零事件合同**：空包必须逐位返回 prev ⇒ 局部池化的 mask 语义要和现在的 `any_node` 门一致。

这个角度在 S37 基座上做过的实验已于 2026-09-06 清除（代码、配置、产物、数字），不再引用；
若重开，须在 S36 基座上从零预注册。

### 角度 3：loss 换回 SO(3)+FK（未实测候选）

**判定：可测，但必须带上一轮的两个补救开关，且预期收益的机制不明。** hand_data51 线的完整测量
（§13–§14）：腕对齐 RA 打平（−0.78 ± 0.61，门槛 −1.1），**绝对平移 63.7 → 83.6 mm 退化**——
根因是 `L_trans` SmoothL1 在 β=1 m 下厘米级误差全落二次区（梯度∝误差，几乎为零）且 `L_FK`
根相对。补救开关已在 `model/model.py` 实现且默认关闭：`TRANS_BETA≈0.01`（恢复常梯度）、
`ABS_FK_WEIGHT>0`（非根相对 FK 项）。S36 的绝对 MPJPE 已经是 45.6 mm，不带补救直接换 loss
可预期重蹈覆辙。第一性原理上：loss 改的是目标流形上的度量，救不了读出处的信息瓶颈——若角度 2
成立，角度 3 应在新读出之上做单变量测试，顺序不可颠倒。

这个角度在 S37 基座上做过的实验已于 2026-09-06 清除，不再引用；`TRANS_BETA` / `ABS_FK_WEIGHT`
两个补救开关（S4 实现，`tests/test_s4_loss.py`）保留在 `so3_trans_fk` 路径上，默认关闭。

## 3. 实验纪律

协议不变量（2026-09-05 起）：默认九受试者划分 `splits_semkine.json`、验证/选点/上报只用留出受试者 zgz、
50 ms 步长、`select_checkpoint.py` 固定网格递推 RA 选点、两种子、`NCCL_P2P_DISABLE=1`、复现漂移 < 0.05 mm。
一次只动一个角度，门槛预注册。**预注册的每一条门槛都是门槛，不是读数**：2026-08-30 S37 只凭精度门槛
被采纳、已否证的延迟门槛被写成"另立轮次"，是随后五轮实验建在一个后来被撤回的基座上的直接原因
（`docs/FAILURE_AND_CLEANUP_LEDGER.md` §2 的 S37 行）。
