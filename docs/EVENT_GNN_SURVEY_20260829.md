# 事件流上的 GNN 与相邻方向遍历（2023–2026），及对本仓库三个优化角度的第一性原理判定

> 2026-08-29。为 S37+ 轮次做的方向遍历：先按方向提炼 2023–2026 一区/CCF-A 代表作的**机制**（不是结果表），
> 再把三个候选优化角度（FK 直连去渲染、LBS 引导读出、SO(3) loss）放到"文献机制 × 本仓库已付学费的坑"
> 两个坐标下判定。实验纪律：一次只动一个角度，两种子、固定网格、递推 RA 选点，门槛预注册。

## 1. 各方向的机制提炼

### 1.1 事件流 GNN 主线（本仓库 S36 的谱系）

| 工作 | 处理方式 | 对本仓库的含义 |
|---|---|---|
| AEGNN (CVPR'22, uzh-rpg) | 事件=节点，时空半径图，SplineConv 把**相对位置**写进滤波器；异步=只重算新事件触及的 K-hop 子图 | S36 的直接参照。`dp=(dx,dy,dt)` 边特征是 SplineConv 的廉价等价物 |
| EvGNN (2024, 加速器) | 因果邻接 + 事件队列近邻搜索 + 层并行，16 µs/事件 | 证明**因果边**是异步部署的先决条件——S36 已按此构图 |
| DAGr (Nature 2024, "Low-latency automotive vision") | 帧 CNN 提稠密上下文 + 异步 GNN 处理事件；**CNN 特征按事件像素取样挂到节点上** | 与本仓库"渲染值挂到事件节点"同构。稠密先验作为**节点值**融合是发表过的正确形态；先验不改图结构 |
| EGSST / eGSMV (2025) | 多图/Transformer 增强时间依赖 | 池化读出是共同短板，注意力读出是共同演化方向 |

**第一性原理**：事件的价值在稀疏性与时间分辨率；GNN 的价值在保住这两者的同时提供空间聚合。
图结构必须由数据本身决定（(x,y,t) 近邻），外部先验只能以**值**的形式进入——这正是本仓库用 KEG
的 0.910 回路增益买来的教训（`docs/GNN_ARMS_ARCHIVE_20260828.md`），文献与之独立地收敛到同一设计。

### 1.2 事件相机手部 mesh / 位姿

| 工作 | 机制 | 对本仓库的含义 |
|---|---|---|
| EventHands (ICCV'21) | LNES + ResNet 回归 MANO 参数 | 本仓库 dense 线的起点 |
| EvHandPose (TPAMI'24) | 手部**流表示**解决运动歧义；Pose-to-IWE：把 MANO 手的**边缘**投到事件对齐（对比度最大化 + 手缘约束）做弱监督 | 模型-事件对应**不需要完整 mask+depth 渲染**在文献里有先例——但它出现在 loss 侧且只用边缘 |
| EvRGBHand (CVPR'24) | 事件+RGB 互补，跨时间/空间/信息维度融合 | 稠密模态提供事件缺的前景语义 |
| Ev2Hands (3DV'24) | 事件当**点云**（PointNet 系）+ 注意力，双手歧义用特征级注意力 | 事件=点/节点的处理与 S36 同路线 |
| EventEgoHands (2025) | 手部分割模块滤背景事件 | 背景事件是一等公民问题；本仓库用低事件率域随机化 + zero-event gate 处理 |

**第一性原理**：事件只报告边缘运动，手是低纹理物体 ⇒ 单包事件欠定，必须有状态先验（递推）或
时间聚合（流）补全。先验与事件的**对应机制**是这个方向的核心自由度：渲染比较（EventHands 系）、
边缘对齐（EvHandPose）、分割门控（EventEgoHands）都是它的实例。角度 1 问的正是"对应机制可否
不经光栅化"——文献没有直接答案，值得实测。

### 1.3 检测 / 双目 / 光流 / 深度（事件）

- **EMatch (ICCV'25) / EventMatch (2024)**：把光流与双目统一成**特征相似度匹配**问题，共享表示、
  分任务头。第一性原理：事件的时间维（流）与空间维（视差）是同一个对应问题的两个切面。
- **IED²S (ICCV'25)**：训练期用强度图向事件分支**蒸馏**稠密结构，推理期纯事件——稠密先验可以只
  活在训练里。对本仓库：渲染通道若在角度 1 被证伪，蒸馏是"保精度去渲染"的备选路径（推理去渲染、
  训练留渲染教师，本仓库已有 DISTILL_WEIGHT 基础设施）。
- **DAGr (Nature'24)**：检测侧同 1.1；帧给上下文、事件给低延迟更新，这与"渲染给上下文、事件给
  增量"的递推手部跟踪同构。

### 1.4 Scene Flow / Motion Segmentation / Ego-motion

- **对比度最大化（CMax）家族**（Shiba et al. TPAMI'24 统一光流/深度/自运动；变分迭代 CMax
  CVPRW'25 做运动分割；Out of the Room 3DV'24 泛化动态分割）。第一性原理：**把假设的运动模型
  作用在事件上，检查事件是否被"对齐锐化"**——模型-事件对应不需要渲染图像，只需要能把模型变换
  作用到事件坐标上。这是角度 1 的最强文献旁证：CMax 的 IWE 本质上就是"参数化模型 ↔ 原始事件"
  的直接对应。
- 运动分割的共识：先补偿主导运动（自运动），残差即独立运动——对应本仓库"prev 解释掉的事件 vs
  解释不掉的事件"的读法，`g_surf` 通道给的就是逐事件的"可被 prev 解释度"。

### 1.5 VO / SLAM / 3D Tracking

- **DEVO (3DV'24) → Stereo-DEVO / DEIO (2025)**：稀疏 **patch 跟踪** + 循环光流 + 可微 BA。
  第一性原理：不要处理所有事件，**选择性地跟踪模型锚定的稀疏局部区域**并在优化层融合。
  对本仓库：读出侧"每个关节只看自己邻域的事件"与 patch 思想同构（角度 2）。

### 1.6 点集上的读出（readout）设计 —— 角度 2 的直接文献

| 工作 | 机制 |
|---|---|
| DAPT (AAAI'25, LiDAR HPE) | 可学习**关节 anchor/query** 在多密度层级与点特征交换信息（MDE），1D heatmap 解码 |
| EgoPoseFormer (ECCV'24) | 两阶段：全局池化 MLP 出**粗位姿提案** → 逐关节 query token 用**投影后的关节位置**引导 deformable attention 在特征图上取局部证据，输出精修偏移 |
| GBT (2023) / HOI-LiDAR (2026) | 逐关节 query 交叉注意力读出成为点云位姿的标准解 |

**第一性原理**：全局池化把 O(N) 个节点压成 1 个向量，空间细节在读出处死亡；解法是让**每个输出
量拥有自己的查询**，只聚合与它相关的节点。EgoPoseFormer 的粗提案≈本仓库的 `prev`（递推先验），
其投影引导注意力≈"用 prev 的 FK 关节决定每个关节头读哪些事件"。**状态在读出侧进入是文献与
本仓库设计法则（州值/读出可用状态，结构不可用）的交点。**

## 2. 三个角度的判定

### 角度 1：MANO FK 与事件流直接对应，去掉 mask/depth 渲染（S37，本轮实验）

**判定：可行，已实现并在训（S37）。** 机制依据：CMax 家族证明模型-事件对应不需要图像化；DAGr
证明先验作为节点值融合正确；EvHandPose 证明手模型的**几何**（边缘）而非**图像**足以构成对应。

实现（`MNISTModel._fk_extra`，`MODEL.PREV_FK_DIRECT`）：每个采样节点得到 4 个解析值，替代原
来光栅化后取样的 `sil`/`inv` 两通道：

| 通道 | 定义 | 对应的渲染面 |
|---|---|---|
| `g_surf` | exp(−d/8px)，d=到 778 个投影顶点的最近距离 | `sil`（软化 + 带梯度方向） |
| `invz·g_surf` | 最近 8 个顶点的 min-z 归一化逆深度 × g_surf | `inv`（min-z 代替 z-buffer 前表面） |
| `g_skel` | exp(−d/16px)，d=到 21 个投影关节的最近距离 | 渲染从未提供的骨架内部结构 |
| `invz·g_skel` | 该关节逆深度 × g_skel | 同上 |

工程要点：特征只在编码器将要 gather 的 ≤`ENCODER_MAX_NODES` 个节点上计算（`_sample` 确定性，
两处调用同行），否则训练批的 (N×778) 距离阵在千万级事件下不可行；采样索引两两互异 ⇒ scatter
确定性。`no_grad`，状态只做条件化。合同测试 `tests/test_s37_fk_direct.py`（6 项）+
单变量 config 差异测试守住与 S36 的可比性。

预注册假设与门槛（debug 轮 s37）：
- **H1** 精度：两种子均值选点 RA ≤ 31.67（S36）为不劣；**≤ 30.67（−1.0 mm，约 1.6× 种子差 0.61）为显著**。
- **H2** 延迟：去光栅化后 scaled latency < 7.40 ms。
- **H3** 风险：无 z-buffer 的解析深度在自遮挡区退化 ⇒ 若 local RA 相对 S36 恶化超过 global，此为死因。
- **H4** 风险：平滑距离场对 prev 误差更敏感 ⇒ 网格中位数显著劣化（S36：38.70/34.05）为回路增益恶化的读数。

**已知的不可越线**：`sil` 的二值性是"事件是否被 prev 解释"的最锐读数；解析软化换来梯度方向，
代价是锐度。两者谁赢由选点协议裁决，不由直觉裁决。

**测量结果（2026-08-30，训练 23:15→05:43，选点 →07:33）——角度 1 成立，S37 取代 S36 为当前臂：**

| 指标 | S36（渲染） | S37（FK 直连） | Δ |
|---|---:|---:|---:|
| 选点 RA，种子 3407 | 31.97（step4500） | **29.64**（step4500） | −2.33 |
| 选点 RA，种子 3408 | 31.36（step4000） | **29.81**（step1000） | −1.55 |
| 两种子均值 | 31.67 | **29.72** | **−1.95**（门槛 −1.0，过） |
| 种子差 | 0.61 | 0.17 | 收窄 |
| 网格中位数（两种子均） | 36.38 | 35.58 | −0.79，无发散点 |
| local 组 RA 均值 | 35.34 | 32.16 | −3.19 |
| global 组 RA 均值 | 27.91 | 27.21 | −0.70 |
| 绝对 MPJPE（非对齐，均值） | 45.65 | 48.34 | **+2.69（退化，记录在案）** |
| 延迟 raw（600 包同会话对测） | 6.01 ms | 6.37 ms | **+0.36（H2 否证）** |
| └ 条件化阶段 | 2.11 ms | 2.47 ms | +0.36 |

- **H1 确认**：−1.95 mm，两种子各自都优于 S36 两种子中更好的那个。
- **H3 否证**：local 组改善最大（−3.19）——无 z-buffer 的深度近似没有成为死因，骨架通道
  （`g_skel`）反而最可能是手指局部的增益来源。
- **H4 否证**：网格中位数 35.49/35.68 对 S36 的 38.70/34.05，无 90+ 发散点，种子差 0.61→0.17。
- **H2 否证**：batch=1 下解析路径（`_sample`+gather+topk+scatter）的 kernel 发射数多于光栅化
  scatter，条件化阶段 2.11→2.47 ms。去渲染的价值在精度与实现简洁，不在延迟；延迟优化
  （顶点子采样、免 topk 的融合核）需要重训对齐，另立轮次。
- 附注：绝对（非对齐）MPJPE 退化 2.69 mm，主要来自种子 3408 选中的早期 checkpoint
  （step1000，abs 52.47）。选点协议以递推 RA 为唯一准则，此处如实记录不加辩护。

### 角度 2：池化+解码头改为 LBS 引导（S38 候选，待 S37 出结论）

**判定：机制上最对症，风险最清楚。** S36 的瓶颈已被测量定位在读出：`probe_s36_nodes` 把节点数
从 512 提到 4096，递推 RA 只动 0.09 mm——信息死在 mean+max 池化，不死在采样。文献（1.6 节）的
标准解正是逐关节 query 读出，且 EgoPoseFormer 的"投影引导"与本仓库"状态可以在读出侧进入"的
设计法则重合。

必须绕开的本仓库前科：
1. **KSGN（§9，hand_data51 线）**：LBS 语义关节头作为**加性旁路**被判惰性——梯度走直连路，旁路
  贡献 0.16 mm。⇒ 逐关节读出必须是该关节局部参数的**唯一通路**（S10 active head 已是此结构：
  `joint_heads[k]` 是 45D 局部位姿的唯一出口，改的只是它的**输入**从全局池化换成关节局部池化）。
2. **KEG（回路增益 0.910）**：状态引导的是**读出聚合权重**，不是消息传递结构——EdgeConv 的图
  仍由 (x,y,t) 决定。且必须保留一条全局池化通路给 root_head/兜底，关节局部读出零初始化门控，
  从"纯全局"连续形变到"全局+局部"，训练自己决定用多少。
3. **零事件合同**：空包必须逐位返回 prev ⇒ 局部池化的 mask 语义要和现在的 `any_node` 门一致。

设计草案（S38）：`nodes[k] = Σ_i softmax_i(−‖p_i − π(J_k(prev))‖²/σ²)·h_i`（对 16 个 MANO 关节
各一个空间核读出，σ 取 ~16 px 起步），`_decode_active` 已有 `nodes` 参数位（`(B,16,node_dim)`
路径现成）。参数增量 ~0：核无参数，或每关节一个可学习 σ（16 个标量）。

**测量结果（2026-08-30，训练 10:25→14:23，选点 →15:01）——角度 2 否证，S38 不采纳，S37 仍是当前臂：**

| 指标 | S37（全局池化） | S38（关节 query 读出） | Δ |
|---|---:|---:|---:|
| 选点 RA，种子 3407 | 29.64（step4500） | 32.05（step1500） | +2.41 |
| 选点 RA，种子 3408 | 29.81（step1000） | 36.24（step5000） | +6.43 |
| 两种子均值 | **29.72** | 34.15 | **+4.43（劣化，弃）** |
| 种子差 | 0.17 | 4.19 | 爆开 |
| 训练后 σ（初始 16 px） | — | 均值 54.5 / 116.1 px，最大 147 / 365 px | 核被摊平 |

- **H5 否证**（两种子均值差 4.43 mm）。死因不是实现而是机制，σ 的走向就是证据：
  优化器把窄核**主动**训成准全局平均（365 px ≈ 整幅画面），即它在训练分布下拒绝
  "由上一状态决定读哪里"。而摊平后的读出是 128 维的准全局均值，信息量低于原来
  512 维的学习投影池化——所以不是打平而是净劣化。
- **机制（H6/H7 合并证实，KEG 法则的读出侧版本）**：跟踪所需的大噪声课程
  （`PREV_NOISE_LARGE_POSE=0.3 rad`，投影偏移可达几十像素）会**反选择一切由状态决定
  证据取舍的结构**——图结构（KEG，回路增益 0.910）如此，读出核（本轮）也如此。
  种子 3407 的网格在 step1500 后单调劣化（33.0→40.1）：越训练越依赖状态中心读出，
  闭环鲁棒性越差。
- **变体已被同一份证据预先证伪**：σ≈54 px 的"冻结宽核"变体正是种子 3407 学到的
  终态（32.05，仍差 2.3 mm），不必再花 5 小时。
- **设计法则修订**：状态可以作为**数值**进入任何层（`_fk_extra` 四通道、prev 嵌入、
  解码头输入），但不得决定**证据的选择权重**——无论在图（KEG）还是在读出（S38）。
- 代码保留（`ENCODER_JOINT_READOUT`，默认关；契约测试证明开关不影响 S37 路径的池化
  特征逐位一致），配置与 checkpoint 归档为负结果证据。

### 角度 3：loss 换回 SO(3)+FK（S39 候选，最后做）

**判定：可测，但必须带上一轮的两个补救开关，且预期收益的机制不明。** hand_data51 线的完整测量
（§13–§14）：腕对齐 RA 打平（−0.78 ± 0.61，门槛 −1.1），**绝对平移 63.7 → 83.6 mm 退化**——
根因是 `L_trans` SmoothL1 在 β=1 m 下厘米级误差全落二次区（梯度∝误差，几乎为零）且 `L_FK`
根相对。补救开关已在 `model/model.py` 实现且默认关闭：`TRANS_BETA≈0.01`（恢复常梯度）、
`ABS_FK_WEIGHT>0`（非根相对 FK 项）。S36 的绝对 MPJPE 已经是 45.6 mm，不带补救直接换 loss
可预期重蹈覆辙。第一性原理上：loss 改的是目标流形上的度量，救不了读出处的信息瓶颈——若角度 2
成立，角度 3 应在新读出之上做单变量测试，顺序不可颠倒。

**S39 预注册（2026-08-30，角度 2 否证后基座回到 S37）**：单变量 = LOSS 块
（`so3_trans_fk`，权重 1/1/2，`TRANS_BETA=0.01`，`ABS_FK_WEIGHT=1.0`）；补救开关是 S4
实现后**从未训练背书**的（FINAL_REPORT："retrain never carried a claim"），本轮是其首测。
契约测试（`tests/test_s39_so3fk.py`，6 项）证明两开关确实接线：GT 处零损失、1 cm 平移误差
在 β=0.01 下代价 ~100×、刚性 z 偏移只被 `L_absFK` 收费。门槛：
- **H8** 采纳门：两种子均值递推 RA ≤ 28.72（S37 − 1.0）；|Δ| < 1.0 判打平（§13 池化线
  −0.78±0.61 打平的重演即此结局）。
- **H9** 守门：两种子均值绝对 MPJPE ≤ 50.3（S37 48.34 + 2.0）——补救若无效，abs 会像
  §13 一样 +20 mm 级恶化，此时无论 RA 如何都判补救失败。
- **H10** 稳定性：网格无 > 45 mm 格点（S37 网格峰值 ~38）。

**测量结果（2026-08-30，训练 15:56→20:07，选点两种子完整网格）——角度 3 否证（递推 RA），
补救开关首测有效，S37/mse_51d 仍是当前臂：**

| 指标 | S37（mse_51d） | S39（so3fk+补救） | Δ |
|---|---:|---:|---:|
| 选点 RA，种子 3407 | 29.64（step4500） | 32.06（step2500） | +2.42 |
| 选点 RA，种子 3408 | 29.81（step1000） | 30.15（step3500） | +0.34 |
| 两种子均值 | **29.72** | 31.11 | **+1.39（超出 1.0 打平带，判劣化）** |
| 绝对 MPJPE 均值 | 48.34 | **45.83** | **−2.51（H9 确认，补救有效）** |
| local 组 RA 均值 | 32.16 | 36.47 | +4.31（手指精度被让渡） |
| global 组 RA 均值 | 27.21 | 25.70 | −1.51 |
| 网格峰值 | ~38 | 40.9 | 无发散（H10 确认） |

- **H8 否证**：+1.39 mm，方向与 §13 dense 线（−0.78 打平）一致偏坏。**H9 确认**：abs 不但
  没有重蹈 §13 的 +20 mm，反而改善 2.5 mm（也略优于 S36 的 45.65）——`TRANS_BETA=0.01`
  + `ABS_FK_WEIGHT=1.0` 的护栏作用成立，这是这两个开关自 S4 实现以来的第一次训练背书。
- **机制读数**：流形损失把精度从**手指关节（local +4.3）挪给了全局位姿（global −1.5）与
  绝对平移（abs −2.5）**。SO(3) 逐关节等权 + FK 米制项天然偏向大骨骼；mse_51d 的
  λ=450/45 维隐式加权反而更偏向手指。本项目的主指标是腕对齐递推 RA（由手指主导），
  所以 mse_51d 胜出。若未来主指标换成绝对（非对齐）MPJPE，此结论需要反转重审。
- 运行事故记录：3408 的首次选点误跑在训练未完的部分网格上（误选 step1000/32.13），

执行：GPU 0-1 串行（每次启动前等 GPU 1 空闲），每臂两种子训练后立即选点。

**S41 结果（2026-08-31，训练 07:59→12:31，选点 →13:08）——采纳，S41 取代 S37 为当前臂：**
RA 28.24/28.03（均 **28.14**，对 S37 **−1.58**，过 −1.0 门槛；两种子各自都优于 S37 两种子，
种子差 0.21）；abs 44.25/41.80（均 43.02，**−5.32**）；网格中位数 31.1/31.3（对 S37 的
~35.5 整体下移 4 mm）。两指标同向改善、无权衡。机制闭环：S38 死于"状态中心的选择"
（σ 被摊平），S41 证明"更富的读出"本身成立——内容注意力的选择权重只依赖节点特征，
噪声课程无从反选择；query 零初始化 = 从纯 mean 池化连续形变，下行有界。角度 2 的
最终结论修正为：**读出瓶颈真实存在，解法必须状态无关（内容注意力），不能状态中心
（空间核 query）。**

**S40 结果（2026-08-31，训练 01:31→06:22，选点 →07:59）——否证，不采纳：**
RA 31.73/30.29（均 31.01，对 S37 **+1.29**，超打平带）；abs 44.46/41.56（均 43.01，
**−5.33**）。两种子选点都落在 step5500。与 S39 同向的权衡再次出现：FK 几何信号
（无论进 loss 还是进输入通道）改善绝对定位、损害递推手指精度——机制上，方向场在
prev 有噪时指向的是*带噪*的预测表面，等于给网络一条依赖 prev 精度的捷径，噪声课程
下它换来的是闭环鲁棒性变差。该模式已有两份独立证据（S39、S40），升格为设计约束：
**FK 几何只该以幅值（距离）形式进入，方向/米制项是 abs↔RA 的权衡旋钮，不是免费改进。**

`NCCL_P2P_DISABLE=1`、复现漂移 < 0.05 mm 纪律。
