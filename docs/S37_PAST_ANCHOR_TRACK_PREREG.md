# PA1：固定过去伪锚的局部候选诊断

2026-09-26，真实数组读取前登记。承接已关闭的PA0；不重跑PA0、NF2、HE0。仅一个CPU诊断，不是新完整网络候选、自身纠偏闭环、创新通过或最终H成绩。S37仍为当前臂。

## 问题与固定范围

问独立于当前MANO候选生成的二维轨迹，能否在给定过去自身几何时选择一个更好的局部姿态。关联是有偏的条件伪锚，轮廓不保证材料身份；继承过去姿态偏差。官方[HASTE](https://github.com/ialzugaray/haste/tree/955c80acf6256d1d4fead22e6b11b8e351b34f53)仅作固定事件前端，原理/时钟证据见PA0两篇文档。代码固定上述commit、原始MIT许可，不改评分/模板公式，不使用作者app的初始化辅助函数。

复用D1 `lyq_local`、`lyq_global` native首秒各一次；复用R0 seed3407 step2500同两序列的自身轨迹。只含训练前缀；不是新鲜留出集。native全事件比S37的粗格/最多2048节点输入更丰富，任何收益不能归因于评分公式本身。原H和短反馈未答项不改。

## A0：固定事件前端，先封存后读姿态

原生int64微秒、640×480、稳定原始行ID、非递减时间；同时间行按原ID顺序，不按float时间重新归属。HASTE输入时间先减序列origin再转float秒；原生时钟保存在外层。每条轨迹依次消费每个前缀行一次，接受事件ID单独保留，绝不从中间向后回读。序列更换新建全部状态；无重检测、标签修剪或追踪质量选优。

用[0,50ms)事件选种子：按32×32原生像素单元统计非空单元，计数降序、cell ID升序，取至多32个；每单元位置取x/y各自中位数（允许半像素），theta=0。这是稀疏活动种子，不声称角点检测器；不创建全幅稠密栅格。选种子用到的全部行属于谱系。50ms之后开始顺序输入，保留原HASTE31×31局部模板、193接受事件窗。极稀疏种子允许一直未初始化，不补种或降低窗长。

固定输出cut为100、150、200、250、300、…、1000ms，包含且仅包含timestamp<cut的事件。100/150/200为过去记录，250…1000共16个查询/动作（32个总查询），不删失败行。200ms固定源锚，100和150ms仅用于可用性检查及过去速度定义。每记录保存ID、运行状态、xy/theta、接受总数、最近193接受行、中间行/原生reference τ、最新接受行/时刻、消费前缀界、源输入identity和计算后单调时钟。

持久模板可能依赖很早的事件，保留每条轨迹全接受ID链及种子选择前缀哈希，不能把最近193行当全部祖先。reference不等在线availability。这里是离线CPU回放，`computed_monotonic_ns`只表示本次计算完成；cut是传感时间消费上界，二者不得相加或冒称真实传感器时延。三个时钟均明确保存。本实验不验收7ms。

A0先保存并哈希封印两个序列全部二维轨迹和种子。此前不反序列化R0姿态/target、MANO或相机。先通过人工接口测试：193时钟、同时间ID、顺序/重复拒绝、重置、输出所有权、前缀不受未来改变影响、空/稀疏、不同绝对origin平移一致。只验证驱动语义，不声称HASTE的近似增量分数等于另一完整重算算法。

## A1：固定源关联和当前候选

A0封印后只读R0字段`prev,pred,end_ms,betas,camera_K`；不读target或meta。要求首段start=0，end_ms=49+50k，prev[k]=pred[k-1]，原段起始prev[0]的时刻是0ms。实际核对`prepare_hand_data.py:283,325`与`nf2/stage_a.py:317`后确认：R0的K已保留原生标定，直接使用，不再次缩放。此前实现前草稿误称粗格K，已在任何真实读取前更正。

200ms时已初始化轨迹作为源候选。在其reference τ_a处，以0ms初值和截至200ms已可用的原S37预测（49/99/149/199ms）对原始51D存储坐标作分段线性插值，越末端只保持199ms值。该运动近似会有偏，不是SO(3)真轨迹；不读取以后预测。用同一τ_a的自身mesh在源xy射线取最近正深度面和重心，固定(face,bary)；未命中留原因但不造深度。此后不重新ray-hit当前候选来改变材料。

每个查询cut的q0为原R0 pred[k]，k=cut/50−1；q+和q−只把**51D存储index6**分别加/减5π/180。它是首个local残差的第一个轴角分量，不宣称解剖屈曲轴；其他50维逐位保持。顺序固定q0,q+,q−，不选别的关节/轴/幅度救场。

当前观测reference τ处，使用截至cut已可用的相同自身历史插值，仅用候选替换本查询末端q0；τ早于上一状态时自然不依赖当前候选，τ在末端后则保持候选，不把观测回填为早期在线输出。固定源(face,bary)投影到该τ的候选mesh得到P_c(τ)。同一查询各候选和null共同合法集合：源命中、当前running、当前τ大于200ms时**全部已命中固定源**的最大τ（包括本查询随后不合格的源，保守固定界）、点深度>1mm、投影在原生图像内、全数有限。非法行统一排除，记录原因；不按残差/标签/遮挡结果筛选。不是材料可见性证明。

Main分数为共同集合的平均平方像素误差。P控制按track ID升序把完整当前(τ,x,y)tuple循环移一位，保持源face/bary，候选在移入τ上求值；相同权重1。先构造配对，删除任一候选或P几何非法的源行，再在剩余集合重建配对，直到不再删除（至多32轮）；如此最终tuple边缘集合相同，不在删行后暗中保留集合外端点。支持检查必须看`score(c)−score(q0)`向量，不能仅看绝对分数。两轨迹是可定义非恒等配对的最低数，不是充分信息理论下限。

另有两个完全不读当前二维位置的历史姿态对照：Hold取上一原S37 pose；CV取2×上一pose−上上一pose，均保留q0的t/root，仅提供local45。在相同三候选中选择与此历史提议的21关节RA平方距离最小者。它们不用当前观测reference/事件计数，只有相同候选族中q0本来已含当前事件的共同信息。所有政策相同tie规则：与最小分数相差≤1e−8取最早候选。无支持查询Main/P均回q0，Hold/CV照固定规则且保留完整分母。

## 门与B标签阶段

每个查询的共同支持至少2轨迹，Main候选最大最小分数差>1e−8，并且P与Main相对q0的差值向量最大差>1e−8，才算支持。**每动作至少8/16查询支持**才允许开B；这个覆盖门是事前经验可用性标准，不是普遍可观测性定理。任一动作未过即`INCONCLUSIVE_FIXED_TRACK_SUPPORT`，停止且不读标签。

若A门均过，所有候选、几何、分数、选择、支持mask、无支持回q0和32查询预测先封印，然后B解压R0 `target`整字段（128行），仅选择固定k的16行用于MANO解码/评分；不能声称只反序列化16行。实际MANO解码原21关节joint0对齐MPJPE。全部16查询/动作都入分母。任务效用门：Main每动作严格低于q0、Hold、CV三个policy均值（不取四舍五入）。特异性门：Main每动作严格低于P。全部过才`CONDITIONAL_FIXED_PSEUDO_ANCHOR_UTILITY`，仍不认证材料身份/闭环/新颖性；效用未全过`NO_FIXED_PSEUDO_ANCHOR_UTILITY`，特异性单独失败则`UTILITY_WITHOUT_PAIRING_SPECIFICITY`。无标签选样、拟合或训练。
