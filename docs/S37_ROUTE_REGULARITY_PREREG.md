## 2. 实际函数，而非模块名称

固定完整事件包、beta/K、权重和执行环境，当前配置关闭 prev render 与 root covmap。事件图编码 F/h 不依赖历史姿态 q；几何路由输出

`a_i(q) = W_LBS[vid_i(q)] · 1[distance_i(q) ≤ 16 px]`。

最终 vid 和 band 不变时 a 固定，pool 后的 evidence e 也固定；距离没有作为连续权重进入当前读出。非空包输出为 `f(q)=q+H(F,e(q),Lq)+G(q)`。root head 不直接读 q，finger head 读自身三维角，G 读全 51 维历史。在路由和 ReLU 分支固定的理想实数区域，输出是仿射函数，导数为 `I+DG+B`；B 仅含各 finger 自身角块。

`no_grad` 切断自动微分，不能证明前向对 q 不敏感；分支内真导数和跨分支有限变化也不是同一个量。vid 改变可以选到相同 LBS 行，a/e 的变化也可以被池化或 head 消掉。反之，切换到更正确的关联可能有益。仅凭切换次数、输出 gain 或不光滑性，不能推出任务危害、闭环不稳定或平滑替代的必要性。

投影函数返回的是截断后的 `z_safe`，当前 front 选择不是严格物理 first-hit 可见性；本文没有新数据证明负深度顶点在实际序列中造成错误。精度、轴角表示分支、空包与替代 flags 的限制见独立数学报告，不把理想导数充 FP32 极限或 MANO 空间的误差 Jacobian。

## 4. 剩余缺口与不执行的理由

在本轮所查来源中，尚未找到同时具备“自身递推 q0、预定同方向两尺度、实际 vid/band/a 记录、finger own-angle 与固定 evidence 分离”的完整组合。这是有限查阅范围内的归因缺口，不是项目从未做过相应工作的一般断言。

四角输出 `Y_ab=B(q_a,e_b;F)` 满足 `Y11−Y00=(Y10−Y00)+(Y11−Y10)`。这是路径依赖的有限归因恒等式；另一顺序相差交互项。冻结旧路由是控制，不是可部署修复；两尺度不证明极限不连续性。即便路线项非零或很大，也还不知道它是补偿还是破坏，不能据此立项改 head。

当前没有一个新增观察可以在不另加任务危害/效用前提的情况下改变 C0r 决策，因此不做分支普查、方向/幅度扫描、P2 重跑或连续头重拟合。未来若出现独立具体缺陷，须先写清固定输入、任务误差、简单对照以及两种相反结果分别改变什么决定；经验 train-only 效用仍可检验，不要求先得到普遍可辨定理、外观真值或 flow GT。

SU2 的零 soft 支持更新证据仍按原子组/参数风险边界解释；不把它改写成按零支持保持的必要性，也不从其结论推出路由总是有益。AEGNN 的缓存等价/失效问题与估计函数的正则性是两条证据链，不能互相替代。
