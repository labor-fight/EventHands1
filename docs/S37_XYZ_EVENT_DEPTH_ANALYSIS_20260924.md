# S37 起点：完整 FK 三维图与事件深度通道分析

范围：2026-09-24，静态代码检查与文献分析。未启动训练、优化器或新的准确率探针；当前臂仍为 s37_routed。以下设计是待验证假设，不是实验结果。
同日晚间的运行时 DEBUG（无训练）见文末"运行时 DEBUG"一节，它替代本节中尚未验证的推断。

## 代码事实

- `semkine/event_gnn.py` 的图节点是事件，几何为归一化 x、y、t；时间不是空间深度。
- `model/model.py::_project_verts` 返回 uv 和 z，`_route_nodes` 用二者调用 `route_front_vertex_lbs`。该路由以像素近邻挑候选、以 z 选局部前表面，再以 LBS 聚合到关节；属于近似可见性处理，并非精确三角面 z-buffer。
- `model/model.py::_event_guided_mesh_forward` 及 `semkine/event_guided_mesh.py` 已有完整 vertices 输入的独立分支。不能把该分支当成当前 S37，也不能从接口存在推断有效性。

## 判断一：完整 XYZ 可以作为网格图几何

保留三维顶点、选什么边、如何关联二维观测是三个不同问题。建议 DEBUG 首先采用完整 MANO 顶点和固定面邻接，并保留三维相对向量；三维 kNN 作为可选附加边，须检查相触手指和手掌前后表面的短路。

仅欧氏距离或邻接不能表达整体刚体变换：距离在共同平移、旋转下不变。相机系相对向量表达朝向但抵消平移。手部中心化几何可用于局部姿态，相机系位置及事件几何关系用于 root；中心化所去掉的 root 信息需单独保留。

在针孔模型下，像素对应射线 X(lambda)=lambda K^-1[u,v,1]^T。可以将事件反投影成射线与三维 mesh 关联，不必把 mesh 本身变成二维图。也可以保留 XYZ，仅在取观测时投影。两者都需要内参、正确坐标单位及遮挡处理。固定米制射线距离阈值与固定像素阈值不是同一容差，前者随深度改变角度范围。

## 判断二：事件可以增加深度假设，但原始事件没有深度测量

建议显式区分三种来源：

1. 上一状态 mesh 提供的深度先验：事件射线与预测可见面相交，得到 z_prior；没有交点则标 invalid。轮廓事件、遮挡边界及背景不能强制视为表面上有唯一点。该通道包含上一状态误差，并非独立证据。
2. 历史事件推断的深度：递归模型预测 z 或逆深度及不确定度。可以形成可学习假设；需监督或可辨识的几何约束。自由特征维度不能直接称为物理 z。单目学习可以利用手尺度与运动先验，不等于单条事件能测距。
3. 双目、RGB-D 或其他外部测距：引入额外传感约束，已超出当前单目 S37 输入条件。

若 z 表示相机光轴深度，反投影点为 X=z K^-1[u,v,1]^T（常规内参的第三分量为 1）；若使用单位射线，乘数则是沿射线距离，不能混用。

建议候选属性为 (u,v,t,p,z_prior,depth_valid,uncertainty)，保留 t。没有校准过的置信度只可作为启发式可靠性分数，不能直接解释为概率。

主要风险为自反馈：prev 深度错误→事件被放入错误三维位置→按这些位置建边→回归器得到支持错误 prev 的输入。detach 只能切断梯度，不能消除推理时的循环依赖。DEBUG 优先让状态无关事件编码保留，再在读出/事件—网格关联处引入深度条件。

## 代表性文献与迁移边界

- [Pixel2Mesh, ECCV 2018](https://www.ecva.net/papers/eccv_2018/papers_ECCV/papers/Nanyang_Wang_Pixel2Mesh_Generating_3D_ECCV_2018_paper.pdf)：三维网格图结合图像感知特征逐级变形。启发是三维几何与二维观测可以共同存在；不是异步事件跟踪验证。
- [Mesh Graphormer, ICCV 2021](https://arxiv.org/abs/2104.00272)：图卷积与注意力结合，分别建模局部和非局部关系。支持研究 mesh 拓扑消息传播，但不证明任意三维 kNN 或删除相机接口有效。
- [FastMETRO, ECCV 2022](https://fastmetro.github.io/)：分离图像与 mesh token 的交互，并加入形态结构先验。启发是保留独立观测编码，再让 mesh 查询证据；原作不是使用上一状态深度的事件闭环。
- [HaMeR, CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/papers/Pavlakos_Reconstructing_Hands_in_3D_with_Transformers_CVPR_2024_paper.pdf)：从图像估计 MANO 参数，强调数据和模型规模。启发是 mesh 可以承载中间特征，而输出仍可保留 MANO 参数约束；不能直接照搬其规模到 S37。
- [EvHandPose](https://arxiv.org/html/2303.02862v3)：hand flow、事件扭曲对比度和手边缘约束。启发是检验预测运动能否解释事件，不能把它理解成原始事件带有深度。
- [EvRGBHand, CVPR 2024](https://arxiv.org/abs/2403.07346)：事件与 RGB 互补手网格重建。RGB 是额外观测，不能把该证据能力视为单目事件 S37 已有。
- [Learning Monocular Dense Depth from Events, 3DV 2020](https://arxiv.org/abs/2010.08350)：递归网络从事件预测稠密深度。支持事件历史可用于推断深度；其场景与非刚性手部不同，效果不可直接迁移。

上述“对 S37 的启发”均为分析推论，非原论文直接验证的结论；没有比较跨论文指标。

### 判读

**问题一（完整 FK 三维点、不投影、直接 xyz 建图）：能建，运行时证据不支持它带来增益。**

- "投影丢深度"在 S37 里不成立。`_project_verts` 返回 (u, v, z)，在已知内参下与 (x, y, z) 一一对应；S37 在三分之一以上的事件上用 z 选前后层。二维事件和三维网格的任何关联都要经过相机射线，不投影时的点到射线关联在网格外事件上与 S37 路由几乎逐一相同（A）。
- S37 真正的几何近似是顶点散点加 3 px 前表面测试。在手指交叠的 local 序列里，它把 26–30% 的网格上事件分到与精确表面不同的关节，主要是抓到附近更靠前的遮挡部位。换成精确关联（等价于三角面 z-buffer，仍然是投影）后，当前网络闭环 RA 的变化在 ±0.34 mm 内，符号不一（A2）。
- 在当前姿态的 xyz 上建 kNN 边：global 上 60% 的边就是网格边、短路不到 1%，不带来新东西；local 上最差 10% 的帧有 29% 的边短路，最差 10% 的相邻 50 ms 步边集只重合 64%，闭环 prev 建的图与同刻 GT 图在最差 10% 的步里只重合约一半（B）。图结构随状态变化正是 KEG 失败的机制；MANO 固定拓扑（或静息姿态上的邻接，即 DynamicFusion 在规范空间建图的做法）没有这个问题。
- 把 xyz 作为节点或边特征，S38a 已经训练测过（递推 RA 26.90，闭环放大率 4.26）：几何以 prev 先验的形式进入并在闭环中回灌。
- 若一定要做 3D：边用固定拓扑，关联继续走投影或射线（两者等价），几何只能乘证据进入（S38 判读的第 2 条）。

**问题二（异步事件流加深度通道引导 prev 的 3D 图）：可以加一个通道，但它不是新观测；异步不改变这一点。**

- 事件本身没有深度。即使网格完美，按 1 px 判定也只有约一半事件有确定的表面深度，按 3 px 容差只有 10–25%，其余在轮廓或遮挡边上（C）。
- prev 给的深度通道就是 prev 自身的深度误差（相关 0.75–0.98，斜率约 1），闭环中为 25–100 mm；把状态改成逐事件更新（异步）只能消掉 1–1.5 mm（D）。
- 一个包内事件自带的深度信号（逼近、视差）只有 0.02–0.11 px，远低于 1 px 的像素量化（E）。EMVS 一类的事件深度依赖已知运动和多视角视差，这个条件在手部跟踪里不成立。
- 如果用这个 z 去建事件图，会改动 20–31% 的手上边，而闭环 prev 的 z 判断跨层边约一半是错的（G）。
- 剩下有依据的深度来源只有有监督的单目学习（本数据可以用 GT 网格射线求交给手上事件打深度标签）或额外的测距传感器。前者按 BEVDepth 的经验必须显式监督；而且上午的根深度 oracle 已经表明，深度不是 RA 的瓶颈。

**对当前臂的含义。** 两个方向都不开臂，当前臂保持 S37 路由读出。上午的探针显示，S37 在 global 上比逐帧基线多出的误差在像面内的旋转和平移漂移上，而不是深度丢失；本次没有推翻这一点。

| [I2L-MeshNet, ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123520732.pdf) | 每个顶点的 x、y 是图像空间 1D 热图，z 是根相对深度热图（手部以腕为根），有监督；绝对根深度另由 RootNet 给出 | 图像对齐特征里的"深度维"是根相对、有监督的，不是从 2D 观测里保留下来的量 |
| [BEVDepth, AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/25233) | Lift-Splat 只靠任务损失学到的逐像素深度很差（AbsRel 3.03），加入 LiDAR 显式深度监督后 0.23；把预测深度换成真值，mAP / NDS 提升近 20% | 自由的深度维不会自己变成物理深度；若做学习式事件深度，需要 GT 网格射线求交给出的标签 |
| [EMVS, IJCV 2018](https://rpg.ifi.uzh.ch/docs/IJCV17_Rebecq.pdf) | 已知相机轨迹，把每个事件按其时刻的位姿反投影成射线，在视差空间体里找射线密度极大值得到半稠密深度 | 依赖已知运动与足够视差；E 显示每包视差只有 0.02–0.06 px |
| [Ev2Hands, 3DV 2024](https://arxiv.org/abs/2312.14157) | 单目事件双手 3D：事件作为 (x, y, t) 时空点云，PointNet++ 处理 | 事件文献里的"第三维"是时间，不是深度 |
| [EvHandPose, TPAMI 2024](https://arxiv.org/abs/2303.02862) | 用预测 MANO 的网格运动（mesh flow）扭曲事件，以对比度最大化和手边缘损失做弱监督 | 预测网格引导事件的方式是一致性约束（损失），不是给事件加深度通道 |

上表"迁移边界"是分析推论，不是原论文验证的结论；没有做跨论文指标比较。
