## 0. 先读这条：证据怎么裁决

遇到互相矛盾的历史描述，按以下顺序取信：

1. **同一 checkpoint 的推理期消融**、逐序列递推评测（配对、确定性）。
2. **双副本 / 双 seed、固定步网格、池化均值**，而不是 best-of-N。
3. **教师强制（TF）单步探针、LOSO、数据审计**。
4. 两次独立训练之差。
5. 早期定性判断或已被后续探针修正的文档。

统计边界（S0 冻结，后续一律遵守）：

| 量 | 数值 | 含义 |
|---|---:|---|
| 同配置副本散布 | ±0.4 mm | 点估计噪声地板 |
| 跨训练分辨率 | ≈ 1.1 mm | 低于此不能声称“赢了” |
| 观察到的副本极差 | 2.43 mm | `ch_inv` 两副本 17.55 vs 19.98 |
| `track_render51` 分布中心 | 20.6–20.7 mm | **19.26 是 4 个测点的最小值**，不是期望性能 |

**主方法保留门槛**（至少满足一条）：池化/配对改善 ≥ 1.1 mm；配对 bootstrap 95% CI 不跨 0；或精度持平（2% 内）但真实延迟/操作数改善 ≥ 20%。

## 1. 问题设定（全程不变的部分）

任务：单目事件相机 → 51D MANO 手部状态（平移 3 + 根旋转 3 + 局部残差 45），再经 LBS 得到 21 关节 / 778 顶点。

必须冻结的闭环合同：

```
当前事件证据
+ 上一时刻 51D 状态
+ 上一状态几何反馈（渲染 / KSSF）
→ 预测相对上一状态的 delta
→ prev ← pred
→ 递推到下一时刻
```

硬约束：

- 每段只在开头 GT+噪声初始化一次，之后姿态 GT 不进网络。
- 空事件包必须恒等更新（零事件门）。
- 输出仍是 MANO 状态，不是直接回归顶点。
- checkpoint 按**递推 RA-MPJPE** 选，不按 `val_loss`（后者与闭环 Spearman 曾为 −0.07）。

数据：`data/hand_data51/`，74 序列，51D meta。环境：`EventHandsTrain`（`base` 没有 torch）。

## 2. 三条协议，数字不能混表

这是读后续所有表格的前提。**三套协议的毫米数不可直接比大小。**

| 协议 | Val 构成 | 代表读数 | 用途 |
|---|---|---|---|
| **A. 旧协议** | 仅 `zgz_global` + `zgz_local`（2590 帧） | 19.26 / 18.73 / **12.77** | 2026-08-12–19 的全部 EventHands 实验 |
| **B. 新协议 val_core** | 主体不重叠（train 5 / val 2 / test 3），`zgz_local` 降为命名压力序列 | Track+domrand **16.64 / 17.74** | SemKine S1 起的稠密基线 |
| **C. 混合窗 5–50 ms** | 同 B 的划分，训练窗 5–50 ms，**在 50 ms 上选点、主张在短窗** | LNES 对照 worse-of-two **21.09**；KEG 递推 ~30 | S20 速率主张的对照族 |

旧协议的致命缺陷：`zgz_local` 占 val 约一半帧，事件率仅 692/50ms（同主体 global 的 1/43）。19.26 mm 被这一条序列支配。新协议就是为修这个而生的。

两种评测形态：

- **逐帧绝对**：每帧独立，`prev` 置零。PCA6 / Full 主表用这个。
- **递推 tracking**：step 默认 50 ms，`prev ← pred`。主指标是 **root-aligned MPJPE（RA）**。读短窗结果时必须同时看**非对齐绝对 MPJPE**——RA 会把已经飞走的根平移减掉（20 ms 上曾出现绝对误差 922 km 而 RA 仍是 22.5 mm）。

## 3. 主线叙事：根因被修正了三次

这是整段实验史最重要的认知路径。每一层都曾被当时的证据支持，又被下一层推翻。

```
层 0  纯开环增量 → 线性漂移到数米          否证：无锚积分不可用
层 1  “瓶颈在网络/损失”                    否证：SPA/EDD/J3D/CMN/KSGN 全部无效
层 2  “LNES 丢掉方向信息”（99.4% 正交）    否证：那是闭环差分伪影；TF 增益 0.54–0.78
层 3  “对 val 主体不泛化”（train 5.4 vs val 26.8）
                                           否证：LOSO 未见主体 local 仅 6.0 mm
层 4  真正瓶颈 = zgz_local 低事件率采集域
                                           证实：域随机化 19.26 → 12.77 mm（旧协议）
层 5  稀疏前端在单步已打平，缺口全在闭环
                                           证实：KEG TF 11.59 vs LNES 10.95；递推 30 vs 21
层 6  “软路由不连续导致自激”               否证：1 cm 尺度下软/硬 TV 相等；重训 FAIL
层 7  当前主嫌疑 = 可见性硬门删掉轮廓外侧证据
      + 两臂共享的曝光偏差（相关误差回声）
                                           待验：S21 halo（E5.5a）+ unroll（E5.5b）
```

一句话：**最大的已测精度收益来自数据分布覆盖，不是换网络；当前稀疏前端的缺口来自闭环敏感度，不是单步表示容量。**

## 5. 第一阶段：稠密 EventHands 闭环（旧协议）

详细收据：[experiment_history.md](experiment_history.md) §1–14。

### 5.1 表示不是瓶颈

| 模型 | 维 | 逐帧 RA-MPJPE | local / global MPJPE |
|---|---:|---:|---|
| PCA-6 | 12 | 19.61 | 30.00 / 10.99 |
| Full-51 | 51 | 19.39 | 28.56 / 11.78 |
| GT-PCA6 oracle | — | **6.85** | — |

Full 相对 PCA 只改善 0.22 mm。误差在 LNES→pose 回归器，不在 6D PCA。

### 5.2 纯开环增量不可用

`track_delta51`：`out = prev + Δ`，无渲染反馈。递推 RA **93.38 mm**，平移有偏积分到 5554 mm @ 65 s。失败机制：开环不收缩、误差在输入空间不可见、exposure bias、静止段仍输出非零 Δ。正面信号：抖动确实低于纯 abs。

### 5.3 零训练融合证明闭环方向

\[
x_k=(1-\alpha)(x_{k-1}+\hat\Delta_k)+\alpha\,\hat y^{\mathrm{abs}}_k
\]

α=0.5：RA **19.32**、jitter 8.26，同时优于纯 abs 的精度与抖动。裁决：**放弃无锚开环，升级为绝对锚 + 事件增量。** DualClosed 联合训练双头曾做到 ≈21.37，未超过零训练融合，代码已删。

### 5.4 Track(render)：当前稠密机制的骨架

关键改动：上一状态 MANO 渲染成 silhouette + inv-depth，与 LNES 拼成 4 通道；保留 `prev+Δ`；零事件门；混合噪声；从 abs_full51 暖启动。

选中 `step=1000`：**19.26 mm**（机制 PASS；抖动 11.38 未赢过零训练融合的 8.26）。S0 复现 **19.25760436702419**，逐位一致。

2×2 消融：

| | 输出 = 绝对 | 输出 = prev+Δ |
|---|---:|---:|
| 输入 2ch LNES | 19.97（Full） | **93.38**（Track Δ） |
| 输入 4ch +render | 20.08（AbsRender） | **19.26**（Render） |

**渲染反馈输入 + delta 输出缺一不可**；相对 Full 的精度收益主要来自输出侧 tracking 结构。

### 5.5 语义头路线：看起来涨了，其实头是惰性的

| 实验 | 声称 / 实测 | 裁决 |
|---|---|---|
| SPA（§7） | 选中 17.91 mm（−1.35 vs 19.26） | 历史记录；**KSGN 重建未能复现** |
| SPA2：EDD + J3D | worse-of-two 18.40 | **FAIL**；EDD 的 \(a_j\) 卡在 0（恒等门） |
| CMN 闭环匹配噪声 | 最好 19.25，local 退化 | **FAIL**；用当前策略残差建库反而缩小扰动覆盖 |
| KSGN 重建 | worse-of-two 19.50 | **与基线打平**；同 ckpt 清零图头只动 **+0.16 mm** |

方法学教训：零初始化加性旁路没有理由长大——`fc→51D` 已经直接回归整个 delta。**推理期消融才是判定“头是否工作”的工具**；两次独立训练之差混有 ±0.4 mm 噪声，不能支撑“图传播 +1.34 mm”这类结论。

若再做关节头，必须让它成为局部关节的**唯一通路**（S10 合同），不能再做加法旁路。

### 5.6 根因探针（零训练）与 δ-trust

工具：`tools/debug_probe_local.py`。协议自校验与官方 `eval_track.py` 逐位一致。

| 假设 | 判定 |
|---|---|
| LNES 在输入端毁掉方向 | **否**（作为主瓶颈）。TF 下 train 增益 0.78、val 0.54 |
| 暴露偏差导致误差滚雪球 | **否**（在旧协议 zgz_local 上）。TF 26.84 ≈ 闭环 27.97 |
| 损失导致 delta 收缩 | **否**。val 上过冲 2.3–17× |
| 模型不利用 prev | **是（更强）**。注入噪声被放大 2.4–8× |
| 事件密度造成 train/val 差 | **否**。train 稀释到 val 密度仍 5.9 mm |

δ-trust（推理期 `pred ← prev + 0.5·(pred−prev)`）：19.26 → **18.73**，local 抖动近半。这是**补丁不是解法**——配对比较成立（无训练随机性），但消不掉相关偏差。后来在域随机化模型上边际收益从 0.53 降到 ~0.4 mm。

### 5.7 LOSO + 域随机化：本仓库最大的已测精度收益

LOSO 把 ycy 完全移出训练：未见主体 TF 5.11 mm（在训练集里时 5.09），闭环 local **6.02 mm**。`zgz_local` 仍是 28.7 mm。排除了 GT 时空错位、姿态 OOD、表观尺寸。唯一异常：**事件率 692/50ms**。

唯一改动 = dataloader（网络 11,209,429 参数不动）：

- 相机一致几何增强：滚转 ±15°、缩放 [0.8, 1.25]、平移 ±14 px（事件坐标上变换，标签精确镜像）。
- 事件统计：随机丢弃 keep∈[0.25, 1] + 热像素 2e-4。

旧协议双副本 worse-of-two：

| | 闭环 RA | TF `zgz_local` |
|---|---:|---:|
| 基线 step1000 | 19.26（trust=1）/ 18.73（0.5） | 26.84 |
| 域随机化 | **12.77** / 12.56 | **12.60 / 12.06** |

−34% 闭环、−53% TF。这是四轮网络侧改动全部失败之后，第一个过预注册门槛的修复。

**含义：任何新 raw-event / GNN 模型都必须使用同一增强，并对照这个控制，而不是对照 19.26。**

### 5.8 输入通道、目标函数、语义 mask

**渲染通道（§12，有静默失效警告）。** 当时 `MODEL.RENDER_CHANNELS` 一度从未被代码读取，三臂训的是同一个 4ch 模型。修复后：sil / inv / both 池化均值 20.79 / 20.23 / 20.70，臂间 ≤0.5 mm，不可区分。训练好的 4ch 模型推理期几乎走 `inv`（置零 +37.86 mm），但那是路由选择不是信息需求——重训 3ch-sil 精度一分不少。

**SO(3)+FK 目标（§13）。** `L = L_rot + L_trans + 2·L_FK`。池化 ΔRA −0.78 ± 0.61，未过 −1.1 mm 门槛，判定打平。副作用：非对齐 MPJPE 63.7 → **83.6 mm**（米制 SmoothL1 在厘米误差落在二次区，root-relative FK 不约束绝对平移）。后续若用几何损失，必须加 `ABS_FK_WEIGHT` 和/或 `TRANS_BETA≈0.01`。

**语义值化 mask（§14）。** 不占新通道，把径向骨架坐标写入 sil。51D MSE 上 −0.44 mm（方向对、幅度不够）；叠在 SO3FK 上 **+1.21 mm**。两条路线互斥，不能叠加。迭代 render-and-compare（it2）已撤回：绝对 MPJPE 爆到 198.7 mm。

独立 7ch LBS 输入通道实验已撤回；它唯一留下的结论是“config 键必须被代码读取，未知键直接报错”。

### 6.4 S7 oracle：主动估计的前提被重写

50 ms 上几乎每个关节每步都在动（中位 4.54°，<1° 仅 2.5%）。“跳过没动的关节”描述的不是这份数据。改写为**短窗下的偏差–方差权衡**：多数关节的运动低于估计器分辨率，更新它们是在注入噪声。

旧协议 `zgz` 两序列（功效不足，故 INCONCLUSIVE 而非 FAIL）：

| 臂 | RA | vs 对照 |
|---|---:|---|
| 基线 | 19.26 | — |
| δ-trust 0.5 | 18.73 | 无 GT、无逐关节决策 |
| oracle 0.10 | 18.52 | vs 随机同速率 **−1.38 mm**（CI 不跨 0）；vs δ-trust −0.21（CI 跨 0） |
| oracle 0.40 | 25.30 | jitter 0.225，过跳有害 |

结论：路由信号真实；50 ms 上几乎全部可实现收益已被一个全局常数吃掉。主动主线必须在短窗上判，单在 50 ms FAIL 不得停线。

### 6.5 推导被测试抓住的几条（避免再踩）

- KSSF：不能用与点撒的 IoU 做正确性门（点撒盖不住表面）；距离和胜出线段必须一次 reduce。
- Jacobian：根支点是 `p_root` 不是 MANO joint-0；根运动 Schur 后手指信息只降 5.1%（原门 −60% 不可证伪），改成支撑对比 + 法方程恢复。
- 滤波：误差运输用伴随 `Ad`，不是 \(J_r^{-1}\)。
- 融合：SE(3) 度量在 0.6 rad 腕部不一致时平移偏 5.9 mm；默认改为解耦 R³×SO(3)。
- ~0.9% 帧手穿过像平面（顶点深度到 −5 cm），不得当方法证据。

## 7. 第三阶段：KEG 稀疏前端（S18–S21）

方法名工作标题：EventKineGraph / KEG-Track。主方案合同：[EVENT_KINEGRAPH_MASTER_PLAN.md](EVENT_KINEGRAPH_MASTER_PLAN.md)。

### 7.1 设计上已经关掉的入口

| 入口 | 为什么关 |
|---|---|
| 像素 AEGNN / `torch.cdist` 全包 kNN | \(O(N^2)\)；像素邻域跨手指率实测 0.30–0.80；无 evolving state |
| 把同一 global feature 复制到 16 节点再加图 | 重复 KSGN 惰性头 |
| 输入门控 `gated_scan` | 破坏 LTI，失去任意步长重离散化；改对角 LTI + 闭式 `index_add_` |
| 未归一化指数加权和 | 读出的是事件率不是姿态（median 1.75 / max 3347）；必须用加权均值 |

保留：16 个 MANO 节点、按蒙皮把事件路由到关节、对角 LTI 时间聚合、树上消息、零事件恒等。参数 141k vs raw_scan 166k（匹配宽度）。稠密主干 1.49 GMAC/窗；KEG 在最密序列约 37× 更少乘加，最疏约 585×。**没有异步运行时，不报延迟。**

### 7.2 S20：单步打平，闭环差 10 mm

混合 5–50 ms 训练，50 ms val_core 选点：

| 臂 | 单步 RA | 递推 RA | 放大 |
|---|---:|---:|---:|
| LNES 对照 | 10.95 | 20.87 | ×1.91 |
| KEG（归一化，硬路由） | 11.59 | 30.39 | ×2.62 |

单步差 0.64 mm，在 1.1 mm 分辨率内。**全部 9.5 mm 递推缺口是闭环放大。** 漂移曲线不发散（两臂都稳定在平台），×1 与 ×4 初始化噪声轨迹重合——不是初值复利，是每步误差注入的稳态太高。

S20b 硬化噪声表：水平几乎不动（KEG worse-of-two 31.10 vs LNES 21.07），但晚段退化变平。说明“更依赖近乎正确的条件状态”是真实现象，它决定失败的**形状**而非**大小**。δ-trust 式收缩能把 KEG 每步运动从 10.7 压到 4.9 mm，误差却从 29.66 变为 29.87——走错地方，走慢了也还是错。

### 7.3 软路由：测过、否证、停投

假设：`argmax` 蒙皮在状态误差下不连续 → 整带事件跳到邻关节 → 自激。

| 检验 | 结果 |
|---|---|
| ε 扰动 TV | 硬 2.0 → 软 <0.05（假设在零点成立） |
| 1 cm / 0.1 rad（闭环真实尺度）TV | 软 1.46–1.78 ≈ 硬 1.51–1.79 |
| 双 seed 重训放大 | ×2.66 / ×2.47，门限 ≤×2.10，**FAIL** |
| 单步 | 反而倒退 0.6–1.4 mm（证据被摊到四个关节） |
| 同 ckpt 硬/软切换 | 递推差 0.8 mm、单步 0.12 mm（底噪内） |

**R5 REJECTED。** 路由形式（硬/软/重训软）三条负结果，写进负对照链，不再投入。

### 7.4 闭环裁决（debug 3eaac2，四臂 g 曲线）

单步 RA 对**实测**条件误差（经 FK，不是噪声倍数）：

| 臂 | e=0 | e=26 mm | 斜率 | 独立噪声不动点 | 实测递推 | 回声超额 |
|---|---:|---:|---:|---:|---:|---:|
| KEG soft | 11.15 | 18.03 | 0.32 | 14.3 | 32.6 | ×2.28 |
| KEG hard | 11.59 | 18.04 | 0.30 | 14.6 | 30.4 | ×2.08 |
| LNES | 10.95 | 14.10 | 0.15 | 12.0 | 20.9 | ×1.74 |

逐条假设：

| ID | 内容 | 裁决 |
|---|---|---|
| R1 | KEG g 曲线比 LNES 陡 2.2–2.8× | **CONFIRMED** |
| R2 | 独立噪声不动点远低于递推稳态（相关误差回声） | **CONFIRMED**（两臂都有） |
| R3 | 可见性删除随状态误差增大 | **CONFIRMED**。val_core vis_frac：GT 0.62 → 6.6 mm 0.54 → 26 mm 0.43 → 50 mm 0.32 → 递推稳态 0.47 |
| R4 | 欠更新 | TF 域拒绝（更新比 0.77–0.93）；闭环域确认（0.069 vs 需要的 0.61 rad，两臂都冻住） |
| R5 | 路由形式是变量 | **REJECTED** |

### 7.5 当前执行序（尚未出数）

**E5.5a `s21_keg_halo`**（config 已写，合同测试已过，训练曾启动）：把 `keep=vis` 换成 deletion-free halo。

- \(w_{\mathrm{geo}}=\exp(-[\mathrm{sdf}]_+/6\,\mathrm{px})\)
- 轮廓外事件沿法向投影到最近轮廓段读 LBS
- 路由质量恒 1：\(w_{\mathrm{geo}}\) 给表面关节，\(1-w_{\mathrm{geo}}\) 给 BG
- 内侧事件与硬门版逐位一致（单变量 = 被删那一半证据的去向）

Gate：G-a 单步不超过 11.59+1.1；G-b 26 mm 处斜率 < 0.20；G-c 放大 ≤×2.10 或递推 ≤ 21.9 mm。

**E5.5b unroll / scheduled sampling**（已排期，未实现）：打两臂共享的曝光偏差。算术上限已知：只修回声 → KEG 落回 ~14.3 mm；只修表示 → 残留 ×1.74–×2.28 回声。若 G-b 过而 G-c 不过，直接叠加；若 G-b 不过，halo 押注被单变量否证。

## 9. 方法学教训（比任何单次涨点更值钱）

1. **先拆单步与闭环。** `run_closed_loop_probe.py` 应在归咎表示之前运行。KEG 若只看递推 30 mm 会去加前端容量，而单步已经打平。
2. **推理期消融 > 两次训练之差。** KSGN 清零头 +0.16 mm；渲染通道置零测的是依赖不是必要性。
3. **best-of-N 不是期望性能。** 19.26 是 4 点最小值，分布中心 20.6 mm。主张用池化或 worse-of-two。
4. **λ 必须和目标归一化一起报告。** SPA 重建时 aux 按 stride-8 归一化导致 2044× 失衡。
5. **未知 config 键必须报错。** 否则会出现“config 层消融、代码层静默失效”。
6. **短窗必须看绝对误差。** RA 看不见飞走的根；非有限状态或平移出 10 m 捕获体要记 `n_diverged_runs`，不能让 NaN 变成缺格。
7. **对照被扭曲时，单变量结论不能外推。** semsil 在 MSE 上有利、在 SO3FK 上有害；只做后者会错误关闭输入语义。
8. **Oracle 必须配同速率随机对照。** S7 真正成立的是 −1.38 mm vs 随机，不是 vs δ-trust。
9. **连续性要在闭环误差尺度上测。** ε-Lipschitz 买不到 1 cm 稳定性。
10. **训练噪声是为稠密臂设的。** 状态条件前端的 12 个几何通道全在上一预测上读取，对条件误差更敏感；独立高斯到不了模型自己注入的误差方向。

## 10. 当前可信结论 vs 明确不主张

### 可以写进内部结论（已在本机测过）

- PCA 不是瓶颈；纯开环增量不可用；render-and-compare + delta 是稠密闭环的必要结构。
- 旧协议 19.26 被 `zgz_local` 支配；跨主体泛化本身很好。
- 域随机化是目前最大的精度修复（旧协议 12.77；新协议 Track+domrand 16.64/17.74）。
- δ-trust 是 rank-1 的信息收缩，50 ms 上几乎吃掉 oracle 上界。
- 加性语义图头在本配方下惰性。
- KEG 作为窗内估计器与 LNES 打平；递推缺口来自状态条件前端的敏感度 + 曝光偏差，不是单步容量。
- 像素图、硬可见性门、软化路由三条失败机制都有测量支撑。

### 明确不主张

- 任何毫米级超过 **同增强稠密基线** 的 SOTA（旧协议对照是 12.77，新协议对照是 16.64/17.74，不是 19.26）。
- RDOR / 主动估计在 50 ms 上的精度收益。
- 异步推理延迟（没有异步运行时）。
- 与 EvHandPose / Ev2Hands 等跨数据集、跨协议并表。
- halo 或 unroll 已经有效（训练未完成或未实现）。
- “换成 GNN/原始事件就一定涨点”。

## 11. 下一步（只允许这些变量）

按主方案 2026-08-24 第三次修订的执行序：

1. **等 E5.5a halo 出数**，按 G-a/b/c 单变量裁决。不得同时改路由形式、损失、窗口或噪声表。
2. **仅当 G-b 过、G-c 不过时**，上 E5.5b 短闭环 unroll。
3. **若 G-b 不过**：halo 押注失败，表示层“证据不删除”被否证；不要加迭代次数或更大图。
4. 任何新模型必须：同一 domrand、同一划分、≥2 seed、固定网格、递推选点；精度主张对照 Track+domrand，不对照 19.26。
5. 主动估计（RDOR/S12/S13）只在短窗上判，且必须赢 δ-trust，不是赢随机跳过。

Kill rules（违反即停，不改成更大网络）：

- 因果图过不了线性内存 / 高事件率 p95 → 停。
- LBS 路由的 oracle 都不能比 global pooling 改善 active-joint error ≥5% → 停 kinematic GNN。
- GNN 不优于 matched-parameter shared MLP → 删 GNN，留 router+MLP。
- 证据阻尼只救异常低事件率、损害 normal bucket >2% → 回退。
- 增量运行时与同步前缀不等价 → 不能写 asynchronous inference。
- 只超过 19.26、不超过同增强控制 → 不能写 accuracy SOTA。

## 14. 一页纸结论

1. **机制：** 事件手部 tracking 成立的最小结构是「上一状态几何反馈 + delta 输出 + 零事件恒等」，不是纯绝对回归，更不是纯开环积分。
2. **数据：** 旧指标被一条低事件率序列支配；域随机化是目前唯一大幅过门槛的精度修复。新论文的稠密对照是 Track+domrand（val_core 16.64/17.74），不是 19.26。
3. **网络侧加法头、可学习门、任务空间损失、匹配噪声、独立语义通道，在本配方下都没过门槛。** 惰性头要用同 ckpt 消融抓，不要用两次训练之差。
4. **稀疏前端 KEG 在窗内已经够用；不够用的是闭环。** 软路由已否证。当前只打两个点：可见性硬门（halo）和曝光偏差（unroll），按门顺序执行，不许并行堆模块。
5. **50 ms 上的逐关节路由几乎没有超出 δ-trust 的空间**；主动估计若要成立，必须去短窗，并同时报告绝对误差与发散率。
