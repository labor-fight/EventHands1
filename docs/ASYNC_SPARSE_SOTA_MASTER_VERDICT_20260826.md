# 异步稀疏迁移与 SOTA 可达性:最终裁决与主方案(2026-08-26)

> 本文回答一个问题:**"迁移到异步稀疏网络(AEGNN 族)的方案,是不是无论如何也实现不了 SOTA?是否必须要有之前的绝对姿态?"**
> 结论先行:**必须保留"上一时刻绝对状态"这个递推载体(三层实证+第一性原理都封死了无状态路线),但 SOTA 的决定量不是"有没有绝对姿态",而是 (单步偏置 b, 保持率 G) 前沿。稀疏前端死在 G=0.58–0.82,不是死在缺锚。方案不是不可行,而是必须换靶:把 G 当作一等设计目标,把状态条件从"证据编码层"挪到"读出层"。**
>
> 证据边界:本仓库 `docs/` 全部实验记录(截至 2026-08-26 15:43 的 `model/model.py`)、`outputs/semkine/*.json` 探针产物、两个本地 skill(creative-thinking-for-research、research-opportunity-graph)及其 Event4D 踩坑账本、以及 2026-08-26 的外部检索(检索词与命中见 §7)。凡标 `[reported]` 的外部结论未独立复验。

## 0. 对核心问题的完整回答

### 0.1 "必须要有之前的绝对姿态"——是,且已被三层独立证据封死

| 证据层 | 测量 | 出处 |
|---|---|---|
| 开环积分 | 纯 `prev+Δ` 无几何反馈:递推 RA **93.38 mm**,平移 65 s 积到 5554 mm | `experiment_history` §Track(Δ) |
| 绝对回归上限 | 纯绝对(G=0):19.32/19.08 mm,jitter 7.40;**递推(带 prev)16.64 mm 更好** | S1 八臂 + fusion 扫描 |
| 可辨识性 | 单目事件-剪影目标函数与关节误差相关 **ρ=0.167**;按目标函数选点(22.29)比不动(21.27)更差 | `objective_identifiability.json` |

第一性原理表述:事件是对数亮度的**时间差分测量** \(\Delta L(\mathbf u,t)\approx\nabla L\cdot\mathbf v\,\Delta t\),绝对位形只以两种方式可观测——(i) 运动轮廓的空间构型(单窗绝对回归,本数据上限 ~19 mm,且 ρ=0.167 证明**不能**迭代精化),(ii) 通过时间积分继承(必须有递推状态,否则漂移无界)。所以**绝对信息必须由一个跨时刻的状态承载**。你的冻结闭环合同(prev 51D + 几何反馈 + Δ 输出 + 零事件恒等)就是这个载体的已验证形式;DAGr(Nature 2024)在检测任务上用"帧提供绝对上下文 + 事件异步更新"证明的是同一条结构定律,我们的递推状态起的就是它那张帧的作用。

### 0.2 "无论如何实现不了 SOTA"——错,但活路只剩一条,且与直觉相反

跨 11 checkpoint × 2 seed 的测量(`bias_gain_frontier*.json`)已确立:

\[
\text{递推 RA}\;\approx\;\frac{b}{1-G_{\mathrm{rand}}},\qquad
\text{预测/实测}\in[0.85,1.23]\ (n=11)
\]

- Spearman(G, 递推) = **+0.929 / +1.000**(两 seed);
- Spearman(单步偏置, 递推) = **−0.607 / −1.000**——**单步精度越好,跟踪越差**;
- G 跨配方 0.215–0.693(3 倍),跨 seed 差 ≤0.05:**G 是配方的稳定属性,可独立控制,且从未被当目标优化过**。

KEG/halo 的失败完全被这条定律解释:单步 11.6 vs 10.95(打平),G 0.58 vs 0.37(差一倍),递推 27.8 vs 20.9。四个候选方案(DAKM/CT-KineFlow/NeuMANO-FG/unroll)全部 NO-GO 的根因相同:都在给 ρ=0.167 的测量加结构,或在 2.83 mm 的项上建模,没有一个动 G。

**所以答案是:稀疏迁移可以 SOTA,当且仅当同时满足** (a) 保留递推绝对状态(不可谈判),(b) 把稀疏前端的 G 从 0.58 压到 ≤0.25 而单步偏置不涨破 ~12.6 mm(此时闭式预测 ≈ 12.1/0.75 ≈ 16.1 mm < 16.64),(c) 精度主张对照 `s1_track_domrand` 16.64/17.67,不对照任何历史数字。

### 0.3 为什么"绝对锚/融合"不是那条活路

- 撞车:direct+delta 可学习 Kalman 融合是 E-3DPSM(CVPR 2026, arXiv 2604.08543)的核心贡献 `[reported]`,我们的 α 融合是其稳态标量特例(`POSITIONING_VS_E3DPSM.md` §1);
- 不需要:最优融合(18.75/17.21)已被无锚的 `s1_track_domrand`(16.64)打败;
- 有代价:等预算对照证明锚的收益来自"持续稀释 G"而非"偶发救火",且 jitter 恶化 2–3 倍。

锚是**推理端稀释 G**;我们的主线是**训练端做小 G**。同一个病,不同的干预点,机制不重叠——这就是与 E-3DPSM 的切分线。

## 3. 闭环误差动力学:完整推导(论文理论章的骨架)

### 3.1 记号与测量模型

状态 \(x=[\mathbf t\in\mathbb R^3,\ \omega_0\in\mathfrak{so}(3),\ \omega_{1:15}\in\mathbb R^{45}]\),误差度量取根对齐关节空间(探针与正则必须同度量,S014 教训):
\(\|e\|_J := \mathrm{mean}_j\|J_j(\hat x)-J_j(x^*)\|_2\),\(J=\) MANO FK。

跟踪器 \( \hat x_k = f(\hat x_{k-1},\ E_k)\),其中 \(E_k\) 是第 k 个事件包。

### 3.2 一步误差分解与稳态

对真值轨迹线性化,定义:

\[
b:=\mathbb E\big[\|f(x^*_{k-1},E_k)-x^*_k\|_J\big]
\quad(\text{单步偏置,TF 测得}),\qquad
G:=\mathbb E_{\delta}\Big[\frac{\|f(x+\delta,E)-f(x,E)\|_J}{\|\delta\|_J}\Big]
\]

误差递推 \(e_k \approx G\,e_{k-1} + b_k\)。两种噪声结构给出不同稳态:

- **白噪声** \(b_k\) i.i.d.:\(\ \mathbb E\|e_\infty\|^2=\sigma_b^2/(1-G^2)\) ——这是"独立噪声不动点"(实测 KEG 14.3 / LNES 12.0 mm);
- **相关偏置** \(b_k\approx b\)(实测步间自相关 0.91):\(\ e_\infty=b/(1-G)\) ——几何级数全额兑现。

实测递推稳态(27.8/20.9)与两个理论值的比值就是"回声超额"(×1.7–2.3):**回路里跑的是相关偏置,不是白噪声**。这同时解释了为什么 δ-trust(收缩输出,只压噪声)只值 0.4 mm,为什么独立高斯噪声训练覆盖不到自误差方向(\(G_{\text{self}}>G_{\text{rand}}\),KEG 0.75 vs 0.58)。

### 3.3 训练目标:约束优化形式

\[
\min_\theta\ b(\theta)\quad \text{s.t.}\quad G(\theta)\le\gamma
\qquad\Longleftrightarrow\qquad
\mathcal L=\mathcal L_{\text{task}}+\lambda\,\mathbb E_\delta\Big[\frac{\|f(x+\delta,E)-f(x,E)\|_J^2}{\|\delta\|_J^2}\Big]
\]

即 `TRACK.GAIN_REG_W`(已实现)。三个不可省略的实现合同(每条都有一次真实失败背书):
1. **度量必须是根对齐关节空间**(参数空间版在 λ 上完美单调却把关节空间 G 推高到 0.457>基线 0.242——优化了与漂移近乎正交的方向);
2. **扰动前向不得污染 BN running stats**(`_frozen_bn_stats`;污染轮所有 λ 臂 +2~4 mm,损伤跟前向不跟 λ);
3. **两支都保留计算图**(detach f(x) 会退化成单向拉近)。

与已死方案的本质区别:unroll 改**数据分布**(把误差课程稀释掉,实测把 G 从 0.578 推到 0.693);δ-trust 改**输出**;锚改**推理端有效增益**;G-reg 直接改**算子的敏感度**。与 Bishop'95 的联系:prev-噪声课程是隐式各向同性 Jacobian 正则,G-reg 是它的显式、有向(J-空间)、可控(λ→γ)版本。

### 3.4 率不变性:为什么 LTI 聚合是唯一正确的时间骨架

设连续时间收缩率 λ_c,离散一步保持率 \(G(\Delta t)=e^{-\lambda_c\Delta t}\)。跨固定时域 T:
\(G_T=G(\Delta t)^{T/\Delta t}=e^{-\lambda_c T}\) ——**与步长无关**。这要求更新算子对 Δt 的依赖是一致离散化(ZOH:\(A_d=e^{A\Delta t}\)),即对角 LTI + 闭式再离散化(KEG 已采用;S008 实测 KEG 5–50 ms 平坦,LNES 5 ms 发散 4/8)。文献:SSM for Event Cameras(CVPR'24)同一结论(3.3 vs 21+ mAP 率泛化差)。
推论:**只要把 KEG 的不动点做好(压 G),率不变性立刻从"绕着坏不动点转"变成"全速率域 SOTA"**——这是本方案 5–20 ms 主张的存活路径,也是 S20 短窗主张失败的解药。

### 3.5 架构定理(非正式):状态条件的深度决定 G 的下界

把 f 分解为证据编码 Φ 与读出 R:\(f(x,E)=x\oplus R(\Phi(E;x),x)\)。链式法则:

\[
\frac{\partial f}{\partial x}=I+\underbrace{\frac{\partial R}{\partial x}}_{\text{读出层,可正则}}+\underbrace{\frac{\partial R}{\partial\Phi}\frac{\partial\Phi}{\partial x}}_{\text{若编码依赖状态,则不可避免}}
\]

- LNES 臂:\(\partial\Phi/\partial x=0\)(事件图像状态无关),render 通道走比较式路径 → G 由读出层决定,可被噪声课程压到 0.24;
- KEG:12 通道全部 \(\Phi(E;x)\),\(\partial\Phi/\partial x\neq0\) 且承重(S007:置零→86 mm)→ halo 修删除也压不动斜率(S006)。

**设计律:证据编码必须状态无关;状态只允许进入读出/路由,且每个状态条件特征必须配一个状态无关的 fallback。** 这正是 E5.6 的形式化,也是 AEGNN 的正确借法(它的事件图本来就是状态无关的)。

## 5. 主方案(最终形态)

**工作名:LoopGain-Track(或沿用 EventKineGraph 品牌):Contraction-Aware Asynchronous Event Tracking for Monocular Hand Mesh Recovery**

四个贡献,每个都已有(或预注册了)运行时证据形式:

**C1(定律,已有数据)**:事件递推跟踪的 (b,G) 分解与闭式预测 \(e_\infty\approx b/(1-G)\);单步-递推负相关;G 是配方稳定属性。证据:11 臂 × 2 seed 前沿 + 预测律 0.85–1.23。*这是别人没有的证据形式,也解释了 E-3DPSM 融合为何有效(把有效 G 稀释成 (1−α)G)。*

**C2(训练,S24 重跑中)**:根对齐关节空间保持率正则(GAIN_REG),显式化 Bishop'95 意义下 domrand/prev-噪声的隐式 Jacobian 正则,给出可控 (b,G) 前沿。失败模式账本(参数空间度量正交性、BN 污染)本身写进 analysis。**若软约束失败 → 单变量升级为读出层硬收缩参数化(谱归一化,REN 思想)——G 线有两发子弹,不是一发。**

**C3(架构,E5.6 起步)**:状态条件因子分解的异步前端——
- 证据编码:**状态无关**因果局部事件图(AEGNN 借"触及子图更新";禁止像素全图 kNN;16 节点 KEG 作聚合中枢);
- 时间骨架:对角 LTI + 闭式任意步长再离散化(SSM 借"率泛化",EventNet 借"递归+真实时间间隔");
- 读出:halo 无删除路由(SoftRas 式连续可见性,已验证保留)+ 每个状态条件通道配状态无关 fallback(E5.6);
- 证据阻尼:\(g_q=I_q/(I_q+\lambda_q)\)(SAST 只借"按证据分配预算"思想);
- 零事件恒等、prev+Δ、递推 evaluator、domrand 全部不动(tracking 策略 100% 延续)。

**C4(评测协议)**:G 进常规指标;(b,G) 前沿图;5/10/20/50 ms 率-精度曲线 + 发散率 + 绝对误差;MAC/事件;prefix-parity 异步运行时(无它不写 async)。

**明确不做**(全部有负结果或撞车):绝对锚/融合头、软路由、像素 AEGNN、迭代 render-and-compare、CM 推理环、778 顶点在线图、替换式 unroll、可学习保守门、SAST 全模块、SNN/扩散/GN 首版堆叠。
