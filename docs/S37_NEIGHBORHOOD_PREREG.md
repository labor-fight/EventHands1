1. A阶段只读白名单缓存字段 prev/pred/betas/camera_K/end_ms/n_events，重建完整原事件包，核 R0 input/prediction hash 与源身份，保存 tokens/src/p/mask/各图。不得从稀疏 sampled events 重新生成 token。

3. B阶段全预测先封存。原 A 前向与 R0 保存 51D 必须逐位一致；替换为已保存 A 边的前向也必须逐位一致。无 tolerance fallback。各臂 p/mask、路由 a/dist/vid 逐位不变；有限性必须通过。D逐层消息及最终 hidden/pose 支持单列：local 至少半数包 hidden相对最大差>32eps32，或 translation>1e-6m/angle>1e-5rad。若只有内部变化而输出无变化，不能以 D 的任务不退化否定机制。
4. A/B文件封存后才读取 target。NPZ会解码16序列完整128×51字段，仅评分固定64行，如实记录。一次固定评分，不按变化子集改分母。

政策效用失败：停止此checkpoint固定替换，不扫k/W/半径/主体。B与C接近：简单扩大窗口可能足够，不能称exact搜索必要。阳性只准继续有界最小修复Debug与自身闭环核验，不自动正式训练或采纳。阴性不外推到重训后的所有邻域方法。
