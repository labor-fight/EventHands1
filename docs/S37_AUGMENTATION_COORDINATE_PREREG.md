## 2. 增强确实传递了相机和几何变换

`semkine/dataset.py::__getitem__` 对同一个增强参数先变换事件，再把 prev/target 一起送入 `DR.transform_labels`，随后将返回的 K 放入 packet。噪声在几何增强后加入 prev。`model/model.py::forward_packet` 的 routed 路径读取该 packet 的 betas/K；没有发现“只动事件、漏改 K”或两个状态使用不同虚拟相机的实现错误。

`semkine/domrand.py` 的 scale/shift 是纯内参变换。令事件尺度为 s、缩放 a、事件像素平移 d，则 `K'=A K`，其中 `A[0,2]=(1−a)cx+dx/s`、`A[1,2]=(1−a)cy+dy/s`；3D 标签不随这两项改变。roll 则左乘相机 z 轴旋转 Q，并使用 MANO 根枢轴 j0：

`Rg'=Q Rg`，`t'=Q(j0+t)−j0`。

这与 `V=Rg(Vrest−j0)+j0+t` 一致。不能把 t 简化成 Qt。连续像素 roll 与 3D roll 仅在 fx=fy 时完全相同；源码已有 fx/fy 差异的显式残差函数。事件随后取整，故连续投影一致性也不等于整数像素逐位相同。既有 `tests/test_s1_dataset.py` 已覆盖标签投影、相机比例残差、开关恒等和变换同时到达事件/标签；本轮仅审阅这些定义，未重跑。

## 3. 几何正确不意味着轴角坐标连续

roll 后，`transform_labels` 对两帧分别计算 `Log(Q Exp(r))` 的主值。设 `Q=Rz(α)`，增强前两帧为 `Rz(π−α−ε)` 和 `Rz(π−α+ε)`，并选择 ε 大于实现的近 π 分支阈值。增强后旋转相差 2ε，主值坐标却分别为 `(π−ε)ez` 和 `−(π−ε)ez`，坐标增量模长为 `2π−2ε`。

这是解析图册反例，未执行合成实验。当前监督比较最终输出与 target 的加权 51D MSE，网络最终输出是 prev 加总增量；因此近主值切面的等价旋转可以带来很大的坐标目标差。它不证明真实训练 draw 经常跨越该切面，不证明此问题主导 local/global 闭环误差，也不是事件和标签的物理投影错误。增强后的噪声也可能使 prev 离开主值范围，不能把“GT+噪声”视为严格规范坐标保证。

独立审查另指出 `_log_so3` 的极近 π 分支从 `(R+I)/2` 选择正主轴，未使用 skew 确定符号；对 `Rz(−π+ε)` 的极小 ε，可能返回相反主轴。它是微小数值近似问题，与上述跨切面的大坐标跳变不同。没有证据把它提升为当前误差主因，不为它重新训练。

## 5. 两条历史解释需要收窄

**手指残差不能直接当完整轴角规范化。** 旧 `canonical_aa` 对 `out[3:]` 每组三维都做包角；其中手指存储的是 residual，实际 MANO 旋转为 `Exp(residual+hands_mean)`。一般有 `Exp(wrap(residual)+mean) != Exp(residual+mean)`。若未来需要手指规范化，正确的几何合同应作用于 full angle，再减去 mean，而非直接包 residual。

父代理读取旧 C0c JSON 的全部 14 个 model×sequence 记录，`frac_any_finger_aa_gt_pi` 全部为零。因此保存摘要没有显示这次旧运行触发了手指残差包角；不能仅凭函数的通用缺陷宣布旧 root 规范化实验无效或重跑它。此项核验只读既有文本字段，没有重新验证原数组或任意状态的 FK 等价。旧脚本和数值原样保留，不能把它作为任意 51D 状态的通用规范化工具复用。

**CNN 的渲染分支不代表整个 CNN 对包角不变。** JOURNAL 15:40 的早期解释把 CNN 能使用 SO3FK 归因于 prev 经渲染天然不变；实际 `eventhands_track_render51_dr_so3fk_rep2.yaml` 同时启用 `PREVPOS_EMBED`、`PREDICT_DELTA` 和 `PREV_RENDER`，当前 CNN forward 还将原始 prev 输入 MLP 并加回状态。故只能说渲染子路径对等价旋转不变，不能据此证明整个 CNN 不受坐标表示影响。旧实测比较保留，撤回该过强的架构归因。
