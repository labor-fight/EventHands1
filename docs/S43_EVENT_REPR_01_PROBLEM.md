# S43 新事件表示研究 · 01 现状核实与科学问题定位

日期：2026-10-28（Asia/Shanghai）。研究对象：本地仓库 `/data1/lyq/code/mesh/EventHands1` 的当前基线 **S43**（run `s43n_sp`，W50 原始协议、无滤波）。本轮只做现状核实与问题定位：不改主模型、不启动训练、不命名新方法。

> **一句话结论。** S43 是"逐事件写时间面、查询时构造整毫秒 last-LNES、与前态点溅射渲染拼成四通道、整幅稀疏前向、51 维加性更新"的逐帧绝对回归器；代码可证明 LNES 在表示前丢弃了同槽多重触发、首毫秒事件、同毫秒顺序与窗前历史，但项目内已有的全部证据（B-R、REL、A/B 原型、XCL/AGG778/MRF/AURA 等）都**没有**证明这些被丢弃的量在当前数据与评测下有可测的 MANO 任务价值；同时证据一致指向误差主体是新受试者上的逐帧映射偏差、前态几乎不被信任、以及评测（RA 对平移盲、1 ms 插值伪标签、单测试人）测不到的部分。因此新表示的科学问题不是"保留更多时间细节"，而是"在可能错误的前态下，哪些事件证据能改变 MANO 更新的可辨识方向，并能在闭环评测里被测到"。

### 2.2 训练 / 推理之间的差异清单（S 级，均由代码读出）

1. **窗长分布**：训练 30–300 ms 对数均匀；主行评测固定 50 ms；在线 harness 默认 200 ms。三份合同（附录 N 第一编 F05 沿用）。
2. **前态来源与噪声**：训练前态是窗首 GT 加人工噪声（50 % 小、30 % 大、20 % 方向相关）；评测只在每段首加一次小噪声（`sample_init_noise` `eval_track.py:158–164`，5 mm / 0.05 rad / 0.05，`evalx.py:243`），之后全部自身预测。训练从未见过"自身预测的误差分布"（`s43n_spself` 曾试过部署环路前态训练，G3 未过，`#s43-result` §2）。
3. **前态时刻**：训练前态对应窗首 `start`；评测前态是上一步输出，对应 `end−50`，比窗首早 1 ms（F06）。
4. **BN**：训练用活跃位点批统计；推理折叠 running 统计。热像素在稀疏臂训练中被去掉（配置 24 行），`#s43-result` 偏离 5/6 证明稠密线的热像素正则是 S43 与 S39 差距的来源。
5. **数值**：训练 bf16 autocast（配置 69 行），渲染 `RENDER_FP32` 未设；执行器 fp32；G6 证明 50 ms 节拍下闭环 RA 差 ≤ 0.01 mm。
6. **零事件判定**：训练与在线都按 LNES 是否全零（不是 raw N=0）；全部事件落在窗首毫秒的窗会被当作空窗。
7. **增强**：训练有几何 DomRand（旋转 15°、尺度 0.8–1.25 按深度一致模式、平移 14 px、keep 0.25–1）、极性翻转与逐像素极性交换（配置 13–25 行；`_polarity` 469–477）；推理无。
8. **记忆语义**：训练样本没有跨窗历史；在线 SAE 跨窗持续存在但被窗口屏蔽——即在线"有记忆"只是实现形态，网络从未被训练去利用它。
9. **旁路**：在线对象另有逐毫秒计数与可选证据门 / 滤波 / 死区（W50 原始协议全关）；训练不存在这些量。
10. **查询副作用**：在线 `query` 一定提交状态并更新网格缓存（291–292）；同一时刻重复查询不是只读（REL 实现才把 query 与 commit 分开）。

### 3.6 S43 自身的机制签名（`#why-s43-baseline-20261026`，描述，CPU）

- 前态扰动一步保留率：根 0.03–0.09、手指 0.04–0.08、平移 **0.26–0.39**（≤ 20 mm）。S43 对前态平移更依赖，闭环平移误差相对 TF 放大 2.5–3 倍（11–15 → 31–38 mm），RA 对此盲。
- 单步（前态 = GT）− 恒等：训练录制 −0.16 mm，zgz **+4.8 mm**（根 +3.5°、手指 +2.5）；TF → 闭环放大 local 1.3 / global 1.1。
- 误差能量 > 1 s 尺度：local 65–72 %、global 80–87 %；向训练先验收缩（local 根系数 0.29–0.33）。
- zgz 闭环 RA 12.8 / 8.0 ≈ 恒等 4.3 / 2.5 + 单步映射偏差 +4.9 / +4.4 + 环路放大 +3.2 / +0.9。
- 同型旁证（S39，S42 §1 零训练分解，账本 2517–2525）：从完美前态出发的单步 TF（global 6.41 / local 8.65）差于"只保持上一步 GT"（2.43 / 4.35）；根←GT 与手指←GT 后 local 各约 7.5 / 7.7（"各约一半"，不是单一瓶颈）；慢变 : 快变 = 10.0 : 2.7。C1 家族同型：E3 恒等 4.41 / 2.43，C1 15.35、A3F0（全 oracle）8.78（账本 14459）；Q1 在 local 1204 包 0/1204 优于 hold（signed z −64.7 mm）。"在 GT 前态处比什么都不做差"是跨三代结构的共同签名。

## 4. LNES 压缩可能丢失的任务相关信息：四分类与区分实验

### 4.1 从事件生成机制到 MANO 状态辨识（沿用附录 N 第二编 §1 与附录 Q Q.5.1，这里只写本轮用到的最小链）

记像素 u 的 log 亮度 L(u,t)，理想阈值模型下事件 e=(u,t,p) 表示自上次参考以来 ΔL 跨过 ±C。在局部光滑、同一可见材料片、不跨遮挡切换的区间内

> s_p·C ≈ ΔL ≈ −∇L(u)ᵀ·[J_root(s)·Δξ + J_art(s)·Δq]·Δt + ΔL_nuisance，  s_p = 2p − 1，

其中 J_root、J_art 由 MANO FK + 针孔投影（K×0.375，β 外供）给出。由此可以直接读出四件事：

1. **单个事件只约束像面运动在局部亮度梯度方向上的分量**（孔径）；它不含深度、顶点编号、关节编号。关节 / 根 / 深度 / 尺度 / 照明 / 阈值相位的不同组合可给出相同事件集合。
2. **多次触发携带的是累计 |ΔL| 的下界**（n·C），即"沿梯度方向走了多远"的量；last-LNES 只留最近一次，于是把"走了 3d"与"走了 d"写成同一个像素值（附录 N 第二编 §4.1–4.2 的 toy：同 LNES、同逐毫秒全局计数、根终点差 2–2.8 mm，1 mm 级下界）。这是**可证的表示层非单射**，但其在真实数据中的发生率与任务价值尚未测（第二编 §7 明说）。
3. **无事件区间**只有在采集存活、阈值 / 相位已知、可见的条件下才是 |ΔL| < C 的删失约束；掉流、静止、沿等亮度运动、遮挡都给同样的"无事件"。
4. **前态（渲染）提供的是 J 的线性化点与可见性假设**，不是观测；前态错则 J 错，证据会被解释到错误方向——这正是 REL/A 原型试图把"证据写入"与"手态解释"分开的理由。

### 4.4 最重要的疑点与低成本区分实验（本轮只设计，不执行；任何读数前须预注册）

按"若结果为 A 则归 R，若为 B 则归 N/E/M"的可区分性排序。全部 CPU 或零训练，使用冻结 `s43n_sp` 三种子权重与现有 zgz / FIT 数据；凡涉及 zgz 读数，只作一次报告、不选点。

**X1 覆写与同码碰撞的真实发生率（区分 R 是否存在于当前数据）**
- 问题：I1/I2 在 W50 真实窗口里多常见？被覆写的触发与目标更新是否相关？覆写率本身已有一次 zgz 读数（global p50 87 %、local 53.6 %，研究稿 3626），但首毫秒零码的发生率从未统计，覆写率与误差的关系也从未读过。
- 设计：对训练 18 基础录制 + zgz，按评测网格（end = a+49+50k）统计每窗：活跃槽数、总事件数、覆写比例、首毫秒事件比例、"全零图但 N>0" 的包数、每槽计数分布；把每窗按"覆写比例"分箱，读冻结 S43 的 TF 单步误差与闭环误差（`evalx_val_core_last_tf_pert.npz` 含 TF 与 model 两种模式，可直接取）。
- 判读：若覆写比例高的窗 TF / 闭环误差显著更高且与事件总数、运动量无关 → R 候选成立，进入 X2；若无关 → I1 降级为"存在但无任务相关"。注意 E3/TF 对事件保真度不敏感（§4.3 M），主判读用闭环误差。
- 成本：纯 NumPy，< 1 CPU·h。须先定义"显著"（录制级配对区间）。

**X2 受控合成的可辨识方向矩阵（区分 E / R / N）**
- 问题：对一组单变量干预（根 x/y/z 平移、根三轴旋转、各指 MCP/PIP 5–10 mm），raw 计数场、last-LNES、count+first 三种表示在共同有限读出下的候选判别率各是多少？S43 冻结 A4 特征的线性读出又是多少？
- 设计：复用 B-R / witness 的 MANO 二值光度生成器与 null 控制（已存在 `tools/s43_br/synthetic.py`、`tools/s43_revisit/witness_synthetic_diagnosis.py`），固定 β/K/前态/背景；每干预 ≥ 30 上下文；三表示同 RBF 读出。消融轴沿用 K★ KS2 已登记的时间面变体（全窗 / 只留 ≥ 50 ms 前 / 只留近 50 ms / 时间戳置乱 / 逐像素极性互换 / 全局翻转）与研究稿 4190 从未执行的 E19-A（冻结特征 vs 平凡直方图 vs CNN 倒数层）。
- 判读：raw ≈ LNES ≈ 低 → E；raw 高、LNES 低 → R；LNES 高、S43 特征低 → N。与 §4.3 的 null 对结果联读。R 的判定必须同时包含附录 P 反复要求的最强等价基线：逐像素 count、TORE-K、HATS / EST + 同一读出；只赢 last-LNES 而不赢这些，不构成"时间必要性"。
- 成本：CPU，数小时；已有工具，不需新网络。限定：二值光度模型，结论只约束该生成器。

**X3 冻结 S43 的"事件灵敏度 / 前态灵敏度"谱（区分 N）**
- 问题：输出对 LNES 扰动（删最近一毫秒 / 删最早十毫秒 / 随机删 50 %）与对前态扰动的灵敏度，按根旋转 / 平移 / 各指分列，是否与 E3 一步保留率（0.03–0.09）和 S44 P0.3（平移由渲染路承担）一致？
- 设计：zgz + 两条 FIT 录制各 200 包，零训练前向；读 Δ 输出的范数与方向余弦。
- 判读：若删早期事件几乎不改变输出而删最近一毫秒改变很大 → 网络只读"最新边缘位置"，I1/I4 即使保留也不会被此读出利用（N）；若两者都小 → 输出主要由渲染路决定。
- 成本：GPU 分钟级或 CPU 小时级，零训练。

**X4 评测盲区重评（区分 M）**
- 问题：同一批已存预测（三种子 `evalx_val_core_last_tf_pert.npz`）在 absolute / root-only / 关节腕点对齐 / 运动分层（已登记的 GT 事后掩码）下，S43 与 S39-栈 S43 的差异是否改变符号？
- 设计：只读 npz 重打分；不新推理。
- 判读：若 RA 的 1 mm 口径差在绝对 / 分层口径下变号或消失 → 后续新表示的门必须同时报两类口径；否则 RA 可继续作主门。
- 成本：< 0.5 CPU·h。

**X5 窗长 × 滤波的隔离（区分 I4 是 R 还是 N）**
- 问题：S43 从 W50 raw（10.24）到 S39 栈（9.21）的 1 mm 里，窗长 200 ms 本身占多少？S39 前身上已知答案是约三分之二（W200 裸 −0.98，滤波再 −0.5，账本 2077–2106），S43 未测。
- 设计：`evalx.py eval --window-ms 200`（无滤波、无门）对三种子一次性读数，与 W50 raw、S39 栈并列；另加 W100；同时报绝对 MPJPE 与手指 / 根速度比（S39 上 W200 的代价是绝对 +6.4 mm、local 根速度比 0.90 → 0.61）。
- 判读：若 W200 无滤波已接近 9.21 且速度比同样下降 → 与 S39 同型，窗前历史的"收益"是输出平滑而非新证据（I4 归 N）；若 RA 不降 → S43 的稀疏主干对长窗无感；若 RA 降而速度比不降 → 才是 R 候选。
- 成本：GPU 分钟级；是 zgz 读数，须预注册并一次报告。

> 未列入的：直接训练新表示（超出本轮）；读取项目外原始 AEDAT（U 类来源闭合，需用户决定）；EvRealHands（只作最终测试，不得用于定位）。

## 5. 核心科学问题与假设

### 5.1 核心科学问题

> **在固定 β/K、可部署（可能错误）前态与因果查询合同下，单目事件流中有哪一类被 last-LNES 的整毫秒覆写、固定窗截断与"查询即整幅重算"丢弃或掩盖的证据，能够在新受试者上改变 MANO 更新的可辨识方向（而不是更准地重现训练先验），并且这种改变在闭环评测中可测？**

它把"新表示应保留什么"（可辨识方向上的证据）、"为什么现有表示不足"（覆写 / 截断 / 前态污染 / 读出接口 / 评测盲区各占多少）和"怎样验证"（新受试者、闭环、绝对 + RA 双口径、null 控制）绑在一个可证伪命题里。它与附录 J 第三编的主缺口 G1（MANO 目标条件下的证据保留边界：所求 S 满足 p(Y_Q｜S,c) ≈ p(Y_Q｜E,c) 而非保住全部历史区别）、附录 N 第十二编 12.2 与附录 Q Q.6 P1 收敛的问题一致；本文的增量是把"新受试者上的映射偏差"（§3.6）写进命题，因为这是目前最硬的证据所指的位置。

### 5.2 至多三个值得继续研究的假设（均可证伪，附否证条件）

**H1（表示层：证据等价类假设）。** 在 50 ms 查询尺度上，last-LNES 相对原生计数场对 MANO 目标条件分布近似充分；新表示的收益不会来自更细的时间分辨率或更多通道，而只可能来自 (a) 保留与前态无关的证据以便前态更正后重解释，(b) 保留"证据是否覆盖该关节方向"的支持量以抑制无依据纠偏。
- 支持：REL enhanced 无增益；B-R E1 时间破坏不降；P2 enhanced 对 lnes 差 ≤ 0.26 mm；DT2 `lf` tie；Q1 强时间破坏控制 local 无净纠错；S44 P0.5 查询加密反而退化。反向线索（保留）：研究稿 3426–3436 的推导指出"时间盲池化只得 δξ + (T/W)·ξ̇"，可加的包内一阶时间矩才能分开位置偏差与包内运动（只有合成数值）；XVM P4 显示多时间尺度时间面 patch 随记忆变长受益。
- 否证：X1 显示高覆写窗闭环误差显著更高，或 Stage 5 `field_box`（同预算完整计数场）对 `s43` 在 zgz 闭环 RA 与绝对误差上同时改善 ≥ 种子 SD（0.38 / 0.26）且方向一致 → H1 的 (a)(b) 之外的时间结构确有价值，回到 I1 作表示设计（候选量：逐槽计数与一阶时间矩，而非更多 bin）。
- 若成立的含义：表示设计的自由度应用于"前态无关 + 支持量"，不是通道数。
- 继承的判读纪律（附录 O/P）：(a) 的"前态无关 + 重解释"是接口性质，同核重读恒等式本身不是纠错能力也不是创新；(b) 的支持量不是 Fisher / 后验 / 置信，λ 随事件率虚增；两者的收益都只能由闭环任务读数证明。

**H2（接口层：前态污染与事件盲先验假设）。** S43 在新受试者上的单步偏差（+4.8 mm）主要由两条事件盲 / 前态耦合路径产生：渲染路承担平移（输出变化比 7–16）与 prev_mlp 的事件盲拉力；而事件路因 mask 外硬零、首毫秒零码、极性增强抹方向等接口限制，只能表达"最新边缘位置"。一个把事件证据与手态解释分离、并显式输出"该方向有无证据"的表示，其收益应首先出现在**绝对 / 根误差与错误前态恢复**上，而不是 RA。
- 支持：S44 P0.3；REL 方向 f 的绝对位置条件价值；Stage3 R1 的虚假纠偏归因；XDG 去 t 后 local 偏置消失但纠回弱；S41 P0-a 关节锚定采样在大前态误差下比 GAP 差（15.4° 对 8.6°）；"观测是相对 prev 的量"——oracle 关联在闭环里崩（§3.5）；XVM PI 在部署锚点上过度自信（§3.4）。
- 否证：X3 显示事件路对早期事件与最近事件同样敏感且平移主要由事件路决定；或 REL/A 类接口在 X4 的绝对口径下也无方向一致的改善。
- 若成立的含义：新表示的"任务必要性"证明必须含错误前态下的恢复与绝对误差门，RA 非劣只是护栏。

**H3（评测层：可辨识性与测量假设）。** 相当一部分关节更新在单目事件下本就不可辨识或不在标签带宽内（null 对、孔径、遮挡、60 Hz 源插值），现评测（RA、单测试人、50 ms 端点、E3 体制）把剩余可辨识部分的差异压到种子噪声以下；新表示若有价值，只会在"可辨识方向上的条件风险"和"绝对 + 分层 + 闭环"口径下显现。
- 支持：MDE 1.15 / 0.79 vs 效应 0.3–0.5 mm；RA 对平移盲；A2 标签功率与 40–50 % 高频标签成分；null 对反例；S44 P0.5；E3 体制对删 90 % 事件不敏感；GT 姿态钳位抹平递推差；"失败账本里没有一条负结果同时满足单变量 + 完整预算 + ≥ 3 种子 + 匹配对照 + 无 oracle"（账本 5805、5985–5990）。
- 否证：X4 重打分显示各口径符号一致且差异远大于种子 SD → 评测不是掩盖因素，H3 降级。
- 若成立的含义：下一轮（02）必须先建立可检出已知证据破坏的正对照与双口径门，再谈表示。

### 5.3 不进入假设清单的方向（本轮证据已足够排除优先级）

- "更多 778 顶点聚合 / 更大消息传播感受野"：AGG778、MRF 已证在 C1 上无杠杆；S44 P0.4 在 S43 上无改善。
- "改关联规则"：XA、AURA 已证次要；任务信息主要在占据。
- "亚毫秒时间戳"：来源 U、SRCA/OBS-A/A2 都指向无独立高频信息；先闭合来源再谈。
- "异步作为精度杠杆"：G6 等价成立但 h10 退化；异步的价值在延迟 / 内存 / 调度，需另立服务口径（附录 Q P3）。
