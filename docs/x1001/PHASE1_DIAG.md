## 2. 路由证据（单列，不进入普通推理结论，冷启动一行除外）

根旋转（MLP，全部，度）：冷启动闭环路由（无 GT）11.81 / 11.50；协议 GT 初始化闭环 11.76 / 11.68；GT prev 路由（oracle）8.10 / 7.85（s3407 / s3408 选中）。
- 冷启动与 GT 初始化几乎相同：路由特征的信息量不依赖 GT 初始化。
- 普通推理下，路由证据比无 prev 池化好约 1.6–1.9°，仍比 CNN 差约 2.4°。
- GT 路由比 CNN 还好，但这是路由把真实姿态写进了分组，不能作为编码器能力的证据。

## 4. 有效时间感受野与空间覆盖

- 结构时间感受野（S37 三跳祖先的中位时间跨度）：global 1.86 ms、local 5.45 ms；50 ms 窗口里每个节点只"看见"几毫秒。
- 5 ms 切片遮挡（每 4 个开发包取 1 个，共 10 个切片）：
  - CNN：遮挡最新切片使解码根旋转变化 1.1–2.2°，最旧切片 0.06–0.18°；90% 敏感度落在最近 35–40 ms 内（新近加权，与 LNES 记录最新时间戳一致）。
  - S37 无 prev 特征：任一切片被遮挡，解码根旋转平均变化约 6°（global）/ 2.5–3.7°（local），各切片几乎一样。
    这不是"用满了整个窗口"，而是**表示对重采样不稳定**：时间等步长抽样下，少一片事件会让全部 2048 个节点重排。
- 空间覆盖：时间等步长抽样只覆盖 dense 包事件所在 4 px 格子的 73%（global）；稀疏包为 100%。

## 5. 结论与下一步（按用户规则）

- 特征不足 → 先补 **E7**（同编码器绝对姿态，管线对照，不冒充单变量），再单独测 **E9**（空间均匀采样）与 **E8**（因果邻域）。
- E8 的邻域规则只按与权重无关的几何量选定（`diag/e8_geometry.json`）：整包因果 kNN、时间权重 0.1，
  三跳中位时间跨度 global 1.87 → 21.4 ms、local 2.09 → 14.8 ms，三跳半径 43 → 15 px（所试规则中最紧凑），
  邻居搜索 13 → 244 ms / 512 包；训练后再用遮挡法复测有效时间感受野。W256（6.5 / 4.7 ms）扩展不足，不选。
- 不外推：§16 的"离线最优常数滤波收益约 0.6–1.2 mm"只约束常数增益滤波，不能当作所有门控 / unroll 的收益上界。
