# NF1：法向信息必要性审查（未启动数值实验）

2026-09-25。此文件登记解析推导、实际代码与原文核查的终态；不是事后把拟合结果追认为预注册。本轮没有 NF1 数值分数、训练臂或新架构主行。当前仍采用 `s37_routed`，完整研究目标未达成。

## 1. 本轮改变了哪些决策依据

此前“法向流只能约束速度，所以绝不可能纠正姿态偏置”的普遍否定不成立。固定相机、形状、材料关联与测量条件下，未知速度消元后的有限姿态问题是

`D(q)=min_v ||W^(1/2)(z−A(q)v)||²`。

不同姿态若产生相同运动场列空间，可由未知速度完全吸收；列空间不同也只意味着可能产生条件姿态约束。`AᵀWA`是速度块，不能当姿态信息。零残差局部姿态块需先投影掉速度列空间；非零残差含额外导数项。零一阶秩仍可能保留高阶的弱区分，正一阶秩也可能留全局多解。速度ridge可制造纯先验的姿态偏好，优化器失败不证明物理不可行。

关联必须同时满足成像和材料语义。物理速度对固定材料点求导；候选姿态变化的敏感度还需考虑合法重关联。若沿始终命中固定像素的点求投影导数，会因投影恒等而得到零，不代表材料不动。ray-hit 已约束的重心自由度也不能再次无条件作为自由 nuisance 消去。

这些推导缩小了后续可成立的主张，但没有给S37带来新的测量、纠偏效果或性能证据。

## 2. 否决当前 forecast 认证变体

本轮讨论过严格过去的 native SAE 平面，再用未参加拟合的未来像素触发时刻评价。该变体当前 **DEFERRED**：最近触发面不确定下一事件属于哪条边或周期，未来无事件存在删失，不能事后仅保留预测落在未来窗的样本。

还有一个无需数值生成的物理反例：静止物体与相机、共同对数亮度ramp，以及合法固定空间初相，可以产生非零斜率的触发时间平面；留出像素预测和时间错配控制都可能符合期望，物体仍不运动。因此这些检验不能独立认证物体法向方向。该反例不说明真实数据就是照明伪运动，也不否定所有事件方法。

现有毫秒pose标签来自PCHIP/RotationSpline的MANO参数插值。其投影速度可作条件几何参考，不能直接认证事件的亮度边材料对应或真实像素光流。原H标签及评测保持，没有以此诊断数据失效或重启GT平滑。

**暂缓仅针对这个物理方向认证/profile前提，不是所有NF经验研究的禁令。** 合法train-only姿态标签可以评价另行冻结特征的任务增量价值，缺独立flow GT本身不禁止这类实验；但阳性也不能称物理法向已认证，仍需独立必要性理由、样本/容量/历史条件公平控制及明确停止门，不能变成固定R0的加头或超参重试。本轮没有把这一未来可能性写成已经准入或已运行的实验。

## 3. TEGBP 补齐了一个直接近邻缺口

本轮补读 [TEGBP，CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Nagata_Tangentially_Elongated_Gaussian_Belief_Propagation_for_Event-Based_Incremental_Optical_Flow_CVPR_2023_paper.html)：法向的切向宽不确定性、空间运动先验和局部belief propagation已有直接方法。有限切向精度有先验来源；其环图方差没有一般保证。主文、MATLAB精度实验、C++演示及法向提取是不同执行边界，不能把作者flow核心时间当本项目原始事件到mesh时延。

父方另静态核对了官方冻结commit中Huber局部变量shadow及默认full模式的预计算法向输入。它们是该源码版本事实，不否定作者MATLAB实验，也不构成本项目需要修复外部代码的任务。未安装、编译或执行作者代码。

对S37的含义是：仅把上述不确定性或传播换成MANO token/attention，不足以证明创新。真正未闭合的仍是自身历史误差下的有效增量信息，以及同一策略的完整计算和精度证据。只新增一个原文方法族，补充材料和演示没有另计论文。
