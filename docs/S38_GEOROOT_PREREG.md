## 0. 要回答的问题与依据

S37 最大的旋转误差是改变深度的像面外旋转，而它的证据通路看不见这个方向：

- 上午的 root 探针（`.experiments/root_inplane_20260924/`，GT 状态上注入受控 root 误差、事件固定）：root 头自身（证据通路）对像面外旋转
  rot_x / rot_y 的修正增益 −0.00–0.06，对根深度 t_z 0.03–0.07（像面内 rot_z 0.10–0.18，横向 t_x / t_y 0.30–0.70）；从 root 头的完整输入
  线性解码这三类误差的留出 R² ≤ 0.08。表面上 0.4–0.8 的总修正几乎全部来自 `prev_mlp`（rot_x / rot_y 0.53–0.67，t_z 0.33–0.77），即向训练分布回拉的先验。
- 闭环里像面外旋转 p50 8.1–8.9°，像面内 3.8–6.2°；只把像面外旋转误差施加到 GT 上就有 11.4–14.7 mm RA（像面内 9.0–11.3）。
  上午的 oracle：去掉像面外误差，zgz_local −3.5 / −5.4 mm；根深度 oracle 大幅改善 abs（3408：global 75.4 → 21.1，local 89.1 → 40.3 mm），RA 不动。
- 可观测性（`.experiments/depth_lift_20260924/geom.json`，扣除其余五个 root 自由度后的独有 RMS 像素位移）：像面外 0.10–0.12 px/°，深度 0.022–0.042 px/mm。
  8–9° 的像面外误差约 1 px，70 mm 深度误差约 1.5–3 px；每包有上千个轮廓附近的事件。
- 像面外旋转在图像上只通过轮廓点相对腕的深度起伏（杠杆臂的 z 分量）和透视项表现出来，所以把它从 2D 事件里读出来，需要 prev 网格的 3D 点和深度。
- 09-20 的 S38a / S38b 把 3D 几何以加性特征给网络：S38a 先验回灌（放大率 4.26），S38b 旋转不改善。几何只能乘证据进入（该文 §9"留给后续的单变量"第 2 条）。

**假设**：把 prev（或预测）的 3D 轮廓点放进事件残差的投影雅可比里，显式求解 root 修正，可以恢复 S37 证据通路看不见的像面外旋转和根深度；
把这个修正作为推理期的一步加在 S37 输出之后，改善闭环。

## 1. 设计（`semkine/geo_root.py`，纯函数，第 0 步与第 1 步共用同一实现）

对一个状态（51D）及一包事件：

1. **遮挡轮廓**：MANO FK 得到 778 顶点（相机系，米）。可见轮廓边 = 一侧相邻面朝向相机、另一侧背向相机的网格边（腕部开口的边界边不算），
   且边中点投影像素的射线第一交点不比该中点近 5 mm 以上（即没被别的部位挡住；射线求交是 1538 个三角面的精确求交）。
   每条边的外法向 = 投影线段的法向，指向远离朝向相机那一侧面的投影质心。
2. **关联与残差**：每个事件取最近的投影轮廓线段（点到线段距离），`|s| ≤ 10 px` 才参与；残差是沿外法向的有符号距离 `s_i = n_iᵀ(u_i − p_i)`，
   `p_i` 是线段上的最近点，对应的 3D 点 `X_i` 按同一参数在两端点间插值。
3. **深度感知雅可比**：root 修正 `ξ = (ω, v)` 是相机系下绕腕关节 `c`（MANO 关节 0）的旋转与平移，
   `∂u/∂ξ = ∂π/∂X(X_i) · [−[X_i − c]ₓ | I]`，`∂π/∂X = (1/z_i)[[f_x, 0, −f_x x_i/z_i], [0, f_y, −f_y y_i/z_i]]`，行 `a_i = n_iᵀ ∂u/∂ξ`（1×6）。
   深度 `z_i` 和杠杆臂的 z 分量只出现在这里，与未知的修正相乘。
4. **求解**：IRLS（Huber，δ = 1.5 px，3 轮），Marquardt 阻尼 `ξ = (AᵀWA + ρ·diag(AᵀWA))⁻¹AᵀWs`，ρ = 0.1；参与事件 < 64 时 `ξ = 0`。
   高斯—牛顿迭代 8 次（用更新后的网格重新求轮廓与关联；初稿为 2 次，见 §6 23:50 的修改），各次修正按"绕同一腕点"复合。
5. **施加**：`global_orient ← R(ω)·R_g`，`transl ← transl + v`（MANO 的全局旋转绕 J0，平移后即腕关节，所以绕腕旋转不改平移）。

**契约**（`tests/test_s38_georoot.py`）：没有参与事件 → `ξ = 0`；残差全为 0 → `ξ = 0`，与几何无关；只改 root 的 6 个参数；解析雅可比与数值差分一致；
在由已知网格轮廓合成的事件上，从注入的 root 误差出发能把误差减小。

## 2. 第 0 步：零训练信息探针（`.experiments/s38_georoot_20260924/probe_s38_stage0.py`）

**G0a 信息量（与 root 头逐样本配对）**：样本与上午 root 探针的 B 部分完全相同（`default_rng(1)`，每包 4 次抽样，旋转各轴 U(±12°)、平移 x / y U(±15 mm)、
z U(±40 mm)，prev = 包起点 GT；zgz_global 5544 个、zgz_local 4816 个样本；扰动从其缓存 `eps` 读取以保证逐样本一致）。
对每个样本，在扰动后的 prev 上求 `ξ̂(prev + ε)`，在未扰动的 prev 上求 `ξ̂(prev)`，差分 `ξ̂(prev + ε) − ξ̂(prev)` 与注入误差 ε 按 root 探针的
`gain_matrix` 定义求增益（1 = 完全修正，0 = 看不见），并按其 `ridge_r2` 协议（前一半拟合、后一半测试）求 6 维差分到 ε 的留出 R²。
这一步只依赖几何、事件与 GT，与种子无关。

**G0b 闭环方向**：在 S37 两个种子各自的闭环 prev 状态上（`make_s36_row.py` 的 rng 协议重跑闭环、逐位复现主行），求 `ξ̂(prev)`，
与真实所需修正 `c = err6(gt_end, prev)`（相机系旋转 deg、平移 mm，定义同 root 探针）逐自由度计算方向余弦 `Σ ξ̂c / √(Σξ̂² Σc²)`（两条序列合并）。

**门槛（预注册）**：一个自由度"准入"，当且仅当 G0a 在两条序列上增益 ≥ 0.3 且留出 R² ≥ 0.3，并且 G0b 在两个种子上方向余弦 ≥ 0.5。
**第 0 步通过**当且仅当 rot_x、rot_y、t_z 中至少一个准入；否则本思路在信息层面不成立，停止，不做第 1 步。六个自由度都报告并适用同一准入规则。

**预测（运行前）**：rot_z、t_x、t_y 增益 0.7–0.9；rot_x、rot_y 0.3–0.6；t_z 0.4–0.7。G0b：rot_x、rot_y 0.4–0.7，t_z 0.6–0.8。

## 3. 第 1 步：推理期几何修正（只在第 0 步通过时执行）

- **模型选项**（`model/model.py`，默认关，关时与 S37 逐位相同）：`GEO_ROOT_REFINE`、`GEO_ROOT_DOFS`（= 第 0 步准入的自由度）及求解参数（与第 0 步完全相同，不另调）。
  只在推理时生效；在 S37 的输出 `pred` 之后执行。
- **时间（异步）**：包分成 5 个 10 ms 时间片，每个事件与"prev 到 pred 按时间插值的状态"在它所在时间片的轮廓比较（旋转在切空间插值，其余线性插值），
  所有时间片的行合在一起解一个 `ξ`（持久误差模型），只施加准入自由度的分量；单步修正裁剪到第 0 步验证过的范围（旋转 12°、横向 15 mm、深度 40 mm）。
- **契约**：空包仍逐位返回 prev；参与事件 < 64 时逐位返回网络输出；手指 45 维不变。
- **checkpoint 与选点**：`outputs/semkine/s38_georoot_s340{7,8}/` 软链接 S37 的 12 个网格 checkpoint，打开修正后用 `tools/select_checkpoint.py`
  按标准协议选点，`tools/make_s36_row.py --run s38_georoot` 出主行。另报在 S37 选中步（2500 / 5000）上的配对数字与网格中位数。
- **门槛（与账本 §1.2 一致）**：采纳需两种子均值递推 RA ≤ **19.64**（20.74 − 1.1），且每个种子不劣于 S37 同种子（19.23 / 22.26）；|Δ| < 1.1 判打平。
- **次要变体**（同时报告，不参与采纳）：若主变体准入了像面内自由度，另跑只施加 rot_x、rot_y、t_z 中准入者的变体，用于归因"深度感知"本身的贡献。
- **诊断**（写入本文，不进报告表）：闭环像面外旋转 p50、根深度误差 p50、abs 的变化；延迟列包含求解耗时，thop 不计求解的运算，本文另给估计。

## 4. 预注册假设

| 假设 | 测什么 | 判据 |
|---|---|---|
| H1 几何解能看见证据通路看不见的自由度 | G0a 增益与留出 R²，对 root 头（≤ 0.07 / ≤ 0.08） | rot_x、rot_y、t_z 至少一个增益 ≥ 0.3 且 R² ≥ 0.3 |
| H2 在真实闭环状态上方向正确 | G0b 方向余弦 | 准入自由度 ≥ 0.5，两种子 |
| H3 prev 的深度误差只造成增益误差 | G0b 中 `ξ̂` 对 `c` 的回归斜率对比 G0a 增益 | 斜率不低于 G0a 增益的 70%（诊断，不设门） |
