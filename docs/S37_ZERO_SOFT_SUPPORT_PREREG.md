## A：无标签定义与原更新核查

单进程逐文件：核NPZ SHA与原receipt、原receipt的contract SHA与原contract、128行/固定50ms end、shape/dtype/finite、support和coverage非负、n_events非负整数。实际 `support==0` 与 `core[:,:,256]==0` 必须逐元素一致，且零支持时前256证据值全零。最后3维与原prev局部块逐元素完全相等；每包support零数、n_events/end_ms须与原provenance对应，原receipt的总零数也须一致。

原空包要求pred与prev逐元素完全相等；不忽略失败。任一合同失败停止，标签不读取，不修字段/换样本再试。记录全体、空包、非空零支持、非空正支持及其每序列/每关节覆盖，原增量是否非零与平方范数；空包和零更新不从分母消失。所有分组由本段固定，不根据target选择。

## B：固定参数坐标风险，所有原行评价

对原15个3D局部角块，用float64算术计算

`d = pred_j - prev_j`

`L_hold = ||prev_j - target_j||²`

`L_pred = ||pred_j - target_j||²`

`change = L_pred - L_hold`。

正值表示原更新增加该坐标风险，负值表示减小；这里只含局部角三元组，单位rad²，不混入root平移的m²。保存所有行的两个风险、change和原A mask；主汇总为各动作**非空且零软支持**行的加权均值，另列非空正支持、空包、全体，以及固定各主体/各关节分组。任何无行组的均值为null，不填0、不丢弃。报告更新非零、变好/变差/相等计数与完整分母；相邻行相关，不据行数声称独立重复。两动作与各主体分别显示，不能平均掩盖退化。

固定判定：仅当local主组均值>0且global主组均值>=0，记 `PARAMETER_HARM_SIGNAL_ONLY`；否则 `NO_TWO_ACTION_PARAMETER_HARM_SIGNAL`。该判定没有方法采纳含义。即使有signal，也只允许先讨论另一个明确的几何/自身闭环必要性合同；所有情况都不自动启动新模型、保持干预或训练。总体平均符号不能概括每个主体/关节，表中保留相反样本。

存储坐标的欧氏风险不是SO(3)测地距离；轴角的非唯一性和MANO耦合尚在。它对应原51D监督的局部角平方项，但不声称是log-batch损失的精确期望最优准则。改变局部参数可能通过父链/pose blend影响多部位，当前不做这类FK或反事实推断。
