## 2. 对项目判断产生的具体变化

P1 的 count 是 LBS 最大权重赢家的硬计数，而 S37 的均值和覆盖率使用全部软权重。故 hard count=0 不等于 soft support=0。P1 的闭环整块保持失败，不能扩大成所有无软证据保持都失败。另一方面，无软证据时 H_j(0,q_j)+G_j(q) 仍可能更新；这只说明源码存在该路径，尚未证明已训模型的更新有害。

`ablate_joint_heads` 只在 head 内清 H_j，后面仍加 G_j；它不等于完整 finger 保持。P1 覆盖最终块同时压掉 H/G，R1 只从固定历史减掉 G，二者均不是完整材料 Jacobian 投影。R0 存有 soft support，但只保存 per-node 路由的 hash，不能反演 vid 或完整 Jacobian。

真实材料导数含 pose blend、祖先链和 LBS；J_X、J_uv、事件法向约束 gᵀJ_uv 是不同对象。几何敏感度本身没有提供被测位移或纠偏符号。即使线性观测可辨的商空间确定，选具体51D更新仍需度量/先验；限制速度 nuisance 增加的条件信息来自该限制，不能全记为新增事件信息。

新局部静态外观延拓只在理想点采样、共同可见材料、无回访/无交叉、没有相冲突历史外观锚定及纹理带宽约束的合法触发序列下成立。它区别于 M4 的特定全图旋转等价，但不是实际首秒/整手零信息定理，也未保留任意 PSF 的结论。

## 3. 最近邻与恢复约束

[Zhang、Kaess、Singh，ICRA 2016](https://www.cs.cmu.edu/~kaess/pub/Zhang16icra.pdf) §IV-B Eq.15–18 已直接组合可解方向的估计和退化方向的预测；裸谱投影/其余保持不构成新颖性。[Huang、Mourikis、Roumeliotis，IJRR 2010](https://www-users.cse.umn.edu/~stergios/papers/IJRR-Observability-based-rules-consistency-2010.pdf) §V Eq.40–52 维护已知 gauge 的线性化一致性，并不创造事件测量。

ArtICP 的 visible-only 关联恢复反例要求新方案能在错误历史下重新获得支持；它没有证明 S37 已发生同样缺陷。S37 实际用所有顶点的 nearest8、近距+3px 前深度选择和16px带，不是精确渲染可见面的硬筛。不能由此直接重跑 P2、扩大背面连边或宣告支持恢复已解决。
