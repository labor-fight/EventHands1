## 2. 當前臂 S37 路由讀出（`s37_routed`）

檔案：`semkine/event_gnn.py`（事件圖）、`semkine/routed_readout.py`（路由與池化）、`model/model.py`（`forward_packet`、`_decode_active`、`_route_nodes`）、

1. **事件圖（狀態無關）**：每包等距取樣 ≤2048 個事件為節點，7 維 token（x, y, p, t, log 事件間隔, 兩個 SAE 年齡）；因果 k-NN（前 32 個事件中取 k=8），邊特徵 `(dx, dy, dt)`；EdgeConv×3（hidden 128）；mean‖max → 512 維池化 `f`。
2. **路由（只在讀出側、no_grad）**：prev 做 MANO FK → 778 頂點投影；每節點取 8 個最近投影頂點中「與最近者相距 ≤3 px 且 z 最小」者為前表面頂點；距離 ≤16 px 則 `a_i = W_lbs[頂點] ∈ R^16`，否則 0。節點到頂點的偏移在過門後被丟棄。
3. **逐關節證據**：`e_j = [Σ a_ij h_i / Σ a_ij ‖ 硬分派 max ‖ coverage]`，(B,16,257)。
4. **頭**：15 個手指頭各讀 `[e_{k+1}, prev 自身 3 維角]`；root 頭是**單層線性** `nn.Linear(512 + 16×257 → 6)`，**不讀 prev 的根**；加性 `prev_mlp(prev)`（51→64→51，不看事件）；`ZERO_EVENT_GATE`：空包逐位回 prev。
5. 訓練：51 維加權 MSE（`LAMBDA_T 30000, LAMBDA_R 60, LAMBDA_POSE 450`），prev 噪聲課程（50% 小噪聲、30% 大噪聲 σ_t 50 mm/σ_r 0.3 rad/σ_pose 0.3、20% 相關），域隨機化，6000 步，2 卡×512。
6. 主行：RA 20.74（19.23 / 22.26），local 26.41，global 15.82；延遲 7.72 ms，0.827 GMACs，0.73 M 參數。對照基線 EventHands-PCA6（global 10.99）。

## 3. 已測的關鍵診斷（S37 prereg §8–§9，2026-09-28，無訓練）

- **不是在跟蹤運動，而是在逐包重估姿態**：同包迭代 `x ← f(事件_k, x)` 從 GT 或遠起點都收斂到 13–17 mm（global），= 閉環誤差；69 s 內無漂移。TF 單步 RA 是「原地不動」的 2.7–3.4 倍；閉環每步關節位移是真實運動的 1.5–3 倍。
- **最大單因是根旋轉**：閉環每步把根旋轉換成 GT，global 15.66→9.58/6.15，合併 20.74→12.4；換手指只到 15.1。TF（prev=GT）時旋轉誤差 6–8°，而 50 ms 真實轉動只有 1.6–3.0°；更新方向與所需方向餘弦 0.05–0.11；與事件數、運動量無關（固定噪聲底）。
- **機制**：`Δr = F(事件; a(prev)) + G(prev)` 可加可分；`G = prev_mlp` 的根斜率 −0.24…−0.64 ≈ 課程噪聲下的 Wiener 收縮係數（往訓練均值拉，不看事件）；事件只貢獻 0.01–0.20 的糾正增益。可加可分的形式只能表示**常數增益**，無法隨「prev 與事件的分歧」變化。
- **資訊探針**（§9.2，單包、固定 S37 特徵上擬合 ridge/MLP，zgz 測試，°）：保持 9.21（乾淨 2.25 / 擾動 11.64）；S37 自身 7.93–8.21；S37 根輸入 z 8.02；完美路由 z = 保持（R² 0）；**119 維 2D 剪影殘差** ridge 7.69 / MLP 7.08；×3D 槓桿臂 +r_prev 7.09 / 6.96；+oracle 事件深度 5.30 / 4.51；乾淨樣本上所有解碼器仍注入 3.9–5.0°。
- local 另有手指誤差一項（事件最稀，中位 652 事件/50 ms）；平移每步亂動 20–56 mm（`prev_mlp` 推 42–130 mm）。

## 5. 用戶的兩個方向與方案

**方向 1：解決全局旋轉。**
- **方案 A（用戶澄清後的原意）**：在 778 頂點三維幾何支路**就開始建圖**——prev 的 778 個 3D 頂點與當前事件在同一張圖裡，建圖時就建立「prev 狀態 ↔ 當前事件」的方向聯繫（例如事件到 prev 投影頂點的相對方向/偏移作為跨邊），用來緩解全局旋轉。不是「約束路由」。
- **方案 B（新息特徵 + 雅可比 + 根新息頭）**：
  1. 新息特徵（無學習參數）：渲染 prev 投影剪影，求有符號距離場 SDF；每個路由節點取 `s_i`（到剪影的有符號距離，外正，截斷 ±16 px）與法向 `n_i`；用現有路由權重 `a_ij` 按部位池化，每部位 7 維 `[Σa·s·n (2), Σa·s, Σa·|s|, 到所派頂點的平均偏移 (2), 覆蓋率]`，再加一行全體節點池化，共 17×7 = 119 維。
  2. 雅可比（無學習參數）：用路由時已算的 FK，得每部位相對手腕的槓桿臂：投影 2D 槓桿臂 `L2_j` 與 3D 槓桿臂 `L3_j`（厘米）。
  3. 根新息頭：`Δξ = Σ_j M(L_j)·ψ(q_j)`；`ψ` 各部位共享、無偏置 7→32→16 MLP（`ψ(0)=0`）；`M(L_j) = reshape(W_L [L2_j; L3_j; 1]) ∈ R^{6×16}`。幾何只與殘差相乘；殘差為零時根更新恰為零（契約測試）。旋轉在相機系複合 `R ← exp(ω)·R_prev`。
  4. 刪除：`prev_mlp` 輸出的根 6 行置零（去掉不看事件的回拉）；線性 `root_head(z)` 保留。
  5. 成本：新增約 1.3k 參數（根頭現 27.7k）；SDF 可用 GPU max-pool 閉運算 + 16 次 min/max-pool 近似，或復用 `mesh_graph.nearest_node_lut` 的 jump-flood；延遲估計 +0.2–0.5 ms（未實測）。
- **方案 C**：由研究給出最佳方案。主代理的**初稿**（待證據修正或否定）：
  - C1 連續時間新息：包內事件帶時間戳，`r_i ≈ J_i (δξ + (t_i − t_0) ξ̇)`；時間盲的池化殘差只估到 `δξ + (Δt/2)ξ̇`，時間感知的回歸可把「prev 誤差」與「包內運動」分開，並給出速度（真正的運動模型）。
  - C2 資訊形式增益：`Δξ = (JᵀWJ + Λ_prior)⁻¹ JᵀW r`，W 由事件特徵學習、Λ_prior 為狀態不確定度；增益隨可觀測性與證據量自適應，殘差為零則更新為零，不可觀測方向不動。
  - C3 雙速率：跟蹤路徑（C1+C2）每包執行；全局路徑（長窗 200–300 ms 的絕對估計，帶不確定度）低頻執行，按新息一致性（NIS、剪影外事件比例）觸發重錨。

**方向 2：架構「全局不像全局，跟蹤不像跟蹤」。** 要回答：哪部分多餘、哪部分需優化、哪部分需增加。主代理的初步讀法：
root 頭從事件的**絕對影像座標特徵**回歸一個**增量**（既不是絕對估計也不是新息驅動的修正），`prev_mlp` 是不看事件的先驗回拉；
手指頭讀路由證據 + prev 角但更新方向餘弦只有 0.25；模型沒有新息、沒有增益、沒有不確定度、沒有運動模型，也沒有一條真正的絕對估計路徑。
