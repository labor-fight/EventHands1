## 2. 深讀

深讀 21 篇（有公式或原文定義，且讀的是 PDF/arXiv 文字，不是摘要轉述）。Hand mesh、空間事件雲、雙手 3DV、3DV 2022 點雲姿態、Ren TPAMI 2025、HOTS 全文不計入這 21 篇。

### 2.1 EventNet（CVPR 2019，arXiv:1812.07045v2）

**原問題**：事件流長度可達數萬、速率可超過 1 MEPS，PointNet 式批次 max 在每個新事件上都要重算窗內全部 `h`。

**關鍵公式**（§2.3–§2.4）：他們把 PointNet 寫成

`y_j = f(e_j) ≈ g(max(h(e_{j-n(j)+1}), …, h(e_j)))`　　(1)

時間差 `Δt` 若留在 `h` 裡，舊事件的 `h` 會隨「現在」改變。他們把 `Δt` 移出 `h`，令 `z_i = h(e_i^-)`，`e^- = (x, y, p)`，再定義時間編碼（排版抽出的式 (3)）

`a_{j,i} = c(z_i, Δt_{j,i}) = (|z_i| − Δt_{j,i}/τ)_+ exp(−i 2π Δt_{j,i}/τ)`。

正文同時說第二項是 complex rotation，「sequentially rotating the element」。複數 max（式 (6)）是逐通道取**模長**最大的那個複數，不是逐通道實部 max。遞推（式 (4)(5)）

`s_j = max(c(s_{j−1}, δt_{j−1}), h(e_j^−))`，`f(e_{j+1}) ≈ g(max(c(s_j, δt_j), h(e_{j+1}^−)))`。

他們寫明：一般時間序列上的 max **不能**在有限窗上遞推，除非窗長無限；式 (3) 的編碼才讓 `max∘c` 可遞推。同一時間戳的置換不改變結果（max 可交換）；小的時間抖動在 `g` 光滑時只造成小輸出變化。`(x,y,p)` 離散，推理時 `h` 可查表（LUT）。訓練用批次結構以使用 BatchNorm，與推理的遞推式不是同一張計算圖。

**觀測與假設**：觀測是因果事件窗。假設 `|z|` 經 tanh 小於 1，衰減是對模長的**均勻線性下移**加**均勻相位旋轉**，所以 argmax 在舊元素之間不變，直到模長被截成 0。

**代碼**：GitHub 檢索 0 筆。無函式級證據。

**對本任務**：這是「max + 特定衰減 ⇒ 逐事件 O(1)」的正面例子，也是「和式做不到同一件事」的反面例子（§5 數值：線性衰減的和不能由「和」本身遞推）。它保存的是每通道的**贏者**，不是殘差的加權和，因此不是方案 B 的充分統計量。全局 max 也不保留部位順序。

### 2.2 Deep Sets（NeurIPS 2017，arXiv:1703.06114v3）

**原問題**：定義在集合上的函數必須對元素置換不變。

**關鍵公式**：Theorem 2（可數全集）：`f` 對置換不變，當且僅當 `f(X) = ρ(Σ_{x∈X} φ(x))`。不可數、固定基數 `M` 時，Theorem 7：連續不變函數 `f:[0,1]^M → R` 可寫成 `ρ(Σ_{m=1}^M φ(x_m))`，且 `φ(x) = [1, x, …, x^M]` 與 `f` 無關，`ρ` 連續。Theorem 9：元素在 `R^d` 的緊集、集合大小固定為 `M` 時，連續不變函數可用同一形式任意逼近（Stone–Weierstrass + 對稱多項式基本定理）。Lemma 3：標準全連接層等變，當且僅當 `Θ = λI + γ 11^T`。他們猜想變長集合仍有同一形式，但承認 `2^{[0,1]}` 上「連續」本身沒有自然拓撲。

**觀測與假設**：元素可交換；`φ` 逐元素、先於求和。求和是可交換么半群。

**代碼**：本次未核原始碼。

**對本任務**：方案 B 的 `Σ a·s·n` 就是 `φ` 已經含路由權重與殘差、`ρ` 先取恆等的和式。定理保證的是**對事件置換**的不變性，不是對 16 個關節行置換的不變性。若 `φ` 裡放進關節編號或槓桿臂，求和仍對事件不變，卻可以表達旋轉。若 `φ` 只看到偏移向量本身，求和會把以形心為中心的旋轉場消掉（§5）。

### 2.3 PointNet（CVPR 2017，arXiv:1612.00593v2）

**原問題**：點集無序、有局部度量、整體剛體變換不應改變類別。

**關鍵公式**：§4.2 式 (1)：`f({x_1,…,x_n}) ≈ g(h(x_1),…,h(x_n))`，`g` 對稱。他們把 `g` 實作成 `γ ∘ MAX`。Theorem 1（§4.3）：對 Hausdorff 連續的集合函數，任意 `ε>0` 存在連續 `h` 與 `γ`，使 `|f(S) − γ(MAX_{x_i∈S} h(x_i))| < ε`。證明思路是最壞情況把空間劃成體素。Theorem 2：`u = MAX h(x_i)` 時，存在臨界點集 `C_S` 與上界形狀 `N_S`，`C_S ⊆ T ⊆ N_S ⇒ f(T)=f(S)`，且 `|C_S| ≤ K`（`K` 是 max 的通道數）。特徵對齊正則 `L_reg = ||I − AA^T||_F^2`（式 (2)）。

**代碼**：`https://github.com/charlesq34/pointnet/blob/master/models/pointnet_cls.py`，註釋 “Symmetric function: max pooling”，`tf_util.max_pool2d(net, [num_point, 1])` 接在 `conv5`（1024 維）之後。

**對本任務**：追加事件時，無衰減的 max 是 O(1)：`m ← max(m, h(new))`。有限時間窗的一般 max 不是 O(1)，除非像 EventNet 那樣讓衰減與 max 交換，或用滑動窗 deque。Theorem 2 說輸出只由 ≤K 個臨界點決定，**加性質量（有符號殘差的和、計數、時間矩）被丟掉**。這不能實現方案 B。T-Net 還會把整體旋轉對齊掉，與「要估計 root 旋轉」相反。

### 2.4 PointNet++（NeurIPS 2017，arXiv:1706.02413v1）

**原問題**：PointNet 的一次全局 max 看不到度量空間裡的局部結構，密度又不均勻。

**關鍵公式**（§3.2）：集合抽象層 = 採樣 + 分組 + 局部 PointNet。採樣是迭代最遠點（FPS）：每個新中心是離已選集合最遠的點。分組用球查詢（半徑內、上限 K 個點），點座標改到中心局部系 `x_i^{(j)} − x̂^{(j)}`。密度用多尺度分組（MSG）或多解析度分組。

**觀測與假設**：局部鄰域由**當前點集**的度量決定。

**對本任務**：新來一個點可以改變 FPS 中心與球成員，舊局部特徵不能只加一項就等於在新集合上重跑。**不是**逐事件 O(1) 精確更新。PEPNet 的層次骨幹繼承了這件事。

### 2.5 Set Transformer（ICML 2019，arXiv:1810.00825v3）

**原問題**：Deep Sets 的 `φ` 逐點獨立，表達不了元素間交互；全自注意力是 O(n²)。

**關鍵公式**（§3.1）：`MAB(X,Y) = LayerNorm(H + rFF(H))`，`H = LayerNorm(X + Multihead(X,Y,Y))`（式 (6)(7)），無位置編碼。`SAB(X) = MAB(X,X)`（式 (8)）。`ISAB_m(X) = MAB(X, H)`，`H = MAB(I, X)`（式 (9)(10)），`I` 是 m 個可學習誘導點，複雜度 O(nm)。Property 1：SAB 與 ISAB 都置換等變。PMA 用 k 個可學習 seed 做注意力池化（式 (11) 起）。softmax 注意力權重依賴全體 key。

**對本任務**：多一個事件會改變所有注意力權重與歸一化常數，不存在與集合大小無關的精確充分統計量。誘導點把複雜度降到線性，但仍要掃過整個集合，不是 O(1)。等變性保留了元素身份，可是 S37 的 root 要的是**關節順序**這組離散標籤，不是事件之間的軟注意力。

### 2.6 Janossy Pooling（ICLR 2019，arXiv:1811.01900v3）

**原問題**：Deep Sets 把所有交互都推給 `ρ`，例如 `max_{i,j} |x_i − x_j|` 在求和之後很難學。

**關鍵公式**：Definition 2.1：對所有置換 `π` 施以置換敏感函數 `f`，再求和（或平均），外面套 `ρ`。這在 `|h|!` 上不可行。Definition 2.2：k-ary 截斷，`f` 只看置換後的前 k 個元素。k=1 就是 Deep Sets（他們在 §2.2 與後文明確這樣寫）。`π`-SGD 用隨機置換做近似，不再精確。

**對本任務**：k≥2 的精確 Janossy 不是 O(1)。它說明「只求和」的表達力缺口在**元素交互**，而方案 B 的交互不在事件之間，在「事件 × 凍結的 prev 幾何」。那種子交互已經折進 `a_ij, s_i, n_i`，不需要二階 Janossy。

### 2.7 Wagstaff 等（arXiv:1901.09006v2）

**原問題**：Zaheer 等曾讓人以為潛變數維度可以不隨集合大小增長。

**關鍵公式**：Definition 2.2：經 `Z` 和式可分解，且 `ρ,φ` 連續時稱為連續和式可分解。Theorem 4.1：若 `M > N`，存在 `R^M` 上的連續置換不變函數，不能經 `R^N` 連續和式分解。實用復述：集合大小 ≤ M 的萬有逼近，要求和發生的潛維度至少為 M。max 分解有類似必要條件（Appendix B.6，本次未逐行核對證明，只讀到這個指向）。Theorem 4.3/4.4：固定大小 M 時經 `R^M` 是充要；變長 ≤M 亦然。可數情形用高度不連續的 `φ`（如 `4^{−c(x)}`）可以壓進 `R^1`，他們認為這對神經網路沒有意義。

**對本任務**：2048 個事件的任意連續不變函數，不能指望一個很小的和向量去萬有逼近。方案 B 不需要萬有逼近；它只需要特定的低維矩。矩的維度由部位數與矩的階決定（17×7 再加時間矩），與事件數無關，這不與 Wagstaff 衝突——Wagstaff 限制的是「所有函數」，不是「某一族可加統計量」。

### 2.8 Phased LSTM（arXiv:1610.09513）

**原問題**：常規 RNN 假設等間隔採樣，不適合事件時刻。

**關鍵公式**：時間門 `k_t` 由週期 `τ`、開啟比 `r_on`、相位 `s` 控制（式 (6) 的分段線性）。細胞更新（式 (7)–(9)）

`c̃_j = f_j c_{j−1} + i_j σ_c(…)`，`c_j = k_j c̃_j + (1−k_j) c_{j−1}`，

`h` 同樣被 `k_j` 混合。`k_t = 0` 時 `c_j = c_{j−Δ}`，閉合相位記憶不衰減；閉合相位另有洩漏 `α` 以便傳梯度。

**對本任務**：這是 O(1) 遞推，但是**一條**序列狀態，不是集合和。門控依賴學到的振盪，不是殘差為零則貢獻為零。單細胞 Phased LSTM 會把空間場混進一個隱藏態，root 旋轉需要的空間基容易消失。Matrix-LSTM 後文也指出 Phased LSTM 是整條流上的單一細胞。

### 2.9 Matrix-LSTM（ECCV 2020，arXiv:2001.03455v2）

**原問題**：手作時間表面不可微、對任務盲目；ConvLSTM 要求先把事件鋪成稠密幀。

**關鍵公式**（§3）：每個像素（或每個感受野）一條 LSTM，只在該位置有事件時依到達順序更新。表面 `S_E` 由多段時間 bins 的隱藏態拼成。參數在空間上共享，等價於他們所說的 1×1 ConvLSTM，但稀疏實現用 `groupByPixel` / `groupByTime`。感受野 `K_H×K_W` 時，事件可被多個細胞各算一次，並附加歸一化相對座標 `(p_x, p_y)`。時間特徵比較了 timestamp 與 delay、絕對與相對歸一化。代碼頁見論文，本次未讀程式。

**觀測與假設**：同一像素上的事件是一條時間序列；不同像素除了共享權重與可選的更大感受野外，互不混和。遺忘門是學出來的衰減，不是固定指數核。

**對本任務**：空間格子保住了旋轉場的左右差，後面的 CNN 可以讀到。代價是格子上的稠密讀出，不是 17×7 的矩。遺忘門在「當前殘差為零」時仍可從舊細胞狀態寫出非零表面，違反「證據為零則貢獻為零」。它也不能在 prev 改變後，把舊事件重路由到新的 MANO 部位。

### 2.10 EST（ICCV 2019，arXiv:1904.08245v4）

**原問題**：把非同步事件收成網格時，核與測量應能隨任務學習。

**關鍵公式**（§3.2–§3.3）：事件場

`S_±(x,y,t) = Σ_{e_k∈E_±} δ(x−x_k, y−y_k) δ(t−t_k)`　　(3)

測量 `f_±` 插進同一和式。卷積後（式 (5)）

`(k ∗ S_±)(x,y,t) = Σ_k f_±(x_k,y_k,t_k) k(x−x_k, y−y_k, t−t_k)`。

離散抽樣得 EST（式 (6)）。沿時間或極性可再做 `Σ` 或 `max`。指數核、alpha 核、三線性核都是這個和的特例。三線性核寫成 `k = δ(x,y) max(0, 1 − |t|/Δt)`。

**對本任務**：若核與測量只依賴單個事件與固定抽樣格，EST 是 scatter-add，逐事件精確、與順序無關（精確算術）。這與方案 B 同一代數。差別是 EST 的格子在相機像素上，不在 MANO 部位上；讀出仍是 CNN，不是 `M(L)ψ(q)`。像素格的和**不會**把左右相反的殘差在進 CNN 之前加總抵銷，這一點對 root 有用，但計算落在稠密網格上。

### 2.11 HATS（CVPR 2018，arXiv:1803.07913）

**原問題**：只用每個像素最後一個時間戳的時間表面對雜訊過於敏感。

**關鍵公式**：HOTS 式時間表面（他們的式 (2)，轉述 Lagorce 等）

`T̄_{e_i}(z,q) = exp(−(t_i − t_0(x_i+z, q))/τ)` 當極性匹配，否則 0。

局部記憶時間表面（式 (3)(4)）改為對時間窗 `Δt` 內、同一像素與極性的**所有**過去事件求和 `Σ exp(−(t_i−t_j)/τ)`。細胞直方圖（式 (5)(6)）`h_C = (1/|C|) Σ_{e_i∈C} T_{e_i}`。Algorithm 1：每事件 O(1) 更新細胞直方圖 `h ← h + T` 與計數，記憶單元另存原事件以便以後算表面。

**對本任務**：指數核的和可以改寫成遞推（§5）。HATS 的 Algorithm 1 仍要在記憶裡留下窗內事件，因為表面定義依賴鄰域歷史，不是只留一個和。對比度歸一化是除以計數，分子分母各自可加。

### 2.12 TORE（TPAMI 2023；深讀 arXiv:2103.06108v1）

**原問題**：時間窗體素既膨脹又丟掉尖峰時刻；全歷史又存不下。生物膜電位被近期尖峰主導。

**關鍵公式**（§3 式 (2)–(5)）：每像素每極性一條深度 K 的 FIFO。新事件把佇列前移，`FIFO(·,1) = e_t`，最舊的丟棄。

`TORE(x,y,p,k,t) = log(t − FIFO(x,y,p,k) + 1)`，

並夾在 `log τ'` 與 `log τ` 之間（文中 `τ = 5×10^6`、`τ' = 150`，單位是微秒量級的相機時間）。FIFO 隨事件非同步更新；體積可在任意查詢時刻 t 由 FIFO 算出。K=3 的示意圖、分類實驗用過 K=7 與 K=4。

**對本任務**：更新是 O(1) 的移位，不是和。它保留的是最近 K 個時刻，空間結構還在，所以旋轉場還沒被全局池化吃掉；但要再跑 CNN。K 個時刻不是 `Σ a s n t` 那種對全部事件的充分統計量，早於 K 的事件被硬丟掉。對數是為了壓縮，不是指數衰減的充分統計量。未對過 TPAMI 終稿，若終稿改了夾取範圍，以終稿為準。

### 2.13 Mamba（預印本 arXiv:2312.00752v2）

**原問題**：LTI 的 SSM 不能按內容選擇記憶；選擇性會破壞卷積形式。

**關鍵公式**：連續 SSM `h'(t) = A h(t) + B x(t)`。零階保持離散化 `Ā = exp(Δ A)`。Algorithm 2 讓 `Δ, B, C` 依賴輸入。Theorem 1（附錄）：`N=1, A=−1, B=1`，`Δ_t = softplus(Linear(x_t))` 時，ZOH 得到

`g_t = σ(Linear(x_t))`，`h_t = (1−g_t) h_{t−1} + g_t x_t`。

這是洩漏積分／EMA。選擇性之後不再等於卷積，但平行 scan 仍是沿時間的結合算子，單步仍是 O(狀態維度)。

**對本任務**：沿**給定順序**可以 O(1) 遞推，但 `g_t` 依賴當前輸入，狀態不是事件的可交換和。把事件打亂再掃，結果變。根旋轉若被掃進一條不帶部位標籤的狀態，與全局池化一樣會把空間基弄丟。預印本，不是已發表會議論文。

### 2.14 Zubic 等，State Space Models for Event Cameras（CVPR 2024）

**原問題**：事件檢測網路裡的 RNN 訓練慢，而且換推理頻率就掉點（文中 RVT / GET 在 Gen1 與 1 Mpx 上平均掉 21.25 / 24.53 mAP，他們的 SSM 掉 3.31 mAP）。

**關鍵公式**（§3.1 式 (2)(3)）：連續 LTI

`dx/dt = A x + B u`，`y = C x + D u`，

固定步長 `Δ` 下 `x_k = Ā x_{k−1} + B̄ u_k`。他們用 S4 / S4D / S5，輸入是既有的事件張量（沿用 RVT 的表示），不是原始點。塊內仍有局部與擴張注意力。狀態可跨時刻保存。頻率改變時只改時間尺度 `Δ`。

**對本任務**：LTI 線性濾波**是**指數衰減類的精確遞推，但對象是網格特徵序列，不是 `a·s·n`。它不提供部位槓桿，也不滿足「這一包殘差為零則根更新為零」——舊狀態 `x_{k−1}` 仍在。論文自己的任務是檢測 mAP，不是手的 root。

### 2.15 AEGNN（CVPR 2022）

**原問題**：稠密事件表示浪費計算；靜態事件圖每個新事件都重算全圖。

**關鍵公式**（§4.2）：頂點 `X_i = (x_i, y_i, β t_i)`，邊在時空半徑 R 內且度 ≤ `D_max`。圖卷積

`ẑ_i = Σ_{j∈N(i)} ψ(x_i, x_j, e_{ij})`，`x̂_i = γ(x_i, z_i)`。

新事件只重算其 k-hop 子圖，作者稱與全圖前向結果相同。池化層對受影響體素重做 max。他們點名 EventNet [48] 的限制：沒有層次、不能擴到更難的任務。

**對本任務**：這是「局部重算、結果與批次相同」的圖版本，複雜度隨鄰居數而不是 O(1) 常數。邊集依賴點集，不是 Deep Sets 和。S37 的 EdgeConv 同樣原因不能逐事件只加一項。AEGNN 不估計手的 root，也沒有 prev 幾何。

### 2.16 PAT（Yang 等，CVPR 2019）

使用者種子裡的 PAT，PEPNet 參考文獻 [43] 指的就是這篇：*Modeling Point Clouds with Self-Attention and Gumbel Subset Sampling*。文中自稱為 Point Attention Transformers（PATs）。

**原問題**：點云要吃變長、置換；FPS 對置換敏感且怕離群點。

**關鍵公式**（§3）：非線性注意力 `S(Q,X) = softmax(Q X^T / √c)` 再接 ELU。Group Shuffle Attention

`GSA(X) = GN(ψ(GroupAttn(X)) + X)`，

並證明置換等變：`GSA(P X) = P GSA(X)`。Gumbel subset sampling 用 Gumbel-softmax，訓練軟、測試硬。複雜度仍寫著位置集合上的 O(N²)，實作時不用全部點。

**事件實驗**（§4.3）：DVS128 Gesture。每事件 4 維 `(x, y, t, polarity)`，當作時空點雲。窗 750 ms、步進 100 ms，抽 1024 點。系統準確率取各 clip 的眾數。表 5：PAT（FPS+GSS）11 類 96.0，PointNet 88.8，PointNet++ 95.2，CNN 基線 94.4。延遲是整段前向（GTX 1080 上約 7.5–16.9 ms），不是逐事件遞推。

**對本任務**：PAT 把事件當無序點集做注意力，**沒有** prev 網格，也沒有逐事件充分統計量。等變注意力理論上可以看空間模式，但 1024 點的自注意力不是方案 B 的 O(1) 和，而且手勢標籤不是 6-DoF root。GSS 的子集依賴全體分數，新點會改變抽樣。

### 2.17 PEPNet（CVPR 2024）

**原問題**：事件位姿重定位把時間壓掉了；直接把 `(x,y,t)` 當點雲又違反點雲網路的置換與剛體假設。

**關鍵公式與主張**（§2.3、§3.1–§3.2）：事件 `e_k = (x_k, y_k, t_k, p_k)`，集合寫成式 (1)。他們明確寫：Event Cloud 因為時間順序而**違背**點雲的置換不變與變換不變；既有點雲網路抽不出顯式時間特徵。層次結構「不再強制置換不變」，事件保持原始順序，後面用 Attentive Bi-LSTM 讀顯式時間。空間仍用分組、採樣、聚合（PointNet++ 一系）。預處理把窗內時間除以 `t_l − t_j` 做成偽點雲的第三維。

**對本任務**：最近的「點式事件、6-DoF」工作。它的 6-DoF 是**相機**絕對位姿，場景相對剛性，不是非剛體手、也不是相對於 prev 的新息。他們放棄置換不變，正好說明：若目標依賴順序或空間身份，全局對稱池化是錯的歸納偏置。Bi-LSTM 是 O(窗長) 的序列狀態，不是可交換的矩，也不能在殘差為零時結構性地輸出零。

### 2.18 EventHands（ICCV 2021）

**原問題**：從事件流回歸 MANO 姿態，又要保住窗內時間。

**關鍵公式**（§5.1 式 (4)）：窗長 L，從舊到新覆寫

`I(x_i, y_i, p_i) = (t_i − t_0) / L`。

同一像素同一極性後來的事件覆蓋先前的。兩極性分通道，減少互蓋。實驗窗 100 ms、重疊 99 ms。他們對比 SAE：差別是時間用窗內歸一化單位。

**對本任務**：覆寫是 O(1)，但是**丟棄**該像素上除最後一個以外的事件，因此不是 `Σ a s n` 或 `Σ a s n t`。多個殘差事件落在同一像素時，和式會累加，LNES 只留最後時刻。根旋轉的證據若來自輪廓上一串事件，覆寫會把質量換成一個時間戳。

### 2.19 GET（ICCV 2023）

**原問題**：體素／直方圖把時間與極性揉進空間通道，Transformer 又貴。

**做法**（§1、§3，無獨立編號的集合和式）：Group Token 按時間戳與極性把事件分組，與空間分開。EDSA 先做局部空間自注意力，再做組自注意力；雙殘差避免兩個域互相蓋掉。後面接檢測頭（YOLOX 設定在實驗裡）。輸入側仍常從體素或分組 token 開始，不是逐事件充分統計量。

**對本任務**：分組本身是硬劃分。組鍵若含時間，組內仍要聚合；只有組內聚合是和或 max 時，該組才能 O(1) 更新。跨組注意力不能。GET 不處理手的 prev 幾何。

### 2.20 EventMamba（AAAI 2025）

**原問題**：視覺 Mamba 的固定窗與普通掃描破壞事件的時空局部性；重建要平移不變與局部鄰接。

**做法**（摘要與 §1，圖 2）：U-Net，輸入事件體素 `V_k`，預測強度圖。空間用 random window offset，掃描用 Hilbert 曲線，使時空相鄰的事件在序列裡也靠近。骨幹是選擇性 SSM。沒有讀到閉式的殘差矩。

**對本任務**：掃描順序是作者設計的空間填充曲線，不是事件的自然時間序，更不是可交換和。任務是視頻重建。把它換進 S37 只是換表示加一個序列模型，不構成根新息。

### 2.21 EventEgo3D（CVPR 2024）

**原問題**：自我中心事件上的人體姿態；靜止時事件變少。

**公式**（§3.1）：沿用 EventHands 的 LNES，`L(x_i,y_i,p_i) = (t_i − t_0)/T`，同樣是覆寫。REPM（§3.2 與圖 2 說明）：用幀緩衝把上一幀事件按**事件信心**衰減後送進當前幀，讓網路在幾乎沒事件時仍保住姿態，並壓低背景。正文沒有給出衰減的閉式，不編造係數。

**對本任務**：信心衰減的歷史緩衝在「當前窗沒有手的事件」時仍輸出非零，這是追蹤先驗，不是新息。與本倉庫「殘差為零則貢獻為零」的契約相反，除非這條通路被明確當成先驗而不是證據項。

## 3. 可觀測性、資訊來源與失效條件

對象是單目 DAVIS 類 240×180、50 ms 一包、非剛體手、狀態為 MANO 51 維。遞推評測的 RA-MPJPE 只減腕、不對齊旋轉，所以 root 旋轉全部進入指標。

**資訊實際從哪裡來**

- 事件只在亮度變化超過對比度閾值時出現（EST 式 (1) 的生成模型）。50 ms 內沒有運動或紋理，包可以幾乎是空的。空包沒有 root 的新觀測。
- 單目圖像座標 `(x,y)` 不是 3D 點。深度不在事件裡。多個歷史深度假設不是多次獨立測量。
- 方案 B 的 `s, n` 來自 **prev 剪影的 SDF**，`a_ij` 來自 **prev 的投影與 LBS**。資訊是「當前事件相對凍結 prev 的殘差」，不是事件集合的內稟形狀。
- 時間戳把包內運動和 prev 誤差分開，但只在觀測模型對時間近乎線性、且包內時間有散度時可分（§5 的 C1）。上下文已寫：時間盲的池化只估到 `δξ + (Δt/2) ξ̇`。zgz 上 50 ms 的真實轉動只有 1.6–3.0°，而 S37 的旋轉誤差地板是 6–8°（`00_CONTEXT.md` §3）。包內運動小於誤差地板時，時間矩的信噪比可以很低。
- 部位槓桿 `L_j` 來自 MANO 與 FK，是運動學先驗，不是新觀測。

**旋轉何時進得了統計量**

記部位 j 的圖像位移為 `v_j`。繞腕的平面內小旋轉 `v_j = ω J L_j`，`J` 為 90° 旋轉。則 `Σ_j v_j = ω J (Σ_j L_j)`。

- 若部位關於旋轉中心對稱，`Σ L_j = 0`，全局和**精確為零**。CPU 實驗把槓桿減去均值後，和的數量級是 10^{−16}。
- 手不是對稱的。用種子 4 抽的「腕在原點、指在 +x」槓桿，`ω=0.05` 時和為 `[-1.27, 19.32]`，範數 19.36，與 `ω J ΣL` 一致。這個和非零，但和「全体平移」同維，**不能分開** `ω` 與 `(t_x, t_y)`。只對和做最小二乘，奇異值兩個（387.6 與 16），零空間約 `[-0.041, -0.066, 0.997]`；解出 `ω≈0.030`、`t≈(1.17, 0.078)`，真值是 `0.05` 與 `(1.2, −0.4)`。和本身被擬合到殘差 10^{−14}，姿態是錯的。
- 16 行按關節順序排好之後，同一最小二乘把 `(ω, t_x, t_y)` 收到 10^{−15}。這就是 `model.py` 裡 root 頭按關節順序讀 16 行的理由，見 `_decode_active` 註釋（約 1094–1096 行）：對部位做置換不變池化會抵銷旋轉偏移場。更精確地說：對稱時是抵銷；不對稱時是與平移不可辨。

**失效**

- prev 在包內被更新：`a, s, n` 對**所有**舊事件改變，和式要整包重算。
- 事件特徵來自 kNN / EdgeConv / 注意力：貢獻依賴其他事件，不是單事件 `φ`。
- 把跨包衰減狀態加進根更新：當前包殘差為零時舊狀態仍非零，破壞契約。
- 剛體場景的 PEPNet / EST 分類不能搬到非剛體手指。指關節在 50 ms 內的運動會污染「整手一個 `ξ̇`」的 C1 模型。
- 輪廓法向殘差對 `rot_z` 與橫向平移近共線（上下文 §4，S38 合成輪廓）。矩再可加，也補不出第二個視角。

## 4. 可證偽假說

**H1（可遷移的那條）**。prev 幾何在包內凍結時，方案 B 的部位殘差與 C1 時間矩是單事件貢獻的和，逐事件遞推在實數上與批次和相同；空間基必須留在和裡面（關節順序、或 `槓桿 ⊗ 殘差`），不能改成對 16 行的 sum/mean/max。

最強的反對證據不是代數，而是任務統計：上下文 §3 寫旋轉誤差與事件數、運動量無關，是固定地板。若地板來自深度歧義與常數增益，而不是池化把旋轉消掉，則換上精確的矩也不會動 RA。S37 資訊探針裡完美路由的 z 分數 R²=0，說明「更準的事件—關節關聯」本身不夠；矩若仍乘在錯誤的觀測模型上，會同樣失敗。

**H2（最可能被否定）**。在 zgz、50 ms 包上，加入 `Σ a s n t` 與 `Σ a t` 之後，線性讀出的 root 旋轉誤差會穩定低於時間盲的 119 維剪影殘差（上下文 §3：ridge 7.69° / MLP 7.08°），因為它把 `δξ` 與 `ξ̇` 分開了。

反對證據已經很強：（1）50 ms 真實轉動 1.6–3.0°，誤差地板 6–8°；（2）時間以秒計時，二階 Gram 矩陣條件數在合成均勻包上約 4.7×10³（§5），包內運動的係數被壓在很小的時間方差裡；（3）手指是非剛體，單一 `ξ̇` 是錯模型；（4）事件不是輪廓上的均勻取樣。H2 應先被一個不訓練大網路的探針否定或保留，而不是直接訓練。

## 5. 最小可遷移機制

### 5.1 精確遞推的條件（問題 a）

設每個事件貢獻向量 `φ_i`，聚合 `A(φ_1,…,φ_n)`。逐事件 **O(1) 且與批次相同**（實數算術）當且僅當下面幾條同時成立。

1. **可分離**：`φ_i` 只依賴事件 i 與包內不變的量（凍結的 prev、固定的 SDF、固定的像素格）。不依賴其他事件。EdgeConv、球查詢、FPS、softmax 注意力、GSS 都不滿足。
2. **聚合是可交換么半群，或固定個數的此類聚合的函數**。和、積、逐通道 max/min 滿足。均值是 `(和, 計數)` 的商。方差用 `Σφ` 與 `Σφ²`。Set Transformer 的 PMA、Janossy 的 k≥2、PointNet++ 的 FPS 不滿足。
3. **時間重加權必須能穿過聚合**。
   - 指數權 `exp(−α(T−t_i))`：對和與 max 都可以。和的遞推是 `U ← exp(−α(t_new−t_cursor)) U + φ`，游標改到 `t_new`，最後對齊查詢時刻 T。中間時刻會消去，所以**用真實時間戳移動游標時，處理順序可以不是時間順序**（負的 `Δt` 也成立）。CPU 上把 2048 個事件打亂後，float64 與批次和的最大絕對差仍是 `5.1×10^{−13}`。若改成「每來一個事件就乘固定係數、不看時間戳」，打亂後不再相等。
   - EventNet 的模長線性下移 `(m − Δt/τ)_+`：與 **max** 交換，因為每個舊元素被減去同一個量。與 **和** 不交換：舊元素各自在不同時刻被截成 0，只存一個和無法知道誰先被截斷。合成實驗：500 個數的線性衰減和是 47.71，用「和與平均時間」硬套是 −57.30，絕對差 105.0。
4. **有限窗的普通 max** 不是 O(1)，除非衰減與 max 交換（EventNet）或另存滑動窗結構。PointNet Theorem 2 的臨界點集大小 ≤ 通道數，刪掉贏者時必須知道誰是贏者。
5. **prev 一變，舊的 `φ_i` 全部作廢**。跨包只能保存「當時幾何下的歷史摘要」，不能把舊事件 O(1) 地重寫成新 prev 的殘差。

Mamba / Phased LSTM / Matrix-LSTM 是沿順序的 O(1) 遞推，但不是第 2 條的可交換和。Zubic 的 LTI SSM 是第 3 條指數核在網格序列上的特例。

### 5.2 方案 B 與 C1 的遞推（問題 b）

記號對齊 `00_CONTEXT.md` §5 與 `semkine/routed_readout.py`。prev 凍結時，路由 `a_{ij}`（`route_front_vertex_lbs`）、有符號距離 `s_i`、法向 `n_i∈R^2`、到所派頂點的像素偏移 `o_i∈R^2` 都只依賴事件 i。現有池化（`pool_joint_evidence`）是

`e_j = [ (Σ_i a_{ij} h_i) / (Σ_i a_{ij})  ‖  hard-max  ‖  (Σ_i a_{ij}) / n_live ]`。

`h_i` 若來自事件圖，**不**可分離，下面的 O(1) 對它不成立。方案 B 的 7 維用的是可分離殘差，不是 `h_i`。

對每個部位 j（再加一行全體），令 `a_i = a_{ij}`。批次定義

- `U_j = Σ_i a_i s_i n_i ∈ R^2`
- `S_j = Σ_i a_i s_i`
- `A_j = Σ_i a_i |s_i|`
- `O_j = Σ_i a_i o_i ∈ R^2`，`W_j = Σ_i a_i`
- 平均偏移 `ō_j = O_j / W_j`（`W_j=0` 時定為 0，與現有 `wsum>0` 的門一致）
- 覆蓋率 `c_j = W_j / n_live`

7 維是 `[U_j, S_j, A_j, ō_j, c_j]`。平均與覆蓋率不是和，但 `(O, W)` 與 `n_live` 是和。逐事件

`U ← U + a s n`，`S ← S + a s`，`A ← A + a|s|`，`O ← O + a o`，`W ← W + a`。

LBS 每事件非零部位是少數，複雜度 O(1)（相對已處理事件數），與 2048 的歷史長度無關。

C1：`r_i ≈ J_i (δξ + (t_i−t_0) ξ̇)`。若在部位內把 `J` 收成常數 `J_j`，並把觀測殘差讀成 `s_i n_i`，則

`U_j = Σ a s n ≈ J_j ( W_j δξ + T_j ξ̇ )`

`Q_j = Σ a s n (t−t_0) ≈ J_j ( T_j δξ + Q^t_j ξ̇ )`

其中 `T_j = Σ a (t−t_0)`，`Q^t_j = Σ a (t−t_0)^2`。`Q_j` 的遞推是 `Q ← Q + a s n (t−t_0)`，同樣可加。`T_j`、`Q^t_j` 也是。時間盲只用 `U_j / W_j`，得到的是 `δξ + (T_j/W_j) ξ̇`。均勻分佈在 `[0, Δt]` 上時 `T/W = Δt/2`，與上下文 C1 的句子一致。

合成核對（常數 `J`，`Δt=0.05` s，800 點）：時間盲估計等於 `δξ + 0.0242 ξ̇`；兩個矩在精確算術下收回 `δξ` 與 `ξ̇`。Gram 矩陣 `[[W, T],[T, Q^t]]` 的條件數約 4735，因為 `t` 用秒、方差約 `(0.0145)^2`。實作應把時間改成 `τ = (t−t_0)/Δt ∈ [0,1]` 再累積，線性關係仍在，條件數回到 O(1)。

**指數衰減（只有在明確把它當歷史先驗、而不當本包新息時）**。查詢時刻 T：

`U(T) = Σ_i a_i s_i n_i exp(−α(T−t_i))`。

時間順序或任意順序（游標用真實時間戳）都是上面的乘法遞推。它**不**滿足「本包殘差為零則輸出為零」。本包新息只用本包、不衰減的和。

**數值等價**。事件數 N，`a` 為稀疏 LBS 權重（約 15% 事件在帶外），`s~Unif[−16,16]`，`n` 單位向量，`o~N(0,8^2)`，`t` 在 `[0,0.05]` 上排序。參考是 float64 的 einsum。最大絕對誤差：

| N | 量 | float64 順序和 vs einsum | float32 順序和 vs float64 | float32 打亂順序 vs float32 時間順序 |
|---|---|---|---|---|
| 2048 | `U` | `2.8×10^{−14}` | `5.37×10^{−5}`（相對 `2.3×10^{−5}`） | `9.2×10^{−5}` |
| 2048 | `S` | 0 | `5.27×10^{−5}` | `3.8×10^{−5}` |
| 2048 | `A` | 0 | `4.0×10^{−4}` | `4.3×10^{−4}` |
| 2048 | `O` | 0 | `5.5×10^{−5}` | `4.2×10^{−5}` |
| 2048 | `W` | 0 | `3.7×10^{−5}` | `6.1×10^{−5}` |
| 2048 | `Q` | `1.3×10^{−15}` | `1.1×10^{−6}` | `1.1×10^{−6}` |
| 2048 | `ō=O/W` | — | `5.0×10^{−7}` | — |
| 20000 | `U` | `2.3×10^{−13}` | `4.3×10^{−4}` | `5.5×10^{−4}` |
| 20000 | `A` | 0 | `1.0×10^{−2}` | `8.8×10^{−3}` |

指數衰減 `α=20`、`T=0.05`、N=2048：float64 遞推對批次 `U` 的誤差 `7.2×10^{−13}`；float32 為 `3.0×10^{−4}`。EventNet 式複數 max（保留相位、模長線性衰減、再乘 `exp(−i2πΔt/τ)`）遞推對批次的誤差 `5.8×10^{−16}`。Kahan（float32）能把 `U` 的誤差從 `5×10^{−5}` 降到約 `7×10^{−6}`，但不是本任務的瓶頸。

**建議的數值契約**（對原始矩，不是對網路輸出）：

- float64 對 float64：最大絕對誤差 `< 1×10^{−8}` 視為同一和。上面全部滿足（實測 `< 1×10^{−12}`）。
- float32 對 float64、N≤2048：像素矩最大絕對誤差 `< 1×10^{−3}` 視為幾何上同一輸入。`U,S,O,W,Q` 滿足；`A` 的 `4×10^{−4}` 也滿足。N=20000 時 `A` 到 `1×10^{−2}`，若包遠大於 2048 抽樣，不要用 float32 累加器。
- 不把 float32 順序差當成逐位相同。`model.py` 已記錄：累加順序造成的約 `1×10^{−6}` 網路輸出，在種子 3408 上被閉環放大到 0.15 mm RA。矩的 float32 誤差是 **輸入統計** 的 `1×10^{−5}–1×10^{−4}`，乘上根頭之後是否穿過 0.05 mm 復現門，本次沒有閉環，不能宣稱通過。
- 商 `ō` 在 `W` 接近 0 時放大誤差。沿用 `W>0` 才除，否則 0。
- 指數衰減遞推要麼用 float64，要麼在歸一化時間上做，並在查詢時刻對齊 T。

### 5.3 遞歸集合表示對 root 能給什麼、不能給什麼（問題 c）

能給的：

- 對**事件**置換不變的和，只要 `φ` 裡含有部位編號、像素座標或槓桿，就可以留下旋轉。最小的做法就是 16 行分開加，再按關節順序送進現有 root 頭。這與 Deep Sets 一致，也與 `_decode_active` 的實作一致。
- `Σ_j (J L_j) ⊗ U_j` 這類交叉矩本身是一個全局和，仍然可交換，而且在合成數據上能把 `ω` 與平移分開。它不需要 16 行拼接，但要把槓桿乘進統計量，不能乘在與證據無關的加性項上（S38 契約：幾何只乘殘差）。
- 相機格上的可加表示（EST 的和、HATS 的細胞直方圖）在進 CNN 之前保留左右差。那是另一條讀出，不是 O(1) 的根頭。

不能給的：

- 對 **16 個部位行** 再做 sum/mean/max，且 `φ` 不含關節身份：平面旋轉與平移不可辨；中心化之後旋轉和為 0。
- PointNet / EventNet 的 max：只留每通道贏者（Theorem 2，`|C_S|≤K`），有符號殘差的質量消失。
- Set Transformer、PAT 的 GSA、PEPNet 的層次採樣：表達力或許夠，但不是精確 O(1)，而且 PEPNet 自己已放棄置換不變。
- 全局複數 max 或單細胞 LSTM：沒有部位基。
- 任何只換輸入表示、不把觀測改成「相對 prev 的殘差 × 槓桿」的點雲網路（PAT、空間事件雲、PEPNet）都不估計這隻手的 root 新息。
- 單目矩補不出深度，也解不開上下文裡 `rot_z` 與橫向平移的共線。

### 5.4 接入點與成本

- 接入：`semkine/routed_readout.py` 的 `route_front_vertex_lbs` 已經給出 `a`。方案 B 的 `s, n, o` 尚未在該檔實作；累加器應放在路由之後、`pool_joint_evidence` 旁邊，**不要**把事件圖的 `h` 放進這個和。
- 讀出：`model/model.py` 的 `_decode_active` 繼續 `evidence.flatten(1)`，保持關節順序。不要對 16 行做 mean/max 再送 root。
- 參數：矩本身 0 個可學習參數。若根新息頭仍是上下文方案 B 的 `ψ`（7→32→16，無偏置）與 `M(L)`，時間矩只增加 `ψ` 的輸入維度（例如 7 改成 7+4），參數仍是千級，不是百萬級。
- 計算：2048 事件 × 最多 16 部位 × 約 10 個標量和，約 `3×10^5` 次加乘，相對現有 0.827 GMAC 可忽略。延遲量級是記憶體散點加，遠小於 0.1 ms，前提是 SDF 與 `a` 已經算好。SDF 本身的成本在方案 B 的上下文估計裡（+0.2–0.5 ms，未實測），不是本遞推新增的。
- 不取代事件圖。圖特徵的池化仍然是批次的。

## 6. 最小判別實驗（問題 d）

不要訓練完整模型，不要用 GPU。資料只用 zgz 上已經能取出的包，或合成場。

**E0 數值契約（已做，CPU）**。上面的表就是 E0。通過條件：float64 絕對誤差 `< 1×10^{−8}`。已通過。float32 的 `< 1×10^{−3}`（N=2048）已通過。否定條件：若有人改用 float32 且 N≫2048 仍宣稱與 float64 批次逐位相同。

**E1 旋轉是否真被全局池化弄丟**。凍結 prev。對同一批事件構造三個向量，用同一個 ridge（與上下文 §9.2 同一協議：zgz，乾淨／擾動 prev）預測 root 旋轉：

- P0：全體事件一個 `Σ s n`（無部位）。
- P1：16 部位的 `[U, S, A, ō, c]` 按關節順序拼接（方案 B，時間盲）。
- P2：P1 加上歸一化時間矩 `Σ a s n τ`、`Σ a τ`、`Σ a τ²`。
- P3：同一 `φ` 的逐通道 max（PointNet/EventNet 聚合，無複數相位也可先做實數 max）。
- P4：LNES 圖的全局平均（覆寫表面，再平均掉空間）。

預期：P1 接近上下文已有的 119 維剪影殘差（ridge 約 7.7° 這一檔），P0 與 P4 明顯更差，P3 接近 P0 而不是 P1。P2 相對 P1 的改進若不超過兩種子與抽樣噪聲，否定 H2。

否定 H1 的觀測：P0 在平面內旋轉上的誤差與 P1 相同（說明這個殘差場的和並未失去可辨性），或 float64 遞推與批次和的差 `> 1×10^{−6}`（說明實作把不可分離的 `h` 乘進去了）。

**E2 與簡單修復分開**。同一讀出上比較：

- 可見性修復：只把 `a` 改成前表面門控，特徵仍是現有 `h` 的全局池化。
- 普通時序濾波：對 root 角做指數滑動平均或常數 `δ`-trust（倉庫裡 0.5 已吃掉大部分可實現增益，見上下文 §4）。
- 換表示：LNES 或 EST 直方圖接一個線性頭，沒有部位順序。
- 本機制：P1 或 P2，幾何只乘殘差，殘差為零時該項為零。

預期：滑動平均與 `δ`-trust 不降低單步旋轉地板（它們不看事件）。只換 LNES/EST 而不分部位，平面旋轉仍與平移混在一起。可見性修復可以改變覆蓋率，但不提供 `s n` 的符號和。若 E2 裡濾波與 P1 打平，則本機制沒有超出常數增益，應放棄。

**E3 契約**。構造 `s=0` 的包：P1/P2 的根項必須為 0。構造「上一包有殘差、這一包為空」：若有人把衰減狀態加進根項，契約失敗。通過的實作必須把衰減狀態放在先驗支路，或根本不跨包累積新息。

## 7. 六個創新問題

**此前未解決的矛盾是什麼。** 一邊要逐事件更新（EventNet、AEGNN、TORE），一邊要用置換不變集合函數（Deep Sets、PointNet）。S37 的 root 又不能對部位行做這種不變池化，否則旋轉與平移不可辨。方案 B 的和式同時滿足「對事件可交換」與「對部位有序」。這不是新網路，是把聚合選成與觀測模型匹配的充分統計量。

**新資訊從哪裡來。** 新的量只有事件相對**凍結 prev** 的 `(s, n, o, t)`。槓桿與 LBS 是 MANO 先驗的再次使用。指數衰減記憶是舊殘差的再加權，不是新觀測。單目仍然沒有第二視角。

**非同步、時間、稀疏各自貢獻了什麼。** 稀疏使「每事件加一次」比每包重跑 CNN 便宜，但 S37 已經把包抽成 ≤2048，這點便宜不是精度來源。時間戳是 C1 裡把 `δξ` 與 `ξ̇` 分開的座標；不放進 `φ` 就只剩 `Δt/2` 的混疊。非同步本身不增加資訊：50 ms 包已經把事件收齊，遞推只是和的結合律。EventNet 的複數相位編碼的是贏者的年齡，不是速度。

**相對最近的方法，變化在哪一層。** 相對 PEPNet / PAT / 空間事件雲：觀測從「事件點雲 → 絕對位姿」改成「事件相對 prev 剪影的殘差」。關聯仍是 S37 路由，不是新的圖。狀態更新從注意力或 LSTM 改成可加矩。計算從 O(N) 或 O(N²) 的集合編碼改成 O(1) 累加。相對 EventNet：聚合從 max 改成和，因為殘差是質量不是存在性。相對 Zubic / Mamba：不用 LTI 或選擇性 SSM 去記根，避免舊狀態在零殘差時仍輸出。

**為什麼可見性修復、時序濾波、換表示不夠。** 可見性只改 `a` 的支撐，不產生法向殘差的空間分布。時序濾波與 `δ`-trust 是不看事件的增益，上下文已把它們排除在創新點之外。換成 LNES、TORE、EST 或 PointNet，若最後仍全局池化，旋轉偏移場仍不可辨；若保留像素格再接 CNN，那是另一條稠密網路，不是根新息頭，也沒有「幾何只乘殘差」的結構。

**什麼結果直接否定。** E1 中 P0 與 P1 的 root 誤差沒有差距；或 P2 相對 P1 的改進落在探針噪聲內（否定 H2）；或零殘差包仍產生非零根項；或 float64 遞推與批次和不一致（實作混入了圖特徵）。任一條成立就不要把「遞歸點集」寫成 root 的貢獻。

## 8. 限制與誠實聲明

- 深讀 21 篇的公式來自本次打開的 arXiv 或 CVF/AAAI PDF 文字層。EventNet 式 (3) 的相位是「覆寫」還是「累乘」與排版抽出的式子不完全一致，數值核對的是「保留相位 + 線性模長衰減 + 時間旋轉」這一讀法，沒有作者程式。
- TORE 讀的是 arXiv v1，不是 TPAMI 終稿。Wagstaff、Phased LSTM、Mamba 以預印本為準；Mamba **不是**已發表會議論文。
- 未讀全文：WACV 2019 空間事件雲、3DV 2024 雙手、3DV 2022 事件點雲姿態、Ren TPAMI 2025、HOTS 原文、CES、PRE-Mamba。Ev2Hands 這個名字在 Crossref 標題中沒有命中。
- Hand mesh（CVPR 2024）只讀了問題設定，未當作深讀。
- 除 PointNet 的 `pointnet_cls.py` 外，未核對其他論文程式。EventNet 的 GitHub 檢索為 0。
- CCF 與中科院分區未對到官方表，表內一律待核。
- 合成槓桿不是 zgz 的真實投影。旋轉不可辨性是二維剛體場上的線性代數，不是閉環 RA。float32 是否破壞 0.05 mm 復現門，沒有跑追蹤。
- H2 未被實驗否定，只是先驗上最脆。H1 的代數部分有數值支持；它是否降低 RA，本檔沒有證據。
