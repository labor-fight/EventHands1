## 0. 根路径计算图（核对后的精确形式）

【代码事实】`model/model.py`（当前文件行号；`00_CONTEXT` §3 表中的 825 / 1133 / 1380 等为旧行号，语义一致）：

1. **根头构造**（routed + active_head）：`ev_dim = 2*hidden+1 = 257`，`root_head = Linear(feat + 16*ev_dim, 6) = Linear(512+4112, 6) = Linear(4624→6)`（`model/model.py:860-863`）。
2. **根头前向**：`root = root_head(cat([feat, evidence.flatten(1)]))`（`_decode_active`，`model/model.py:1172-1179`）。`feat` 来自 EventGNN 全局 mean‖max 读出；`evidence` 为 `(B,16,257)`。
3. **prev_mlp**：`51→64→ReLU→51`，末层零初始化（`model/model.py:891-898`）；加到 Δ 上（`1518-1524`）。
4. **残差**：`out = delta + prev`（`PREDICT_DELTA`，`1525-1530`）；空包时 `ZERO_EVENT_GATE` 把整包 Δ 置零。轴角与平移均**直接相加**，无 SO(3) 复合。
5. **MANO 解码**：`pose_repr.decode_to_mano_inputs` 切出 `transl / global_orient / local`（`model/pose_repr.py:81-106`）；`ManoLayer.forward` 把 `global_orient` 作为链根旋转（`model/mano_layer.py:118-169`）。
6. **损失**：`split_losses` 得三块 MSE，再 `(λ_pose·L_local + λ_r·L_root + λ_t·L_t)/51`（`model/model.py:198-210`；默认 λ 450/60/30000）；`training_step` 对标量再包 `log10`（`462-464`，`LOG10: true`）。

一步根状态：

\[
\begin{aligned}
\Delta_{\text{root}} &= W[f;\, e_0,\ldots,e_{15}] + b + g_{:6}(\text{prev}),\\
\begin{bmatrix}t\\ r\end{bmatrix}_{\text{out}}
&= \begin{bmatrix}t\\ r\end{bmatrix}_{\text{prev}} + \Delta_{\text{root}},
\end{aligned}
\]

其中 \(g=\mathrm{prev\_mlp}\)（不看事件），\(r=\mathrm{prev}[3:6]\) **不进**根头线性层；prev 进根的几何通道只有路由 \(a(\mathrm{prev})\)（`_route_nodes`，`1384-1392`）。【代码事实】【与 `S37_ROUTED_READOUT_PREREG.md` §9.1 公式一致】

## 1. 轴角加法 vs SO(3) 复合；§9.1 左雅可比论断

### 1.1 加性更新的几何误差

网络实现的是 \(r_{\text{out}}=r_{\text{prev}}+\delta\)（轴角向量加），而非 \(\mathrm{Log}(\mathrm{Exp}(r_{\text{prev}})\,\mathrm{Exp}(\delta))\) 或左乘/右乘相机系小旋转。

【实验事实】CPU 蒙特卡洛（`.experiments/lit_hyp_20260929/A2/root_geometry.json`，|aa| 取训练分布中位附近）：

| \|aa\| (rad) | \|\δ\| (rad) | 加性 vs 复合 夹角 p50 |
|---|---|---|
| 2.0 / 2.3 / 2.6 | 0.05（≈TF 量级） | 2.21° / 2.45° / 2.65° |
| 2.3 | 0.087（≈5°） | 4.27° |
| 2.3 | 0.262（≈15°，roll 上沿） | 12.8° |
| 2.3 | 0.30（课程大噪声 σ） | 14.6° |

训练 `|aa|` 中位约 2.30、p95≈2.67（`.experiments/s37_debug_20260928/rot_s3407.json` `data.train_aa_norm`；`S37_ROUTED_READOUT_PREREG.md` §9 点 7）。在 **TF 干净 prev、δ~0.05** 下，表述误差约 **2.2–2.7°**，已与「50 ms 真实转动 1.6–3.0°」同量级，是 TF 6–8° 噪声底的一部分，但不是主因。【实验事实】

### 1.2 §9.1「朝向轴离散 → 固定线性映射够用」核对

§9.1 排除的是另一件事：根头不知 \(r_{\text{prev}}\) 时，相机系角速度 ↔ 轴角增量的**左雅可比** \(J_l(r)\) 随朝向变化；若朝向轴只散开 3–6°，一个**固定**线性映射可达方向余弦 0.994–0.998。【实验事实】`S37_ROUTED_READOUT_PREREG.md` §9.1

CPU 复核（同产物 `fixed_map_cosine`，|aa|=2.3）：

| 轴锥半角 | cos(真 \(J_l\delta\) vs 均值 \(\bar J_l\delta\)) p50 | cos vs 恒等映射 |
|---|---|---|
| 3° | **0.9998** | ~0.57 |
| 6° | **0.9990** | ~0.57 |
| 15°（domrand roll 半幅） | **0.9940** | ~0.58 |
| 30° | 0.977 | ~0.58 |

- 【代码事实】恒等映射余弦只有 ~0.57：在 |aa|≈2.3 时 **不能**把 δ_aa 当成相机系小旋转；§9.1「θ/2≈61–70°」量级正确。
- 【推断】「单个固定线性映射 0.994–0.998」在 **3–6° 轴散度**下成立；在 **domrand roll ±15°** 下仍落在其下沿（0.994），尚未明显破裂。
- 【推断】roll 是绕光轴的**标签复合** \(R_g\leftarrow Q_z R_g\)（`semkine/domrand.py:184-191`），会把朝向轴在训练集上再拨开最多 ~15°；若评测无 roll，测试分布比训练更「轴聚」，固定映射在测试上更安全。加性 vs SO(3) 复合误差（§1.1）与左雅可比近似误差是**不同**两件事；§9.1 排除的是后者，**未排除**前者。

## 2. 像素证据 → 米制平移 / 弧度旋转：几何量与根头可见性

### 2.1 所需几何量

【推断】针孔下，像素残差 \(\delta u\) 与状态的一阶关系大致为：

- 面内平移：\(\delta u \sim (f/z)\,\delta t_{xy}\)
- 深度平移：依赖轮廓缩放 / 面积，需 \(z\) 或等价尺度
- 绕腕旋转：\(\delta u \sim (f/z)\,(\omega\times \ell)\) 的投影，需**杠杆臂** \(\ell\)（关节/顶点相对腕的 3D 或投影 2D 臂）与深度

故从像素域证据恢复米制 \(t\)、弧度 \(r\)，至少需要：\(\{f,c\}\)（或 \(K\)）、深度 \(z\)、杠杆臂 \(\ell\)，以及「观测 − 预测」残差（事件相对 prev 投影的偏移）。【推断】

### 2.2 实际进入根头的量

| 量 | 是否进根头 | 出处 |
|---|---|---|
| 全局池化 \(f\)（512） | 是 | EventGNN readout |
| \(e_j\)：LBS 加权均值 / hard-max / **coverage** | 是 | `routed_readout.py:93-118` |
| 节点特征内的 \(x/W,y/H\)（绝对归一化坐标） | 间接经 \(e\) | token；**不是**相对 prev 的偏移 |
| 路由距离 \(d\)、顶点 id | **否**（过 16 px 门后丢弃） | `routed_readout.py:7-12`；`model.py:1384-1392` |
| \(K\)、顶点深度 \(z\)、\(r_{\text{prev}}\)、\(t_{\text{prev}}\) | **否**（\(K,z\) 只服务于 no_grad 路由投影） | `_project_prev` / `_intrinsics` |
| `prev_mlp(prev)` 的 6 维 | 加性并入 Δ，**不**经根头 | `1518-1524` |

【代码事实】

### 2.3 domrand：roll vs scale/shift

【代码事实】`semkine/domrand.py`：

- **roll**（默认 ±15°）：同步改事件像素、\(R_g\leftarrow Q R_g\)、\(t\leftarrow Q(j_0+t)-j_0\)（`184-191`）；几何自洽。
- **scale/shift**：只改 \(K'=AK\)（`193-195`），**3D 标签不动**；事件像素按 \(q\mapsto a R(q-c)+c+\mathrm{d}p\) 移动（`199-223`）。注释写明这是纯内参变化（`21-30`）。

【代码事实】`_resolve_betas_K` / `_intrinsics`（`1049-1084`）：批内 `camera_K` 乘 `RENDER_SCALE=0.375` 得渲染焦距/主点；路由与渲染用这份 K，**根头线性层不读 K**。

【推断】后果：

- 网络被迫对「同一 3D 手 + 不同 \(K\)」在根头输出上近似**不变**（标签 \(t,r\) 未随 scale/shift 变），同时事件绝对坐标 \(x/W,y/H\) 与路由投影一起变。相对剪影残差若被学到，可保持；但根头看到的是绝对坐标池化特征，缺少显式 \(f/z\)，**尺度–深度–面内平移**纠缠被推给线性层用统计相关硬解。
- **对平移**：scale 改变 \(f\) 等效于改变 \(z\) 的像素杠杆；看不见 \(K\) 与 \(z\) 时，\(t_{xy}\) 与 \(t_z\) 更易与「手在画面上的绝对位置」混淆 → 与 §9 平移每步乱动（global 20–28 mm）相容。【推断】【实验事实】§9
- **对旋转**：roll 有标签同步；scale/shift 不改 \(R_g\)。旋转主要靠剪影朝向，对焦距一阶不敏感，但杠杆臂的像素长度 \(\propto f/z\) 变了而 3D \(\omega\) 标签不变 → 同一像素残差对应的 rad 刻度漂移，根头又无 \(f/z\) 条件。【推断】

## 3. 损失：log10、课程噪声份额、Wiener 收缩

### 3.1 log10 对梯度

【代码事实】先算加权 MSE 均值 \(L\)，再 `log10(L)`（`model/model.py:462-464`）。\(\partial\log_{10}L/\partial\theta = (\partial L/\partial\theta)/(L\ln 10)\)：整体梯度被 \(1/L\) 压缩，**不改变** batch 内谁贡献 \(\partial L\) 的相对结构。大残差样本仍通过 \(\partial L\) 主导。【推断】

### 3.2 课程三档对根旋转 MSE 的期望贡献

【代码事实】`dataset.py:221-251`：mixed 下 50% 小噪声（σ_r=0.05）、30% 大噪声（0.3）、20% 定向（幅度 \(U[0,0.3]\)）；噪声**加性**写在轴角上（`prev = prev + noise`，`352-356`）。

在「残差 ≈ 噪声」（身份预测 / 训练早期）下，\(E[\|ε_r\|^2]\) 份额（产物 `curriculum_mse`）：

| 档 | 权重 | \(E[\|ε\|^2]\) | 对总期望的份额 |
|---|---|---|---|
| 小 | 0.5 | \(3\times0.05^2=0.0075\) | **4.1%** |
| 大 | 0.3 | \(3\times0.3^2=0.27\) | **89.3%** |
| 定向 | 0.2 | \(0.3^2/3=0.03\) | **6.6%** |

每轴方差比 \((0.3/0.05)^2=36\)。【实验事实】（本产物算术）

【推断】**是**：在 MSE（及包了 log10 的同序损失）下，根旋转的训练信号**绝大部分来自 prev 很错的大噪声样本**。小噪声 / 干净样本（测试闭环的常态）对损失贡献极弱。

### 3.3 与 §9.1 Wiener 解释；可证伪预测

【实验事实】§9.1：`prev_mlp` 根斜率 ≈ 课程噪声下的平均收缩；分工况最优增益小噪声 0.02 / 大噪声 0.41 / 干净 0，模型对所有样本用 ~0.3。

【推断】公式核对：文档写 `−Σ_n(Σ_r+Σ_n)^{-1}` 与「mix var 0.0302、σ_r=0.30/0.345/0.417 → −0.34/−0.30/−0.24」。用**标准差**形式 \(-\sigma_n/(\sigma_r+\sigma_n)\)（\(\sigma_n=\sqrt{0.0302}\)）得约 **−0.37/−0.34/−0.29**，接近文档；正统**方差** Wiener \(-\sigma_n^2/(\sigma_r^2+\sigma_n^2)\) 得约 **−0.25/−0.20/−0.15**。实测斜率（−0.30/−0.24/−0.25 与 −0.33/−0.32/−0.31）介于两者之间，定性「往均值收缩」成立，精确对角系数口径有一点点含糊。

【待实验验证的假设】在**不改课程、不改损失**的前提下，任何只改根头结构（更深 MLP、加残差特征、加 \(r_{\text{prev}}\) 通道等）的臂，闭环根旋转仍会被推回 ~10–13° 的常数增益收缩稳态；TF 干净样本仍注入 ≳4°。

可证伪预测（建议预注册）：

1. 若仅改根头结构、课程/损失不变 → 闭环根旋误差相对 S37 **改善 < 1.1 mm 对应的角度**（或打平），且 `prev_mlp` 根斜率仍在 −0.2…−0.4。
2. 若把大噪声档权重降到 ≈0（或 σ_r 大档 ≤0.05）并保持同一新结构 → TF 干净注入应降到接近原地运动（≲3°），且纠正增益随「prev 误差大」升高（不再常数 ~0.3）。**若 (2) 也不降，则否证「课程主导」**，转而支持编码/信息上限（M2/M5）。

## 5. RA 与 global_orient 绕点；杠杆系数

### 5.1 是否绕 J0

【代码事实】`ManoLayer`：`J = shaped(betas)` 回归得到，`rel_joints[0]=J0`，根旋转进入链根变换；domrand 文档式 \(V=R_g(V_{\mathrm{rest}}-j_0)+j_0+t\)，\(j_0=J(\beta)[0]\)（`domrand.py:32-36`）。**是：global_orient 绕 rest-pose 腕关节 J0 旋转；J0 随 betas 变**（零 β 时 \|J0\|≈96 mm，见产物）。`transl` 加在 FK 之后（`mano_layer.py:165-167`）。腕的相机系位置 = J0 + transl（恒等姿态下关节 0 与 J0 重合，产物 `wrist_at_identity ≈ J0`）。

### 5.2 θ → RA 的系数

RA 只减腕、不对齐旋转（`00_CONTEXT` §2）⇒ 根旋转误差 θ 导致的关节 RA 约为 \(\theta\cdot\mathbb{E}_i\|(J_i-J_{\mathrm{wrist}})\times u\|\)（垂直杠杆），不是简单 \(\theta\cdot\mathbb{E}\|J_i-J_w\|\)。

【实验事实】CPU（`mano_lever`，零 β + 7 个随机 β，mean pose）：

- 平均关节–腕距离：104–109 mm（朴素 θ·d 会偏高）
- 有限差分 RA/θ（绕相机 x/y/z）：约 **41 / 93–97 / 95–99 mm/rad**，三轴均约 **76–80 mm/rad**
- §9 / `rot_s3407.json` `sens.root_mm_per_rad`：global **62.8 / 67.0 / 95.4**，local **54.7 / … / 83.3** → 文档 **55–95 mm/rad** 与真实姿态分布上的灵敏度一致

【推断】系数核对通过；「θ × 平均腕距 ~106 mm」是上界量级，轴依赖的 55–95 才是 RA 实际灵敏度。

## 7. 最可能被推翻的结论与未核实项

**最可能被推翻**：§3.3「任何只改结构、不改课程/损失的根头改动都会被推回均值收缩」——若新结构提供了真正的观测−预测乘性新息且**保留**适度先验，有可能在同课程下仍过门（rootinnov 设计故意杀回拉，不是反例）。

**未核实**：

1. 训练受试者上 `|aa|` 轴方向的经验分布 p50=3–6° 的原始直方图（只见 §9.1 文字，未重跑 `probe_rot`）。
