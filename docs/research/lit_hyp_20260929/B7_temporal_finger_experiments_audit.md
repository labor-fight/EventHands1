## 1. `update_ratio_pose` / `alignment_pose`：定义、零假设、0.25–0.26 的读法

### 1.1 代码里其实有两套「alignment」【代码事实】

任务点名的 `tools/run_closed_loop_probe.py:150-172`：

- 记 `d_pred = pred − prev`，`d_need = GT(end) − prev`，姿态切片为 `[6:51]`（45 维局部关节轴角，**不含**根旋转）。
- **`update_ratio_pose`** = `mean(||d_pred[6:]||) / mean(||d_need[6:]||)`（先对各帧取模长再平均，再相除）。
- **`alignment_pose`** = `mean( ⟨d_pred[6:], d_need[6:]⟩ / ||d_need[6:]||² )` —— 这是把更新投影到「所需更新」上的**标量系数**（完美同向同模 → 1；纯欠更新同向 → 小于 1；方向错时即使模长对也会变小）。注释写的是 projection，不是单位向量余弦。

但 §6 表里引用的 0.98 / 0.26 来自 `outputs/semkine/probe_s37_route.json`，由 `tools/probe_s37_route.py:249-290` 计算：

- **`update_ratio_pose`** = `Σ||d_pred|| / Σ||d_need||`（与上面几乎同值）。
- **`alignment_pose`** = `mean( ⟨d_pred, d_need⟩ / (||d_pred|| · ||d_need||) )` —— **真方向余弦**。

【实验事实】两种子均值（`probe_s37_route.json` → `arms.s37_routed`）：`update_ratio_pose=0.983`，`alignment_pose=0.263`。S36 为 0.956 / 0.254。`closed_loop_s36_s37routed.json` 里 TF 的 `alignment_pose` 是投影系数（约 0.28–0.30），勿与 §6 的 0.26 混读。

`probe_decomp.py` 的 `cos_fingers` 用的也是真余弦（`cosine_similarity`）：global 0.267 / 0.281，local 0.247 / 0.251；手指模长比 ≈ 0.94–1.04（`decomp_s340{7,8}.json` → `tf.*.delta_norm`）。

### 1.2 无偏但有噪声估计器的零假设【推断】（仿真见产物）

设 `d_pred = d_need + ε`，`ε ∼ N(0, σ² I_D)`，`D=45`，定义 SNR = `||d_need||/σ`。

| 量 | 无偏加性各向同性噪声下的期望 |
|---|---|
| 投影系数 `⟨d_pred,d_need⟩/||d_need||²` | **恒为 1**（与 SNR 无关） |
| 真方向余弦 `⟨u,v⟩/(||u||||v||)` | ≈ `SNR / √(SNR²+D)` |
| 模长比 `E||d_pred|| / ||d_need||` | ≈ `√(1 + D/SNR²)` |

要对齐观测到的余弦 ≈ 0.26，无偏模型需要 SNR ≈ 1.83，此时模长比期望 ≈ **3.81**（解析 + MC：`.experiments/lit_hyp_20260929/B7/alignment_null_hypothesis.json`）。

观测是 **模长比 ≈ 0.98 且余弦 ≈ 0.26**。这与「低 SNR 无偏」**不相容**：后者若余弦到 0.26，更新会大 3–4 倍；若模长比到 1，余弦应接近 1。

随机方向、模长匹配的零点：`E[cos]≈0`（MC ≈ 0.002），`E[cos²]=1/D≈0.022`。观测 0.26 明显高于纯随机，说明仍有弱同向分量，但主导是**正交分量**。

### 1.3 判读【推断】

**0.25–0.26 应读作方向系统性偏离（模长被训到接近「所需步长」，方向大部分正交），不是「无偏估计器信噪比低的自然结果」。**  
等价图像：在 45 维里，有效同向增益约 0.26，夹角 ~75°；训练目标/课程使 `||Δ||` 贴近真实步长，却学不到正确方向。

根旋转上同一机制更极端（`decomp` TF：`cos_rot` 仅 0.05–0.11，模长比 2.3–3.6）——【实验事实】`decomp_s340*.json` `tf.*.delta_norm`；PREREG §9 点 2。

### 1.4 CNN 逐帧作为「更新」时的方向余弦——当前算不出

【实验事实】`outputs/semkine/probe_s37_cnnroot.json` 只有闭环/融合后的 RA、`ra_art`、`rot_deg`，**没有**逐帧 `pred51` 或 `d_pred`。CNN 配置为绝对回归（`PREDICT_DELTA: false`），若把更新定义为 `d_pred = cnn_abs − prev_GT`，需要一次 TF 前向才能算余弦。

【待实验验证的假设】需要：在 zgz 同一 `valid_runs` / 50 ms 网格上，对 `s37diag_cnnabs` 存 `(prev_GT, pred_abs, GT_end)`，用与 `probe_s37_route.py:252` 相同的真余弦公式报 `alignment_pose` 与 `update_ratio_pose`。**当前证据不足以**给出 CNN 的方向余弦数字。

## 2. 手指：global 冻结更好；local 每步位移 3×

### 2.1 「冻结在段首」的代码语义【代码事实】

`probe_decomp.py:130-131`：`freeze_fingers` 每步执行 `pred[6:51] ← prev[6:51]`。段首初始化后手指不再改，故效应等于**手指锁在段首（+init 噪声）**。`ref.hold.ra_art` 是整姿态保持段首时的仅手指 RA 分量。

### 2.2 global：与根「干净 prev 注入误差」同族，但是手指版【实验事实】+【推断】

| 量（global） | 3407 | 3408 | 出处 |
|---|---|---|---|
| hold 仅手指 RA（段首相对真值） | 5.64 | 5.64 | `decomp_*.json` `ref.zgz_global.hold.ra_art` |
| 模型闭环仅手指 RA | 8.78 | 5.97 | `closed.*.base.ra_art` |
| 冻结手指后总 RA | 13.43 | 15.21 | `freeze_fingers.ra`（基线 15.66 / 15.97） |
| TF 手指模长比 / 余弦 | 0.94 / 0.27 | 0.96 / 0.28 | `tf.delta_norm` |

【推断】global 上真手指相对段首只动 ~5.6 mm，模型手指误差 6–8.8 mm ≥ 不动；冻结手指总 RA 更好。机制与根类似：**prev 已接近真值时，头仍输出与所需近正交的「更新」→ 注入误差**。差别：根是旋转噪声底（TF 6–8° vs 真动 1.6°）；手指是「可动幅度本就小于估计噪声」。  
【待实验验证的假设】若在 global 上对干净 prev 把手指头增益乘 0（或 trust→0），应复现 freeze 收益；当前只有 hard freeze 证据，**不足以**定量拆出 prev_mlp 手指分量 vs 事件头各自贡献（`prev_mlp_norm.fingers_rad` global 已达 0.82 rad，远大于 GT 步长 0.38，是强线索但非因果）。

### 2.3 local 每步关节位移 ≈ 真值 3×：噪声主导，不是经典过冲【实验事实】+【推断】

【实验事实】`regime_s37_routed_s340*.json` `closed.zgz_local`：`jitter_all_mm_per_step` 11.06 / 11.67，对 `gt_move_mm_per_step` 3.79 → 比约 **2.9–3.1×**（PREREG §8 写 3×）。参数空间 TF：手指模长比 ≈ 1，余弦 ≈ 0.25（§1）；平移模长比 ≈ 20×（`pred_trans_mm` 54 vs `gt` 2.7）。

- **经典过冲**：同向且投影系数 / 余弦远大于 1，模长比大于 1。  
- **观测**：手指余弦 ~0.25、模长比 ~1 → **正交噪声 + 模长匹配**；闭环关节 mm 的 3× 是 FK 后「每步乱走」的幅度，不是沿真运动方向增益大于 1。  
平移 20× 才是明显的过推/注入。

【推断】local 手指误差 16.8–17.2（hold art 23.5）说明「有一定跟踪」，但方向差；3× 位移应标为**噪声再注入 / 信念跳动**，不宜称为过冲。  
**当前证据不足以**在「每关节过冲」与「各向同性参数噪声」之间做更细分解（缺逐维符号一致性统计）。

【实验事实】`window_s340{7,8}.json`；PREREG §9.3：

| W ms | 均值递推 RA | global 根旋 ° (7/8) | global 仅手指 RA (7/8) | local 仅手指 RA (7/8) |
|---|---|---|---|---|
| 50 | 20.74 | 11.3 / 11.6 | 8.78 / 5.97 | 16.77 / 17.24 |
| 300 | 20.90 | 12.4 / 10.5 | 7.01 / 4.98 | 18.48 / 18.62 |

global 手指 Δ ≈ **−1.8 / −1.0 mm**；根旋转在 10.5–12.4° 内打转；总 RA 均值 ±0.4 mm 打平。  
**local 手指随 W 变差**（+1.7 / +1.4 mm）——§9.3 正文只强调 global 手指收益，未强调 local 恶化。

【推断】对假设「手指受信息量限制、根不受」：

- **根**：**支持「不受（当前编码下的）证据量限制」**——6× 事件窗口 + 1/6 递推步数，旋转误差不变 → 瓶颈在逐包表示/读出上限（与 §9.2 信息探针、§9 固定噪声底一致），不是包太短。

- **手指（local）**：更长窗口**没有**帮助，甚至变差 → **当前证据不足以**把「手指一律信息受限」做成全局结论；local 稀事件 / 短段动力学可能另有瓶颈（路由、覆盖、或步长–窗口耦合）。

## 4. TF 训练序列 → zgz 差距：S37 为什么更不迁移

【实验事实】`probe_s37_route.json`：

| 臂 | 训练 4 序列 TF 均值 | zgz TF | gap |
|---|---|---|---|
| S36 两种子均 | — | 9.17 | **0.48** |
| S37 两种子均 | — | 9.78 | **1.79**（约 3.7×） |
| S37-3407 | 7.59 | 9.02 | 1.43 |
| S37-3408 | 8.41 | 10.55 | 2.14 |

S37 在训练受试者上 TF **更低**，到 zgz 反超变差 → 更像过拟合 / 表征绑死训练受试者，而不是单纯「两边都差一截」。

### 候选原因与区分检验【待实验验证的假设】

| # | 候选 | 为何可疑 | 区分检验（零训练优先） |
|---|---|---|---|
| C1 | 路由用 GT betas，zgz 手型 ≠ 训练 | 路由 LBS 行依赖 betas；评测两边都用**本序列** aux betas（`probe_s37_route.py:226`），不是「训练 betas 测 zgz」。更可疑的是**训练时**每样本真 betas 使头记住手型–证据耦合 | 评测时把 zgz 的 betas 换成训练受试者均值 / 另一人 betas，看 TF RA 与路由纯度变化；若大变 → C1 |
| C2 | 证据含绝对图像坐标（x/W,y/H），绑相机–受试者取景 | token 含绝对坐标（`encoder.py`）；domrand scale/shift 只改 K | 评测对事件做与训练同分布的 shift/scale（只动坐标/K），看 gap 是否缩小；或比 S36（共享全局池化、无部位路由）对同一扰动的灵敏度 |
| C3 | 受试者手型 / 运动风格（非 betas 通道） | 训练 TF 更好、留出更差 | 按序列拆 gap（已有：`lyq_local` 上 S37 8.87 vs S36 12.20——S37 在难序列上更「吃透」）；在训练受试者上做 leave-one-sequence-out TF |
| C4 | 路由读出过拟合部位外观 | 大噪声纯度 0.14；闭环纯度 0.54 仍赢 | oracle 路由在**训练序列** vs zgz 的 TF 差；证据置零后 gap 是否消失（置零后若 gap≈0 → 差距在证据通路） |
| C5 | 与 S36 相比，S37 手指头无全局旁路，更依赖路由几何 | 契约：他关节证据梯度为 0 | 同一 checkpoint 用 GT 路由 vs 自路由的 train–zgz gap |

【实验事实】PREREG §9 点 7 写「受试者迁移（训练受试者上同样的底）」是针对**根旋转噪声底**，与本节 **TF RA 的 train–zgz gap** 不是同一命题——根底在训练受试者也存在，不否定 H4 的单步 gap。

**当前证据不足以**在 C1–C5 中点名单一主因；只确定「S37 单步更不迁移」是稳健现象。

## 5. local 列构成：多少是初始化优势？

### 5.1 数字账【实验事实】

- 协议：90 段、均 ~0.7 s、每段 GT+小噪声起步（`00_CONTEXT.md` §2；`eval_track.py:159`）。
- 保持段首 RA：**28.16**（两种子相同，`regime` / `decomp.ref`）。
- 模型闭环 local：23.33 / 29.49 → 均值 **26.41**；相对 hold 仅 **−1.8 mm**（3407 −4.8，3408 **+1.3**）。
- 帧时间结构（`train_s3407.json` `elapsed_zgz_local`）：0–250 ms 占 136/1204≈11%；0–1000 ms 约 392/1204≈33%（与 §9「33% 帧在初始化后 1 s 内」一致）。0–250 ms 上模型 RA 17.8/20.9，hold 已 10.5——**一上来就差于 hold 的短时误差**，优势出现在中后段相对 hold 的追赶（3407），3408 在 0.25–2 s 明显差于 hold。

【推断】local 列对 EventHands-PCA6 baseline（30）的「赢」**很大程度上是协议红利**（短段 + 反复 GT 复位），不是长时跟踪。相对同协议 hold（28.2），两种子均值只好 1.8 mm，且一籽失败 → **「跟踪能力」信号弱**。  
初始化优势的粗下界：若把「能赢 hold 的部分」算跟踪，则均值约 1.8 mm；主表 26.41 相对 30 的 3.6 mm 里，**有多少来自与 baseline 不同协议/选点不可比**——PREREG §8 已警告 baseline 不在同一批帧，**当前证据不足以**把 26.41 vs 30 拆成「初始化 vs 跟踪」的干净比例。

同包迭代（local）：远起点 8 次 → 26.8 / 36.1，**不收敛到 GT**；闭环 23.3 / 29.5 ≈ 从 GT 迭代 8 次的 19.1 / 27.6 同量级而不是远起点——说明 local 列读的是「短时自洽信念 + 反复复位」，不是从任意初值锁定手指。

### 5.2 建议诊断协议（不改主表口径）【推断】

主表仍报 local / global RA。旁路诊断（写入各臂 prereg / ledger，不进 `report_table`）：

1. **hold-gap**：`RA_model − RA_hold`（按序列）；local 采纳门槛建议要求两种子均 &lt; 0（赢 hold）。
2. **burn-in 剔除**：丢掉每段前 200–500 ms 再均 RA（或只报 elapsed≥1 s 子集）。
3. **同包迭代收敛点**（已有）：`fixpt gt_8` / `far_8`；local 要求 far 向 gt 移动。
4. **可选长段**：把 local 段拼接或降 init 频率（每 N 秒才复位），专测漂移——仅诊断。

## 6. 「同包迭代收敛点 ≈ 闭环误差」：实现核对

### 6.1 迭代定义【代码事实】

`probe_regime.py:76-89`：固定该包事件 `ev5`，`x ← forward_packet(ev5, x)` 迭代至多 8 次；记录 n∈{1,2,4,8} 的 RA。起点：`gt` = 上一步时间的 GT 姿态；`far` = `run["init"]`（段首 GT，无噪声）。`stride=2`：每隔一包做一次（global 693 / local 602 包，PREREG §8）。

### 6.2 与闭环同一 rng、同一段划分？【代码事实】+【实验事实】

| 项目 | 闭环 `closed()` | 同包迭代 `probe_seq` |
|---|---|---|
| 段划分 | `ET.track_sequence` ← `valid_runs_ms` | `runs_of`（注释写明与 `track_sequence` 相同枚举） |
| rng | **共享** `default_rng(0)` 跨序列（`probe_regime.py:102-105`） | 迭代**不用** init 噪声；copy/hold 用真 GT |
| 与主行 | 3407：15.66382 / 23.33449，逐位复现 | 同文件内对照 |

与 `make_s36_row.py:81-82` 相同：共享 `rng(0)` 顺序跑 val_core 序列。

【实验事实】收敛 vs 闭环：

| | 闭环 | gt_8 | far_8 |
|---|---|---|---|
| global 3407/3408 | 15.66 / 15.97 | 13.38 / 16.14 | 14.53 / 16.83 |
| local 3407/3408 | 23.33 / 29.49 | 19.09 / 27.55 | 26.85 / 36.09 |

【推断】

- **global**：far_8 与闭环同落在 ~14–17 mm，**支持**「稳态 ≈ 逐包信念」；gt_8 略优于闭环（13.4 vs 15.7）——闭环还叠了 init 噪声与逐步自洽误差，不是数学恒等。
- **local**：**弱支持 / 部分不成立**——远起点不收敛到闭环（尤其 3408 远走至 36）；闭环更接近「从较真 prev 出发的信念」而非唯一不动点。PREREG §8「收敛点 ≈ 闭环」的强表述对 local **过满**。
- 额外不对齐：fixpt 只在 stride=2 子集上平均；闭环用满帧。差异通常小，但 **当前证据不足以**声称逐包数值恒等。
