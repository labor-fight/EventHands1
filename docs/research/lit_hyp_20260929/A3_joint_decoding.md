## 2. LBS 混合与硬分派

### 2.1 硬分派规则

**【代码事实】** `pool_joint_evidence`（`routed_readout.py:107-114`）：

1. 仅对 `a.sum(-1)>0` 的节点参与；
2. `j_hard[i] = argmax_j a_ij`（因 `a_i = W[v(i)]·gate`，等价于所选顶点 LBS 行的 argmax 关节）；
3. `peak_j = amax_{i: j_hard=i} h_i`；`count_j = |{i: j_hard=i}|`；
4. `count_j=0` 时 peak 置零。

加权均值则用**软**权重：`mean_j = Σ_i a_ij h_i / Σ_i a_ij`（可含 argmax≠j 的节点）。

### 2.2 列污染与支撑（CPU，静止 LBS 矩阵）

定义（对列 `j`）：质量 `m_v=W[v,j]`；**污染占比** = `Σ_{v: argmax W[v]≠j} m_v / Σ_v m_v`；再按 argmax 关节相对 `j` 分为父 / 子 / 兄弟 / 其他。产物：`.experiments/lit_hyp_20260929/A3/lbs_fk_stats.json`。

**【实验事实】** 污染最重 / 支撑最小（节选）：

| 关节 | 污染 | 父 / 子 / 兄弟 | W>0.1 顶点数 | argmax 顶点数 |
|---|---|---|---|---|
| thumb_cmc (13) | **0.469** | 0.348 / 0.118 / 0.001 | 59 | **20**（最少 argmax） |
| pinky_mcp (7) | **0.281** | 0.114 / 0.159 / 0.007 | **41**（最少 W>0.1） | 23 |
| ring_mcp (10) | 0.253 | 0.088 / 0.137 / 0.022 | 52 | 30 |
| thumb_mcp (14) | 0.218 | 0.085 / 0.078 / 0 | 50 | 31 |
| index_mcp (1) | 0.213 | 0.100 / 0.103 / 0.010 | 53 | 33 |
| 各 DIP / thumb_ip | 0.056–0.077 | 几乎全是父 | 62–67 | 52–54 |

**【推断】** MCP / CMC 是「掌指交界」混合带：软均值大量掺入腕或子关节表面事件；硬 max 只跟 argmax 顶点，缓解软污染但丢弃非主权重节点。拇指 CMC 近半质量来自 argmax≠自身（主因父=腕）。小指 MCP 支撑最窄 → 路由稀疏时最易「硬零、软稀」。

## 3. 坐标系：父骨骼相机系朝向离散度

头输出的是**父系局部轴角增量**；证据是路由后的**相机系**节点特征（无显式 `R_parent`）。用训练集抽样 ≤2 万帧 + `zgz_{local,global}` 各 ≤2 万帧，GT `pos51` + 与 `decode_to_mano_inputs` 相同的 `+hands_mean` 后做旋转链，取关节 `j` 的父关节全局旋转 `R_{parent(j)}`，相对该集 chordal 均值的测地角（°）。

**【实验事实】** 分层（层内关节中位/p90 的平均；详见 `lbs_fk_stats.json`）：

| 层 | train 中位 / p90 | zgz_local 中位 / p90 | zgz_global 中位 / p90 |
|---|---|---|---|
| MCP（父=腕=global_orient） | 15.3° / 29.3° | **8.5° / 16.4°** | 11.5° / 17.1° |
| PIP（父=MCP） | 23.9° / 61.3° | **30.9° / 78.2°** | 13.7° / 22.0° |
| DIP（父=PIP） | 27.0° / 100.9° | **35.0° / 151.6°** | 14.4° / 23.7° |
| THUMB | 21.2° / 43.5° | 18.3° / 37.4° | 12.1° / 21.3° |

**【判读】**

- **MCP**：zgz 上父系（腕朝向）离散中位约 8–12°、p90≈16–17°——不是「几度固定」，但也远小于 PIP/DIP。固定隐式映射对 MCP **可能勉强**，但不能排除中等条件化收益。
- **PIP/DIP（尤其 zgz_local）**：父系朝向 p90 达 **几十到一百多度**——若证据含相机系方向信息，**缺少 `R_parent` 条件化在结构上无法稳定解码父系增量**（对应候选机制 M4）。
- **zgz_global** 各层都更集中（局部关节活动少）→ 与「local 手指差、global 相对好」的现象方向一致，但是否因果仍待 §5 零训练检验。

**【推断】** 「坐标系假设是主因」对 **PIP/DIP** 比 MCP 更说得通；对 MCP 单独作主因证据不足（离散不够大）。

## 4. 没有逐关节门；`f(0, θ)` 非零

### 4.1 门控对照

**【代码事实】**

- S37 routed：仅整包 `ZERO_EVENT_GATE`（`counts<=0` 时整段 Δ=0，`model.py:1527-1530`）；**无**逐关节门。
- mesh_query 对照：`seen = (cov>0)`，手指头输出乘 `seen[:, k+1]`（`model.py:1412-1419`）——无覆盖则该关节不更新。

### 4.2 zgz_local 上「路由到 0 节点」频率

GT prev、50 ms 包、抽样 400 包、与 `event_gnn` 相同 stride 抽样后跑 `route_front_vertex_lbs` + `pool_joint_evidence`。产物：`zero_route_and_f0.json`。

**【实验事实】**

- 软零（`wsum_j=0` → `e_j` 全零）：手指均值 **1.3%**；最差 `index_dip` 4.0%、`index_pip` 2.8%。
- 硬零（`count_j=0` → peak 零，但 mean 可非零）：手指均值 **6.5%**；最差 **`pinky_mcp` 16.8%**、`ring_mcp` 11.3%、`index_*` ≈8%。
- 腕几乎总有路由（soft/hard 0）。

**【推断】** 在 **GT 路由** 下「完全无节点」不常见，不是主失败模式；`pinky_mcp` 硬零偏高与 §2 窄支撑一致。闭环 / 大噪声 prev 下纯度下降（`probe_s37_route.json`：闭环 purity 0.54、大噪声 0.14）→ 错路由与软污染会升，**未在本脚本重测闭环零率**（见末节）。

### 4.3 `f(0, θ)`：选中 checkpoint CPU 前向

选中步：`selection_val_core_step50.json` → 3407 step **2500**，3408 step **5000**。对每头输入 `[0_{257} ‖ θ]`。

**【实验事实】**

| 种子 | 均值 ‖f(0,0)‖ | 最大 ‖f(0,0)‖ | 15 头非零偏置 | 均值 ‖∂f/∂θ‖@0 |
|---|---|---|---|---|
| 3407 | **0.147 rad**（≈8.4°） | 0.292（thumb_mcp） | 15/15 | **0.70** |
| 3408 | **0.186 rad**（≈10.7°） | 0.363（middle_pip） | 15/15 | **0.72** |

θ 网格（含 0.05/0.3/0.5 噪声）上 ‖f(0,θ)‖ 中位约 0.28–0.46 rad。

**【结论】** `f(0,θ)` **是非零偏置且强依赖 θ**（像「无观测时仍按 θ 收缩/推动」），不是恒零。缺逐关节门时，无证据关节仍被头+`prev_mlp` 推动——与 mesh_query「未见则不动」相反。

## 5. 手指头容量（260→64→3）与「幅度对、方向余弦 ~0.26」

**【代码事实】** routed：`ev_dim=2·128+1=257`，`Linear(257+3 → 64 → 3)`（`model.py:861-871`；`ACTIVE_HIDDEN: 64`）。半宽瓶颈。

**【实验事实】** `probe_s37_route.json`：S37 TF `update_ratio_pose≈0.96–1.00`，`alignment_pose≈0.26`（S36 同量级 0.25）；即**步长尺度接近、方向接近正交**。

### 5.1 四种机制与零训练检验

| # | 机制 | 为何会导致「幅度对、方向错」 | 零训练区分检验 |
|---|---|---|---|
| A | **父系 vs 相机系** | 头把相机系特征当固定基底解父系 Δ；父系旋转（§3）一大，最优线性映射随姿态转，平均方向余弦→低，范数仍可被损失校准 | **Oracle 父系条件**：冻住权重，只在头输入拼接 `vec(R_parent)` 或 `R_parent^T` 作用在 mean/max 特征上，用 **ridge/线性** 拟合 Δθ*；若方向余弦相对现头显著↑（而同容量无 R 的线性探针不变），则坐标系是可分因素。对照：仅 MCP（父离散小）应增益小于 PIP/DIP |
| B | **证据 LBS 混合** | `e_j` 掺父/子表面运动 → 更新指向邻关节自由度 | **硬一分派证据**：用仅 argmax=j 的节点重算 `e_j`（或把软权重投影到 one-hot），同一冻结主干+线性读出；若对齐↑且 MCP/拇指增益最大，则混合是主因。对照：DIP（污染<0.08）应几乎不变 |
| C | **证据无方向信息** | EdgeConv 感受野 ~ms（`00_CONTEXT` §3），mean/max 不编码「绕哪根轴转」；头只能学幅值先验 | **证据→Δθ* 互信息上界**：以 `e_j`（及可选 θ）做 ridge/MLP 探针拟合真 Δθ*（TF，GT prev）；若方向余弦上界仍≈0.26 而 ‖Δ‖ 比拟合好，则信息本身缺方向（与 A/B 正交：即便完美坐标系/硬分派也救不了）。可与「完美路由 z」（根上 R²≈0，§9.2）对照 |
| D | **大噪声样本主导损失** | 课程 30% 大噪声（0.3 rad）+ 参数 MSE：最优是大幅值收缩，方向被噪声平均掉 | **按噪声分层的 TF 对齐**：同一 checkpoint，仅在小噪声 / 干净 prev 子集上算 `alignment_pose`；若干净子集余弦≫0.26 而大噪声子集≈0，则训练目标主导。再：**损失重加权反事实**（只评估、不训练）——对已有包按小噪声权重重算「若头输出沿真方向投影」的理想对齐，看差距是否集中在大噪声包 |

**【推断】** 四者可叠加。现有证据更偏向 **C（信息）与 D（目标）在根/整体已有旁证**（§9 TF 与运动量无关；prev_mlp Wiener 收缩），**A 对 PIP/DIP 结构上成立但未测**，**B 对 MCP/拇指 CMC 结构上成立**。容量 64 本身不像主瓶颈：线性探针若已无方向，加宽头也无效——先做 C 的信息上界。
