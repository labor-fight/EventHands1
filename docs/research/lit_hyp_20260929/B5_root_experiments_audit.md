## 3. M1（常数增益）vs M2（逐包系统偏差时相关）

### 3.1 有无逐步误差序列？

**【实验事实】** `.experiments/s37_debug_20260928/*.json`、`regime_*.json`、`probe_s37_*.json` **均无**长度≳数百的 `rot_err` 时间序列，只有均值与分箱。  
因此：**未能**计算 lag 1–20 自相关、最优常数增益、最优一阶滤波可达误差。

需求与成本见：`.experiments/lit_hyp_20260929/B5/README_NEEDED_FOR_AUTOCORR.md`（扩展 `probe_decomp` 导出 npz + CPU 脚本；无训练）。

### 3.2 已有事实对 M1 / M2 的支持与反对

**M1 支持**【实验事实】+【推断】  
- 根更新可加可分 `F(事件;a(prev))+G(prev)`（代码/§9.1）；G 斜率 ≈ Wiener 收缩。  
- 干净样本上加 `r_prev` 改善扰动、恶化干净（info：pert↓ clean↑）——典型常数 K 权衡。  
- trust0.5 变体存在于 decomp（global 3407 15.66→15.09，改善有限）。  
- K0/K1/K2「落在同一条常数增益权衡线上」——**【已删记录，未复核】**，仅能引 `docs/research/dir12_20260928/00_CONTEXT.md` §4。

**M1 反对 / 不足**  
- 闭环 69 s 误差不增长、同包迭代收敛点 ≈ 闭环（§8）→ 更像「每包信念误差平台」而非「增益把误差放大成漂移」。  
- rootinnov 试图做样本依赖增益，G2 未过——**不能**反证 M1（混杂实验）。  
- **无**逐步序列上的最优 K / 滤波下界 → 当前证据不足以量化「M1 可救多少 mm」。

**M2 支持**【实验事实】  
- 同包迭代：信念收敛点 ≈ 闭环稳态；放大率应读成稳态/TF 比，非传播增益（§8）。  
- TF 在 global 主质量区近似与运动/事件无关 → 固定信念噪声，而非「这一包运动没看清」。  
- 窗口加长根旋不动；CNN 换根 −3.8 mm → 瓶颈在逐包绝对根质量。  
- info：干净样本解码器仍相对 hold 注入数度。

**M2 反对 /  нюанс**  
- local TF 随运动量上升 → 并非全局「纯系统偏差、与运动无关」。  
- prev_mlp 回拉在闭环中承重（no_prevmlp 发散）→ 存在**与状态相关**的纠正通道，不完全是与历史无关的 iid 信念噪声。  
- 若误差高度时相关，滤波无用；**未测自相关**，故「滤波完全无用」**【当前证据不足以支持】**。

**判别结论（本审查）**：现有证据更偏向「闭环误差由逐包根旋信念主导（M2 核心）」；M1 描述的是**训练诱导的更新代数形式**，二者可同时为真（形式是常数增益，稳态误差仍是时相关信念偏差）。**严格证伪其一需要逐步序列 + 滤波上界实验。**

## 4. §9.2 信息探针：泄漏、正则与「干净仍注入 3.9–5.0°」

### 4.1 拟合集 / 测试集 / 正则【代码事实】

- 拟合：9 受试者训练序列 28800 包；测试：zgz 2590（`info_*.json` `n_train`/`n_test`；`probe_info.py`）。  
- Ridge：在拟合集前 85% 上选 `λ∈{1e-2…1e3}`，再全拟合集重训（`probe_info.py:206-221`）——**λ 选择未碰 zgz**，无测试泄漏。  
- MLP：拟合集 90% 训练、10% 早停；`weight_decay=1e-4`；种子固定（`probe_info.py:224-246`）。  
- 特征：S37 **冻结**图+在**扰动 prev** 上的路由；目标=把扰动 prev 转到包终点 GT 的旋转。

### 4.2 可能的信息泄漏 / 乐观偏差【推断】

| 来源 | 风险 |
|---|---|
| oracle 事件深度用**包终点 GT 网格**深度 | 上界实验，故意乐观；文档已承认 |
| 「有 GT 深度的事件占比」通道未加噪 | dz_sweep 已写偏乐观 |
| 残差特征用手写几何，与后续 rootinnov 实现相近但非同一数值路径 | 探针好 ≠ 可训头好 |
| 扰动分布（±12° 等）≠ 闭环自预测误差分布 | 外推到闭环弱 |
| z 含路由错误信息；完美路由 R²≈0 | 说明 z 的「新息」部分来自路由失配，不是独立观测 |

**无受试者泄漏**：训练受试者拟合 → zgz 测试，符合留出协议。

### 4.3 「干净样本上所有解码器仍注入 3.9–5.0°」含义

- hold 干净子集误差 ≈ **2.25°**（包内真实运动）。  
- 解码器在干净 prev 上输出非零修正，使误差升到约 **3.5–5.0°**（z-ridge≈3.5；残差/含先验≈3.9–5.0）。  
- **含义**【推断】：在该单包 MSE/回归目标下，最优解码器仍学到「平均要动一点」；即使 prev 正确也会注入噪声。这与 rootinnov G1（干净仍 5.3–5.7°）同方向。  
- **不是**：证明几何上不可观；也不是闭环保证。  
- 措辞修正：CONTEXT「所有解码器 3.9–5.0」略偏高下界（z-ridge 3.5）。

## 5. 「根旋转是逐包绝对估计的上限」——置信度与推翻实验

### 5.1 该结论在文档中的用法

prereg §9.3 / ROTW 前言：根旋误差不随窗口、路由正误、新息头、损失×10 而降，故视为「事件编码 + 根读出」的**逐包绝对估计上限**。

### 5.2 置信度

| 子句 | 置信度 | 理由 |
|---|---|---|
| 在**当前 S37 权重与读出结构不变**时，加长评测窗口不降根旋 | **高** | window JSON 直接支持 |
| 根旋是当前闭环 RA 的最大单因 | **高** | oracle_rot 12.4 |
| 「任何」改进都必须走更好绝对根估计 | **中** | CNN fuse 支持杠杆存在；但路由混杂、选点增益未剥离 |
| 已是该事件前端的**信息论上限** | **低** | 119 维残差/深度上界更低；编码器感受野/表述未穷尽；rootinnov 是混杂失败 |
| 滤波/增益无法再抠点 | **低–中** | 缺自相关与滤波上界；M1/M2 未判别完 |

**综合**：对「当前栈下根旋≈逐包信念误差、且是主瓶颈」置信度 **中高**；对「已达绝对估计上限、无需再试结构」置信度 **低**。  
凡把后者写成定论处，应标：**当前证据不足以支持该结论**。

### 5.3 能推翻或收紧该结论的实验

1. **逐步误差自相关 + 最优 K / 一阶滤波**（§3）：若滤波相对闭环再降 ≥1.1 mm → 上限不只是「逐包绝对」。  
2. **路由固定消融的 CNN fuse**：只换输出 R vs 只换路由 R → 量化「绝对根」纯贡献。  
3. **保留 prev_mlp 的新息头**或信息形式增益（非冻结短训）→ 若 G1/G4 过，则「上限」被结构打破。  
4. **GNN 绝对头**（不读 prev、不 delta）或加长感受野后重训 → 若根旋 TF 显著低于 6–8°，则非「事件前端不可达」。  
5. **网格中位/非选点**上报 CNN 与 S37 → 排除选点夸大绝对根杠杆。
