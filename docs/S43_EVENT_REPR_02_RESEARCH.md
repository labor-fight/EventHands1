## 0. 本轮身份、边界与执行方式

### 0.1 问题与假设（承接 01）

核心问题（01 §5.1，原文）：**在固定 β/K、可部署（可能错误）前态与因果查询合同下，单目事件流中有哪一类被 last-LNES 的整毫秒覆写、固定窗截断与"查询即整幅重算"丢弃或掩盖的证据，能够在新受试者上改变 MANO 更新的可辨识方向（而不是更准地重现训练先验），并且这种改变在闭环评测中可测？**

本文把它拆成两半来回答：(a) "哪类证据被丢弃 / 掩盖"（01 的 E / R / N / M 四分类，信息项 I1–I11）；(b) "哪类改变在闭环里可测"（前态环路、评测口径、功效）。三条假设 H1（证据等价类）、H2（前态污染与事件盲先验）、H3（可辨识性与测量）沿用 01 §5.2。

**第一轮的共同结论（十份报告自评的交集，主线程归纳）：**
1. 没有一个视角主张"更丰富的事件表示会更准"；R 类的任务价值在十份报告里一致被判为"未证且先验低"，条件全部挂在 Stage 5 `field_box` 的同预算检验与零训练审计（M-②b / M-④-1 P1–P3 / M-⑧ A1）上。
2. 八个视角（①③④⑥⑦⑧⑨⑩）独立地把杠杆放到 **N**（读出 / 接口 / 前态进入方式）与 **M**（评测口径 / 功效 / 判定面），这与 01 §3.6 的机制签名一致：误差主体是新受试者上的逐帧映射偏差，不是 Δ 的测量。
3. 四个视角（②④⑦⑩）各自独立得出"查询必须只读、提交必须显式"这一接口性质；它不是精度杠杆，但是所有多假设 / 诊断 / 任意时刻查询的前提。
4. 两个视角（③⑨）独立推出同一个上限论证：一阶低通的 DC 增益恒为 1，任何保留率 / 增益 / 可靠度机制都碰不到持久的映射偏置，只改瞬态；收益若只出现在 zgz_local 段首 1 s 内，属协议锚点（M），不是机制。

### 5.3 三个候选

> 三个候选在"前态如何进入表示"这一点上原理不同（Rev-B §2.2）：候选 I 让前态**完全不进入**事件态；候选 II 让前态成为**被评价的假设**而非测量算子的参数；候选 III 让前态只决定**标量增益与判定面**。它们分别回答核心问题的"哪类证据被丢弃"（I）、"哪类证据只有相对假设才可解释"（II）、"哪类改变在闭环里可测"（III）。三者不是三个网络变体：I 改事件侧状态与读出通道，II 改读出的算子形式，III 不改网络只改信任与判定。

#### 候选 I　像素晶格上的可加充分统计状态 + 只读差分查询

- **原理**：把每像素每极性的 last-only 幂等状态换成结合律精确的**可加状态**（整数计数 N、一阶矩 S1、二阶矩 S2、最近触发 t_last），commit 时冻结快照，查询任意 (s, t] 用快照差分；删失（无事件）由年龄显式给出，首毫秒事件不再与空槽同码。指数核（②a / ⑩b）与次序统计量（①′）作为同一容器的"核"消融轴，不单独立项。写入与前态无关（G9），查询只读、不提交（P10 合同 + C6 / C7）。
- **合并自**：M-④-1（主体）、M-②a（指数核版）、M-⑩b（多时标版）、M-①′（两点版）、M-⑩a（容器合同）、M-⑥ R_count 臂；审计 M-②b（增补版）、M-⑦b、P④ P1–P3、T-J。
- **回答核心问题的哪一半**：R / N 类——I1（多重触发 / 计数）、I2（首毫秒零码）、I4（窗前历史，仅 ≤ 200 ms）、I6（删失）。**不**承诺触及 4.9 mm 映射偏差。
- **保留 / 丢弃**：保留 (N, S1, S2, t_last) 与 K ≤ 4 份快照（≤ 200 ms）；丢层内顺序与 µs 余数（I3，本就不可得）、逐事件身份（I9）、K 份快照之前的历史。
- **闭环结构**：与 S43 逐一相同（前态只经渲染 / prev_mlp / 加性基底）；错误前态不可能写进记忆；环路增益变化只可能来自网络拿到更多事件量后是否更信前态——用 ρ 剂量响应直接测。
- **训练 / 部署同构**：exact 模式 K=1、W50 / hop50：窗 = 两快照之差，窗首 = 段首 floor，训练构造与在线容器为同一函数，位验**逐位**（G7）；不需预读、不需连续片段。decay 模式（第二版）需预读 ≥ 5τ 原始事件（G10），位验容差型，loader 吞吐先实测。
- **成本【估算，按 Rev-C】**：状态 ≈ 1.9 MB + 快照 1.7 MB；每事件 3 次整数加 + 1 次 max（4 个整数散射，C3 △）；查询 O(活跃位点)；首层 4→10 通道，MAC +≈ 1 %；graph 墙钟未测；C5 两列分母待 W50 原始链实测。
- **最接近的已有工作与区别**：TORE / HATS / 时间矩（文献）；项目内 Stage 5 `field_box`（8 bin 整数计数环，lane 体制）、REL enhanced（独立格读出）、DT2 lf。区别只在"可逆窗 + 删失显式 + 首毫秒洞修复 + 同一函数训练 / 在线 + 写入前态无关 + 只读查询"，**不声称新物理量**（除非 P1 通过）。
- **零训练阶梯（全部 CPU；D 类为主，不需样本外面）**：
  1. 工程：`lattice_state.py` 容器（exact / decay）+ 三路对拍（训练窗构造 == 在线容器 == evalx 构造）+ 段起点屏蔽测试。
  2. ②b 增补版审计（D 类 LOSO，9 人）：表示族 {last, count+last, 一阶矩, 二阶矩, 快照差分} × 目标 {GT 轮廓法向位移, 扣除前态扫掠的残差占据, **S43 单步残差 1 s 低通（Q2 长程目标）**} × 前态档 {GT, iid 噪声, E1 轨迹}；读出岭回归；门：候选表示的 ΔR² 不胜 max(C0′ 双窗 LNES, count+last) 或 LOSO 区间含 0 ⇒ 关闭；长程目标 R² ≈ 0 ⇒ 目标收窄到 ≤ 200 ms。
  3. P④ P1（层内时序含速度？按批最大位移分层的偏 Spearman）+ T-J（逆高斯抖动 CV 0.3 下增量不消失）：P1 不过只删"突发时长"通道，不关闭候选。
  4. ⑦b（原始事件时间面 vs SAE 的结构秩混淆矩阵）：角点类差异大 = LNES 淹没稀有事件的直接 R 证据。
  5. 适配层因子：训练臂对照必须含"加宽适配层 + 原 4 通道"（C0′ 同合同）。
  6. Stage 5 `field_box` 对 `s43`：只作方向性筛选（反向则下调先验，不关闭）。
- **训练臂（仅当 2–4 过门，另行预注册 + 用户授权）**：B 类，同 `s43n_sp` 配方 fresh 6000 步 × 3 种子筛选 + 追加 3 种子确认；对照 C0′（加宽适配层）与 count+last；主指标 RA，并报绝对 / 根对齐；W50 原始口径（K=1 严格 W50）。
- **最强反例与否证条件**：计数 = 外观捷径（按对比度分层增益随对比度变化 ⇒ 判死）；②b 增补版 ΔR² 不胜 count+last；训练后 ρ 高于 C0′；真实传感器无帧时钟（P1 的任何正结果不外推）。
- **不能声称**：触及映射偏差；更长记忆修 > 1 s 偏差；真实传感器零样本收益。

#### 候选 II　前态作为被评价的假设：以 S43 输出为中心的根刚体假设束 + 对比读出

- **原理**：证据不再是"前态投影 → 残差"的函数，而是"假设 → 分数"的函数：以 S43 当步前向输出 ŷ 为中心（不是前态），在根刚体 6 自由度 + σ 尺度 nuisance 轴（共 7 维）上生成对数间距阶梯假设（含 2–3 个域外远探针），一个共享小打分器在 last-LNES 上按部位取样打分，读出**只看假设间差**并只输出**方向符号 + 有界幅度**，域外时交回 S43 绝对回归。写端不变（事件态 = SAE），无新跨查询状态。
- **合并自**：M-⑥（改中心、改输出形式、加域外指示、加 σ 轴）、M-⑦a 的读端（分层后绑定；整手相似变换作第二种打分器）、M-⑤B 仅滚转版（事件侧框）作条件对照、M-⑤A 作渲染侧对照（D7 四读数）。
- **回答核心问题的哪一半**："哪类证据只有相对某个手态假设才可解释"，以及**显式输出"该方向无证据"**（E 类的诚实化，对应 H2）。预期收益只在根 / 平移 / 面内滚转（RA 盲），必须同报绝对口径与 E1 / E2。
- **保留 / 丢弃**：保留 S43 主路与 SAE；丢事件 → 顶点指派（无关联步骤）、分数绝对值、迭代；丢 I1 / I2 照旧（对 R 零贡献）。
- **闭环结构**：前态经 S43 主路进入不变；旁路中心 = ŷ（对前态保留率 0.03–0.09），故旁路几乎前态无关；域外指示避免"束外 → 恒等"锁死；重复计数由"旁路只输出对 ŷ 的修正"消除。
- **训练 / 部署同构**：同束、同打分器、同读出；训练锚点 = S43 在（GT + 噪声前态）下的真实输出误差（含映射偏差）；不需连续片段；评测仍 W50 原始 50 ms 端点。
- **成本【估算】**：根块 K≈37–45、P≈200 点、5×5×2 块、φ≈2.1 k MAC ⇒ +0.016–0.02 G（+16–20 % MAC）；graph 墙钟 +0.1–0.2 ms、CPU 2 线程 +0.7–1.2 ms（Rev-C）；每 hop 1 次主路前向 + 1 次旁路，无额外渲染（根假设是前态顶点的刚体变换）、无主机同步（固定形状）。
- **最接近的已有工作与区别**：EDOPT / MegaPose / FoundationPose（假设评分 + 选最优）、ReFit / HeatFormer（展开精修）、项目内 MV2 M5（FIPA 杀、RCA 过）、XDI、M4。区别：方向取 MANO 根运动学 + σ 轴；读出只看假设间对比且只输出符号 + 有界幅度；打分器在 v2e 事件上学习；中心是网络输出而非前态。
- **零训练阶梯（D 类，CPU ≤ 10 h）**：
  1. X-⑥ 骨架（SELECT 两人逐受试者判）：R_nn / R_lnes1 / R_pda（控制）、R_bundle（以 ŷ 为中心）、R_edf（对称化距离场）、理想事件正对照；门：理想正对照 b_off ≥ 0.8【占位】否则读出缺陷；R_bundle 在可回收方向（像面 x、面内滚转）上符号命中率 > 置乱零模型 + 边际、在 y / z / 倾斜上诚实输出"无证据"。
  2. Q1 证据可得性曲线：前态偏移 0–20 mm / 0–10° 下束对比 b_off 与域外指示命中率；E1 轨迹上前态误差 P90 处可得性须 ≥ 下限【占位】。
  3. σ 轴消融：去掉 σ 轴后 z 方向 argmax 偏移是否重现 SBA P0 的 +45 mm 形态。
  4. M-⑦b 的 Fisher 份额（GT 雅可比）决定是否加整手相似变换打分器。
- **训练臂（仅当 1–2 过门）**：B 类，旁路零初始化、对 `s43n_sp` 配对 3 种子筛选；主指标 RA + 绝对根误差 + E1 平移放大；只作"根块两方向修正器"的描述性声明。
- **最强反例与否证条件**：同位置近亲 ≥ 5 个已死；SMG 式"符号可辨幅度不可辨"若连符号命中也不过零模型 ⇒ 判死；KS1 封顶（≤ 2.4 / 1.1 mm，S39 栈）；稳态偏置只去 κ/(1+κ)。
- **不能声称**："反驳前态"的一般能力（只在可回收方向）；手指级证据（SBA R3 单窗 5 mm 优先率 0.65–0.72，指链扩展须 X-⑥ 手指族过门）。

#### 候选 III　任务状态空间：合法样本外判定面 + 前态无关证据的外挂增益 / 账本 + 只加噪的训练前态分布

- **原理**：不改事件表示、不改网络；把"该信前态还是该信事件"从训练噪声混合里隐式固定的常数，变成 (a) 一个在**受试者外**面上标定并可被 NEES / PIT / 风险–覆盖检验的显式标量增益 g（证据评分只用前态无关量；带创新项的 8 维账本是其有状态版本），与 (b) 训练前态噪声在可辨识度方向上**只加不减**的整形；并先用 S43-FIT7 诊断训练建立 SELECT 作为 S43 家族第一次合法的样本外判定面。
- **合并自**：M-⑨b（判定面 + 保守门，主体）、M-⑨a（增益形 + 创新项账本）、M-③（只加噪版、proxy-free 方向）、M-①（提交只跳过的推迟版）、M-⑧ fallback（限幅版）、M-④-2 / M-⑩a（口径与合同）、T-F / T-S（Fisher 共模与沉默自由度）。
- **回答核心问题的哪一半**："哪类改变在闭环里可测"：它改变的正是闭环里被测到的量（保留率、一步偏差、环路放大、hop 依赖），并直接判定 +4.8 mm 是受试者级映射偏差还是录制级 σ\* / 标定缺口（F3）。
- **保留 / 丢弃**：保留一切；不存跨窗学习特征；不输出后验 / Fisher；唯一新状态是账本 P（可选，有状态版才有）。
- **闭环结构**：前态进入的是标量 / 低维增益，环路增益 = 1 − g 可直接算；失败形态是"增益设错"而非"读错地方"；账本版是 18 个提案里唯一跨 > 1 s 的状态，须有创新项与周期重标定防"记得太久"。
- **训练 / 部署同构**：增益版不改训练（A 类，W50 原始 + 栈行两口径同报）；整形版改训练分布但不改推理（B 类，单 seed 停止规则 + 描述）；无连续片段 / 自展开。
- **成本**：增益版部署 +0；S43-FIT7 一次训练（GPU，排在 Stage 5 之后，由用户裁定）；整形版一个 S43 臂 + 基底表（≈ 0.9 GB，CPU 小时）。
- **最接近的已有工作与区别**：DT3 ramp1000 门（折外 −0.19）、E-3DPSM 常数增益、KalmanNet / TTT3R 写强度、Diffusion Forcing 噪声级条件化、Conformal risk control；区别：标定面在受试者外、证据评分前态无关、增益可校准检验、整形只加噪。
- **零训练 / 一次训练阶梯**：
  1. S4 存档分析器（CPU）：E0 保留率剂量响应（proxy-free 雅可比奇异方向 × 事件稀疏化 × 幅度）、E1 oracle 自适应 α 上界（逐窗逐组 α + 置换序列 + 按受试者块置换的去泄漏对照）、E3 三读数（前态误差族 / 过自信因子 / 线性放大预测）、T-F / T-S；**门：E1 上界 − 最优常数 < 0.5 mm【占位】⇒ 全族机制臂判死，只保留判定面本身**。
  2. S43-FIT7 诊断训练（用户裁定）：SELECT 单步 − 恒等、保留率、E1；F3：≤ 0.5 mm ⇒ "现象是录制级"，上报用户，族 III 机制臂关闭。
  3. 增益版 g（≤ 24 常数，在 SELECT 上拟合、搬到 9 人模型不调参）：zgz 一次读数；按初值误差 {5, 10, 20 mm} 与 > 1 s 子集分层；NEES / PIT / AURC 报告。
  4. 整形版（仅当 E0 显示盲增益且 P2 超额能量在 W）：V_rand 对照 + 只加噪臂，单 seed S3 筛选。
- **最强反例与否证条件**：DC 增益恒 1（只动瞬态 + 环路放大，≤ 3.2 / 0.9 mm，实务 ≤ KS1）；三条先验 ≤ 0.2–0.5 mm 低于 B 类 MDE（故机制只走 A 类）；SELECT 两人功效只判 ≥ 1 mm；协议锚点（按剂量分层解决）。
- **不能声称**：消除新受试者映射偏差；多种子可靠性（单 seed 诊断）；主表替换（栈行）。


## 6. 比较与推荐

### 6.1 五轴比较（主线程综合三评审分数与 §5.2；"高 / 中 / 低"是相对三候选）

|---|---|---|---|
| 科学解释力（对核心问题） | 中：直接检验"哪类证据被丢弃"（R / N），但十视角一致先验低；否定结果也有信息（关闭 R 类，把问题推回映射泛化） | 中低：检验"相对假设才可解释的证据 + 显式无证据"（H2），但同位置六次检验无一超过简单控制；正结果限于根两方向 | **高**：直接检验机制签名（映射偏差 + 环路放大）与"可测性"，并判定 +4.8 mm 的来源（受试者级 vs 录制级）；无论正负都回答核心问题的后半 |

### 6.2 推荐

**推荐候选 I（像素晶格可加充分统计状态 + 只读差分查询）作为"新事件表示"线继续，但以候选 III 的判定面与分析器包作为它开 GPU 前的强制前置；候选 II 只在 Q1 证据可得性曲线与 X-⑥ 骨架过门后作条件臂。** 理由：

1. 它是三者中**唯一真正改变事件表示**、且闭环结构与 S43 逐一相同的候选：写入前态无关、可前缀重放、exact 模式逐位位验——三位评审在"自我强化"与"一致性"两轴上都给它最高分。对"面向单目事件 MANO 重建的新事件表示"这一研究目标，它是能被干净检验的那一个。
2. 它的定量门是 **D 类 LOSO 审计**（不含 S43），不依赖样本外判定面，可以**现在就在 CPU 上做**，不与 Stage 5 争 GPU；门的两侧都有信息：通过则进入同预算训练臂，不通过则把"last-LNES 在 50 ms 内近似充分"（H1）从假设升为有读数的结论，并把研究重心正式交给映射泛化。
3. 候选 III 的科学解释力最高，但它**不是表示**；它的判定面（S43-FIT7）与分析器（E0 / E1 / Q2 长程目标）是三个候选共同需要的尺子，所以作为前置而不是作为"推荐的表示"更合适；它的机制臂（外挂增益 / 只加噪整形）上限 ≤ 环路放大，预期 0.2–0.5 mm，只走 A 类。
4. 候选 II 的 MANO 专属性最高，但同位置近亲已死 ≥ 5 个，先验最低；改中心与加域外指示后值得一个 ≤ 10 CPU·h 的 X-⑥ 骨架，不值得先开训练。
