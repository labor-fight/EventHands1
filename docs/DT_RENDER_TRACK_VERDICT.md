# DT 结论：EventHands-Track（render + SO3 + FK + DomRand）的抖动、误差与参数量

> **状态：进行中（2026-10-03 12:05），第二波训练尚在运行。** 预注册在 `docs/DT_RENDER_TRACK_PREREG.md`；它的 §1–§9 在任何 DT 臂被评测之前写下，**§10 之后是看过第一波结果之后的追加**。
> 本文的表格由 `tools/dt/verdict_tables.py` 和 `tools/dt/screen_report.py` 生成，数字不手抄。协议同 AGENTS.md：9 人 72 序列训练，zgz 既是开发集也是测试集，只报最后一步，不选点。因此这里所有结论都带"开发集 = 测试集"的限定。

## 0 结论（初稿，随结果更新）

- **目标架构本身比同网络的 MSE 版好很多。** 在统一配方下重训的 `dt_base` 递推 RA 是 11.28 mm（三个种子 11.03 / 11.52 / 11.53），`rt_cnntrack`（同网络、MSE 目标）是 13.75 mm。历史记录里的 12.22 mm 是另一套配方（batch 2048、3000 步、热启动）。
- **绝对误差的主要问题是深度泛化，不是损失权重。** 已记录的所有模型在 zgz_local（深度 699–742 mm，整条在训练深度之外，训练最大 710 mm）上深度偏小 83–112 mm；在训练序列上深度误差只有几毫米，与深度无关。网络把"受试者外观 → 深度"当作捷径记住了。
- **深度一致的尺度增强（`dt_dz`）把绝对 MPJPE 从 57.4 降到 35.8 mm（−21.6 mm，两个种子 −24.4 / −18.8），RA 持平（11.19 对 11.28）。** zgz_local 的深度回归斜率从 0 回到 0.8–1.1。按预注册的门通过；护栏 G6 以 0.001 的幅度触发，按 §10.2 登记的偏离采纳，种子 3409 补齐后复核。
- **平移监督（`dt_tr`）、去掉尺度增强（`dt_nos`）、去掉 `prev_mlp`（`dt_nopm`）都没有通过门。** `dt_tr` 把抖动减半（acc_err 12.1 → 6.8），但 RA 变差 2.5 mm；与 `dt_dz` 组合（`dt_trdz`）绝对 MPJPE 到 24.8 mm、抖动 −37%，RA 变差 1.7 mm。
- 其余臂（SO(3) 合成、射线平面、屏蔽 `prev_mlp` 的平移输出、半宽 / 去 layer4 骨干及其与 `dt_dz` 的组合）、零训练滤波、参数量和延迟见下文，**待结果补齐**。

## 1 问题与口径

问题和约束见预注册 §0。度量：
- RA = 根对齐 MPJPE（主表口径，递推）；绝对 MPJPE 含平移，两者在 zgz 两条序列（global 1386 帧，local 1204 帧）上按帧加权。
- 抖动：`jit_pred`（绝对关节的一阶差分，mm / 步）、`acc_err`（预测减 GT 的二阶差分范数，mm / 步²，对 GT 自己的运动不计分）、`acc_ratio`；GT 自己的运动 `jit_gt` 5.81、`acc_gt` 3.93。
- 判定：按预注册 §5，同种子配对（3407 / 3408），1.1 mm 为平局带，种子 3409 作确认。

## 2 Stage 0：零训练诊断

### 2.1 抖动归因（D0a，76 条已记录运行，`outputs/dt/reports/jitter_offline.md`）

把 `acc_err` 按平移 / 根旋转 / 手指做 Shapley 归因（反事实混合：以 GT 为底，只把某一块换成预测再做 FK）。独立复核者重算了全部 4047 个单元格，全部吻合。
- 最大贡献块：平移 71 次、根旋转 5 次、手指 0 次（去掉两条逐位相同的评测后 73 / 5 / 0）。份额中位数：平移 68%（22–87%），根 22%，手指 9%。
- `rt_cnntrack` 是例外：平移 39–41%，根 37–39%，手指 21–22%。
- 历史目标架构（`track_render51_dr_so3fk`，第 3000 步）：`jit_pred` 12.07 / 13.16，`acc_err` 16.2 / 17.2，平移份额 63% / 64%；`evalx` 复现旧评测器的 RA（12.254 / 12.192，误差 1e-6）。
- `dt_base`：`acc_err` 12.1，其中只保留平移时 10.9，即 so3_trans_fk 的弱平移监督让平移抖动成为主项。

### 2.2 常数增益滤波套在已有 `rt_cnntrack` 上（D0c，`outputs/dt/reports/filter_cnntrack.md`）

增益事先固定（根 0.5、手指 1.0、平移 0.5）。增益为 1 时两个种子的评测与记录值逐位一致（419 / 419 个共有 json 叶子，68 / 68 个逐步数组）。
- RA −0.46 mm（−0.55 / −0.37，在平局带内），`acc_err` 8.26 → 5.50（−34%），根角加速度 3.64° → 1.56°，绝对 MPJPE −1.14 mm，global 根速度比 1.53 → 1.00。
- 复核者指出：根扰动保留率对真实跟踪器不是 (1−g)^k，而是 ((1−a)+aρ)^k（ρ 是跟踪器自己的一步响应，约 0.2–0.25）；对无响应的替身模块 (1−g)^k 精确成立（误差 2e-7）。预注册 §3 的"滤波律"门按后一种读法。
- 敏感性组合（描述性，不用于选增益）见该报告。

### 2.3 渲染分解（D0b，`outputs/dt/reports/render_breakdown.md`；该报告的独立评审因额度限制未完成）

- 空闲机器上现有前向 3.73 ms（与记录的 3.8 ms 吻合），234 个 kernel、17 次主机同步：15 次在 `ManoLayer.forward`（用 CUDA 张量做列表下标，每次触发 `.item()`），2 次在渲染的布尔索引。
- GPU 实际忙碌约 0.9 ms，其余是主机发射开销。去掉同步并缓存每序列的 MANO 项（输出逐位相同）省 21%；整次前向做成 CUDA graph 重放为 0.66 ms（−82%，逐位相同，仅批 1、仅推理）。
- 预注册的判据"渲染 + FK 仍 ≥ 40% 才试半分辨率渲染"字面上成立（44%，负载下测量），但不值得做：与像素数成正比的 kernel 只占 GPU 忙碌时间的 3.7%，半分辨率最多省约 23 µs。杠杆是 kernel 数或 CUDA graph，不是分辨率。
- 变更没有并入训练代码：训练受数据加载（CPU）限制，同步不是瓶颈；补丁在 `outputs/dt/reports/render_fast_patch/`，只用于部署形态的延迟测量。

### 2.4 深度结构（D0d / D0e / D0f，预注册 §1 的 F4、F13、F14）

- 已记录模型的 zgz_local 深度偏差 −83 至 −112 mm（−12% 至 −15%），zgz_global +18 至 +38 mm；预测深度对 GT 深度的回归斜率 global 0.3–0.7，local −0.3–0.5。`tools/dt/transl_structure.py`。
- 在训练序列上，同一检查点的平移误差整个深度范围（489–660 mm）都只有 3–4 mm（教师强制）和 4–9 mm（闭环），偏差对深度的斜率接近 0。`tools/dt/depth_insample.py`。
- 推理期把 `prev_mlp` 的 z 输出置零，zgz_local 平移误差 90.6 → 36.1 mm，zgz_global 22.7 → 54.8 mm；置零根旋转输出则闭环崩溃。`tools/dt/ablate_eval.py`。
- 手的大小不是混杂因素：由各序列的 MANO betas 算出的中指长度（腕到指尖）在 18 个训练序列上 172.5–176.1 mm（标准差 1.2 mm），zgz 是 173.3 mm（−0.7%），所以像素大小对深度是一个干净的线索，网络本可以读它。
- 解释：9 个受试者每人两条序列，local 序列深度几乎不变；网络把受试者外观当作深度先验。现有尺度增强（标签深度不变）强化了这个捷径，深度一致的尺度增强（`dt_dz`）打破它。

- 滤波在三个臂上都把 `acc_err` 降 30–44%，RA 不变差（−0.2 至 −0.3 mm，在平局带内），预注册的"滤波有效"判据（ΔRA ≤ 0 且 acc_err 下降 ≥ 15%）成立。
- `dt_base` / `dt_dz` 滤波后的 `acc_err`（6.8 / 7.0）与 `dt_tr` 裸跟踪器（6.8）相同：平移监督（C1）带来的抖动下降，用零训练的滤波就能得到，而且不付 RA 代价。
- 代价：10° 根扰动的一步保留率从 0.17 升到 0.57（滤波使纠偏变慢），第 5 步 0.06 → 0.09–0.10，仍然恢复；global 根速度比从 1.23–1.28 降到 0.88–0.90（GT 为 1）。
- 滤波的运行开销：`anchor_blend` 在主机上用 float64 numpy 算一个包的 51 个数，约 0.1 ms；部署中本来就要把状态读回主机。
