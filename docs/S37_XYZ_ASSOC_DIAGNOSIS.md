## 2. 五类假设：代码位置、诊断实验、结果与证据等级

实验代号：P1 = 零训练来源标签对照（`outputs/xa/step1/`）；P2 = 单检查点效应探针（`outputs/xa/step2/`）；A/B/C = 冻结权重只换关联几何（`outputs/xa/step4/geom/`）；D/E = 置信度缩放、几何通道消融、扰动恢复（`outputs/xa/step4/conf/`）；P3 = 配对重训（`outputs/semkine/xa_*`，§4）。冻结权重探针的基线闭环 RA 与选点网格逐位一致（22.9343 / 14.0670 / 33.1421），猴补直通与未打补丁逐位相同，每个 hook 有调用计数。所有区间为步块 bootstrap（块长 20）95% 区间。

### 2.1 时间与几何是否错位

| 项 | 结论 | 证据 |
|---|---|---|
| 事件时间戳是否参与关联 | **不参与**。关联只用 (u, v)；t 只进 token7 的 t/Δt 与 SAE 差分 | 【码】`xyz_mesh.py::associate_rays` 输入无 t；`encoder.py:162-170` |
| 整包是否共用一份旧网格 | 是。≤2048 个抽样事件全部对 FK(prev) 的静止网格关联 | 【码】`model.py::_xyz_mesh_forward` 一次 FK、一次 `associate_rays` |
| prev 对应时刻 | 评估：上一步预测，名义 = 窗首前 1 ms；训练：窗首真值 + 噪声 | 【码】`eval_track.py:199-208`，`dataset.py:392-412` |
| 重叠窗口 / 时间精度 | 评估窗不重叠，事件不重复；t = ms + tsub（亚毫秒） | 【码】`_window_events` |
| 包内运动造成的关联偏移 | zgz 50 ms 真实关节位移中位 global 3.4 px、local 1.9 px，从不（global）/ 0.5%（local）超过 16 px 带宽 | 【验·零训练】`/tmp/motion_stats/out.json`（上轮） |
| 包内时间错位对分配的影响 | 窗首真值 R0 对事件时刻真值 R3：轮廓错配率 M local 6.3% 对 6.0%，global 1.3% 对 0.7%（滞后贡献 +0.3 / +0.6 pp） | 【验·零训练】P1 T1-c |
| 包内时间错位对输出的影响 | TF 下把关联几何换成事件时刻真值网格（B1）：RA **+0.53** [+0.44, +0.63] mm（local +0.89），三检查点同号；只换分配（B1g）+0.17 | 【验·冻结】B 组；方向为"更正确的几何更差"，说明是分布外而非改善空间 |

判定：包内时间错位是真实存在的近似，但在 zgz 的运动幅度下对分配的影响 <1 pp、对输出 ≤0.5 mm，且冻结网络对"更正确几何"的响应是变差。**前态误差对关联的破坏（一致率 −39 pp）比时间错位大一到两个量级**。

### 2.2 几何命中是否被误当成正确对应

| 项 | 结论 | 证据 |
|---|---|---|
| 硬选单面再重心分配 | 是：`t.min(dim=-1)` 选唯一最近面，`wb` 重心权重只在该面 3 顶点内（面内软插值）；不同面之间无软关联；near 分支至多 4 顶点、高斯权 | 【码】`xyz_mesh.py` hit_first 分支（`tmin, fsel = t.min(-1)`；`A_hit = wb/Σ`） |
| hit 直接给高置信 | 是：q = 1、valid = 1，与是否轮廓、是否被遮挡无关 | 【码】`parts["q"].append(where(is_hit, 1, q_near))` |
| 候选漏掉正确部位 | 16 角距候选对真值前态：局部 0.84% [0.52, 1.24] 的 live 事件有更近的面未被候选覆盖（深度改进中位 10.4 mm），global 0%；near→hit 0.025% | 【验·冻结】C 组命中集合统计 |
| 候选漏检对输出的影响 | 全 1538 面搜索：TF RA +0.027 mm，闭环 +0.07 [−0.03, +0.14]（噪声内） | 【验·冻结】C 组 |
| 轮廓事件命中掌心 / 另一指 | 真值前态下 local 手指轮廓事件 6.3% [5.8, 6.9] 被判给关节 0（指尖在掌前的步 11.6%），这些事件 99.5% 经 q = 1 命中、z_prior 偏深中位 +30 mm；global 1.3%、深度误差 ≈0 | 【验·零训练】P1 T1-a/d |
| 遮挡与回退 | 命中优先于 near，正反面同算；near 前景层无深度下界、无法向判据，轮廓 2 px 内 11–13% 的 near 质量在背朝相机的顶点 | 【码】`:196-233`；【验·零训练】上轮几何实测 |
| 命中率 ≠ 对应正确率 | 真值前态 local hit 76.2% 但精确部位一致率 80.6%、手指组 89.6%；闭环 hit 仍 76.7% 而一致率只有 41.9% | 【验】P1、P2-a |

判定：**"命中 = 对应"的生成假设在指掌交界处确实错，且 hit 标志掩盖了它（已确认的实现 / 建模问题）**；但在 zgz 的频率（6.3%）下，它对根更新没有可测效应。替代规则（遮挡轮廓双假设 + near 背面过滤）把 M 降到 0.7%，对应训练臂 xa_ctr 见 §4。

### 2.3 关联置信度是否真正影响最终更新

| 项 | 结论 | 证据 |
|---|---|---|
| 均值通道 | mean = Σwφ/Σw，对 q 的均匀缩放**逐位不变**（实测 s = 0.25 / 0.5 时 mean、peak 逐位相同） | 【码】`xyz_mesh.py:471`；【验·冻结】D1 |
| max 通道 | peak = amax(φ) 不乘权重，低权重事件完整进入 | 【码】`:472-474` |
| q 的唯一作用路径 | log1p(mass) 与残差槽 r = 1 − q；把这两路换回基线后输出与基线逐位相同（0 / 2590 包改变） | 【验·冻结】D1 路径隔离 |
| 缩放响应 | s = 0.25：|Δrot| −14.8% [−16.7, −13.0]，TF RA −8.5%，闭环 overall −7.6%（global +13.9%，local −18.2%）；其中残差槽路径贡献 −12.3%，mass 路径 −1.7%；**符号跨种子不稳**（s3408：TF RA +12.1%，闭环 +3.5%）；s = 0（全部进残差槽）：|Δt| +285%，闭环 80.8 mm | 【验·冻结】D1 / D5，预注册判读 J1 不成立（变化 >5%） |
| 只缩放 near / hit | near 置 0：TF RA +20.5%；hit 置 0：|Δt| +32% | 【验·冻结】D2 / D3 |
| 少量事件是否主导 | 只留 5% 事件：peak 相对变化 97%；只去 5%：12.7% → peak 由多数事件决定，J2 不成立 | 【验·冻结】D4 |
| 零事件 / 无效候选 | 空包 δ = 0 逐位返回 prev；无效事件 q = 0 进残差槽 | 【码】`model.py:2540-2542`，`xyz_mesh.py:215-221` |

判定：置信度**不是可靠性权重**：它不改变顶点特征的均值与峰值，只改变残差槽的内容与 mass 标量；网络对它的响应是非单调、跨种子变号的。这是已确认的实现事实；它是否构成瓶颈无法由冻结探针判定（分布外），本轮未设对应训练臂。

### 2.4 XYZ 究竟提供了什么新证据

| 项 | 结论 | 证据 |
|---|---|---|
| 来自当前事件的量 | 像素 (u, v)、t、极性；经关联后只剩"哪个顶点被哪些事件命中"（O、mass、φ 聚合）与 near 事件的侧向偏移 | 【码】§1.2 |
| 由 prev 推导的量 | 交点深度 z_prior、dXYZ（hit 记录法向分量恒 0，面内重心偏移 ≤0.8 单位）、边向量；都是 prev 的函数，残差对 prev 误差恒零 | 【码】`:357-359`；小噪声下 z_prior 误差与前态 z 误差相关 0.72（[XYZ-SCREEN]） |
| 冻结消融 | no_dxyz：TF +12.3%、闭环 +28.5%（global +62.8%）；**no_z：TF −25.2%、e_rot −33.9%**，闭环 −1.6%（global +12.6%）；no_edge：TF −4.7%、闭环 −5.4%；no_geom：TF −10.9%、闭环 +130%（global +404%）；z_median：闭环 −3.5%。三检查点方向一致 | 【验·冻结】E1（分布外，只说明敏感性） |
| 事件扰动响应 | 事件整体 +4 px：平移更新幅度 ×1.54，变化量与 +x 余弦 0.81、幅度为期望位移的 1.03 倍；换成 1 s 外的事件：平移更新 ×7.8；空包：0 | 【验·冻结】E3 |
| 前态扰动恢复（TF k=1） | 平移 R_excess global 0.54 / 0.60 / 0.25（x/y/z），local 0.27 / 0.24 / 0.69；旋转 0.31–0.43 / 0.57–0.63；单指 0.54 / 0.76；10 步后残余 0.06–0.31；串扰：xy 平移 → 根旋 +1.6–1.9°，旋转 → 平移 +2–5 mm | 【验·冻结】E2 |
| 匹配预算 C0 | 末步 19.62（19.20 / 20.02）对 C1 22.55（22.93 / 22.16）：overall +2.93 在 τ 内；**local +6.88（+7.03 / +6.73）≥ τ 6.36，两种子同号 → 显式 3D 通道在 local 上有害**；global −0.49 | 【验·配对训练】G3 |

判定：网络对当前事件的 2D 位移确实有正确方向的平移响应（E3），对前态扰动有部分恢复（E2）；但显式 3D 通道里 z_prior 在冻结消融下是有害的（去掉后 TF 根旋转误差降 34%），dXYZ 的作用是"面内位置 + near 偏移"而非位移信号。XYZ 提供的"新证据"主要是 near 事件的侧向偏移与覆盖模式，深度与法向全部是先验。

### 2.5 关联信息是否被下游有效使用

## 6. 结论分级

**已确认的实现问题（有代码行与零训练 / 冻结实测，效应层未证明为瓶颈）**
- 命中优先把指掌交界的手指轮廓事件以 q = 1 判给掌部，深度错 +30 mm（`xyz_mesh.py` hit 分支；P1）。效应：P2 两判据不支持；训练臂 xa_ctr 见 §4。
- near 分支无法向判据与深度下界，轮廓 2 px 内 11–13% 的 near 质量落在背面顶点（`:213-218`）。
- 置信度只经残差槽与 mass 进入特征，mean 归一化、peak 不加权（`:433-475`；D1 路径隔离逐位证明）。
- 16 近邻候选漏掉更近面：local 0.84% 事件、中位 10 mm（C 组），效应 +0.03 mm。
- 整包对静止窗首网格关联：对分配 +0.3 pp、对输出 ≤0.5 mm（B 组）。

**实验支持的性能瓶颈**
- 关联自指（问题 1）：三检查点上"更正确的分配"都使闭环变差乃至发散（A1），而用正确分配训练的 xa_orc 大幅改善（含泄漏）；z_prior 冻结去除后 TF 根旋转误差降 34%。替代解释：orc 泄漏、A1 分布外；需 §5 R1/R2 与无泄漏上界臂裁决。
- 显式 3D 通道在 local 上有害（G3）：匹配预算 C0 比 C1 好 6.9 mm（两种子 7.0 / 6.7，≥ τ 6.36），overall / global 无差；与 E1 no_z 冻结去除后 TF 根旋转误差 −34% 同向。可解释的直接原因是 z_prior 以 (z − 0.45)/0.1 原始标量进入关系编码器而 zgz_local 深度 699–742 mm 有 86% 的步超出训练最大深度 710 mm；替代解释（dXYZ / 边向量本身有害）未分离。
- 规则级修正无可测收益（G2）：遮挡轮廓双假设 + near 背面过滤把 local 错配率从 6.3% 降到 0.7%，配对训练 overall +2.46、local +4.42 mm，均在噪声底 τ 内，两种子幅度分裂。
- 前态误差放大与跨块串扰（问题 2）：闭环 local 一致率 −39 pp；扰动恢复 0.25–0.7、10 步残余 0.06–0.31；xy 平移 → 根旋 1.6–1.9°。替代解释：训练 prev 分布与架构耦合未分离。

**尚未验证的设计风险**
- 根轴角直接相加、读出不含 prev 平移、固定噪声 teacher forcing、非因果抽样：均为代码事实，本轮无单变量臂。
- 置信度非单调响应是否构成瓶颈：冻结缩放为分布外，需 §5 W1。
