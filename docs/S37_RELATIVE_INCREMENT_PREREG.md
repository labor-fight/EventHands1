# RI0 — 相对增量是否避开观测歧义：有限定义检查

2026-09-26，执行前合同。上一轮MP1固定配对短训已终态失败，所有旧终态保持。这里不新增完整候选、不运行真实数据/模型/训练，只检验一个会改变下一实现决定的命题：把绝对姿态问题改称相对tracking增量，是否足以得到新的观测约束。

## 问题、来源与四个独立视角

续用creative-thinking-for-research的challenge及现有机会图update模式。目标仍是原始单目事件GNN MANO tracking，原H/精度/完整7ms不变。

- 分析单位变换：M4的常量姿态–纹理朝向偏置保持标量角增量，不能用该反例直接否定所有增量估计。
- 同观测反事实：要求两个世界初始位移和速度相同、固定阈值、非空事件及全部silence相同，却有不同后续增量；分别固定同一外观与允许各自固定未知外观。
- 系统辨识类比：未知观测增益与运动系数的乘积可保持；姿态初值不等于独立标定该增益。只转移辨识条件，不把刚体/线性纹理当真实MANO模型。
- 实验优先的正控制：移动边的时空到达位置可以约束法向速度，且时间–位置错配应破坏这一关系。必须同时保留这一阳性，避免把退化例写成所有事件都没用。

本次不重新生成M3/M4图像、扫描旧profile或复跑NF2/PA1。既有M4 §4.2为常量bias反例；NF2是消去自由51D速度后选root-Y绝对候选，因固定支持门停止；PA1是自身伪材料锚的固定支持诊断。RI0只明确这些结果的量词和增量边界。

## 六项冻结检查

1. 标量角theta与theta+delta在固定时刻序列上差分相同，但初角不同；若强制精确同初角，非零delta不合法。仅代数检查，不冒充新M4事件实测。
2. 抽象SO(3)右侧材料坐标变换R'=RG：空间增量R1 R0^T不变、体坐标增量R0^T R1按G共轭。用固定90度整数旋转矩阵精确验证。这个群恒等式不是任意MANO纹理/几何允许RG的物理论证；也不是轴角相减的等价证明。
3. 同外观aperture例：log纹理L0(x,y)=x，轨迹q1(t)=(t²,0)、q2(t)=(t²,t²)。两世界同位置/速度初态、同绝对initial reference、同图像序列，从而同非空事件和silence；切向增量不同。
4. 未知固定外观与法向运动例：L0_i(x,y)=a_i x，a1=1、a2=2，q_i(t)=(t²/a_i,0)。两世界同位置/速度初态，但法向增量不同；L_i(x,y,t)-L_i(x,y,0)=-t²相同。各自reference=L_i(x,y,0)，相对phase均0；**不声称绝对reference相同或两世界纹理相同**。每个世界外观自身时间不变，照明恒定，C相同，不逐事件调参。
5. 已知a的条件正控制：在固定二次轨迹族q_x=c t²中，第一触发时间满足a c t1²=C，因此已知a/C可确定c。它只说明该族的独立增益标定能破除本例，不声称事件给出了a，也不声称任意触发之间的轨迹唯一。
6. 移动step边正控制：固定像素x=1,2,3、边初位0、候选法向速度1与1/2、观察至7，log跳幅A取3/8与7/16，均在[C,2C)且initial phase0。L(x,t)=A当x>v*t，否则0；初始reference=A，x=0边界不在像素列表。每像素恰一次负触发，时间x/v；reset后残差-(A-C)严格小于C且不再变化。改变幅度不改首次到达时间，改变速度则时间不同。对v=1作固定循环时间错配，保持位置/时间/极性/计数边际但破坏共同速度关系。理想不连续step且无PSF/带宽/refractory；不外推真实边的完整光度模型。

第3–4项使用完整有限16像素FOV `(x,y) in {0,1,2,3}²`，时间 `[0,7/8]`，C=1/4。平面材料覆盖 `[-2,5]²`，所有射线在整个区间始终落在其内部，边界/端点不入镜；不引入隐藏ROI筛选。t<0共同静止，兼容相同无事件前史。它们是有限FOV平面成像反例，不是完整可见手轮廓或所有MANO自由度不可辨定理。

事件时刻为sqrt(n C/(a c))，使用有理数根式精确表示，无均匀dt扫描或浮点近似触阈。每像素每触发后reference更新-C；区间内残差r(t)=-a c t²+kC。系数相同、单调且下一根为完整边界，证明全部连续silence一致；有限时刻的抽查只能作实现附检，不能替代此证书。

证书事件右端的-C为触发前极限，该silence段右开；同一触发时刻下一段左闭的0为reset后值。最后无事件的horizon右端闭合。同初始位置/速度仅指第3–4项两组ramp世界，第1/2项变换和第6项不同速度正控制不作此声明。第6项时间错配只检验冻结恒速step族的关系，不认证另一物理合法世界或真实运动特异性。
