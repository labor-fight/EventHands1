EvHandTrack 整体网络框架（画图说明）
================================================================================

一、画图要求
--------------------------------------------------------------------------------
1. 只画一张整体框架图，表现一次状态更新 x_{k-1} → x_k 的完整信息传递。
2. 17 个节点的运动学树图画在框架里面，即模块 ⑨“运动学树传播 P”的内部。
3. ESMNet（Event Surface Mapping Network）不展开内部结构，画成一个“预训练权重（冻结）”的方框，
   只标它的输入和输出。
4. 每个方框标模块名和关键尺寸；箭头上标传递的内容和张量形状。
5. 术语：“无参数”= 固定的几何计算，没有可学习参数；“可学习”= EvHandTrack 自身的网络层。
6. 最后要画出闭环：新状态 x_k 回到输入端，作为下一次更新的前态。


二、一句话概括
--------------------------------------------------------------------------------
每 50 ms 做一次状态更新：冻结的 ESMNet 把事件映射到手表面；在上一状态的 MANO 网格上算出“事件射线
与前态表面的偏差”；按 16 个手部部位汇聚成部位节点，再加一个手节点；在这 17 个节点的运动学树图上做
3 轮门控消息传递（门由前态关节几何算出）；每个关节局部读出自己的增量，加到上一状态上得到新状态。

四、逐模块说明
--------------------------------------------------------------------------------
① 流式取样 + 事件 token（无参数）
   - 事件逐个到达。事件 i 到达时：
       n_i = 它之前 50 ms 内到达的事件数
       k_i = max(1, ceil(n_i / 2048))
       事件计数器 c_i 满足 c_i mod k_i == 0 时保留
     即按事件率自适应取样，每个更新间隔大约保留 ≤ 2048 个事件。
   - 每个保留事件的 7 维 token：
       [ x/240, y/180, 极性 2p−1, (t_i − t_q)/Δ, log1p(与前一事件的时间间隔 / 1e-6 s),
         同像素同极性上次触发距今 / Δ（上限 1）, 同像素异极性上次触发距今 / Δ（上限 1） ]
     t_q = 上一次状态更新时刻，Δ = 50 ms。
   - 射线：d_i = K^{-1} [u_i, v_i, 1]（z 分量为 1，射线参数即深度）。
   - 每个事件的取舍与 token 只用它自己和之前的事件就能算出。

② ESMNet（预训练权重，冻结；不展开）
   - 输入：本更新间隔的事件图 4 × 180 × 240（每个极性一张“最后事件时间 / Δ”、一张 log(1 + 事件数)），
     以及 ① 保留事件的像素位置与 7 维 token。不读前态。
   - 输出（每个保留事件）：在手上概率、16 个部位的分类、MANO 静息模板上的表面点。
     解码成表面路由：在手上概率 ≥ 0.5 的事件路由到某个三角面 f_i，并给出重心坐标 b_i。
   - 权重固定（137,252 参数），EvHandTrack 训练时不更新它。

③ 前态 MANO 前向运动学（无参数）
   - 输入：上一状态 x_{k-1}（平移、根旋转、15 个关节轴角）、手形 β。
   - 输出：
       网格 V（778 × 3，相机坐标系，米）
       16 个关节 J = J_regressor · V
       每个部位节点的坐标系 F_p（父关节的全局旋转；手掌用相机系）

④ 表面关联（无参数）
   - 事件归属只由 ESMNet 决定，前态只决定“这个表面点现在在哪里”。
   - 公式：
       P_i   = Σ_r b_ir V[f_i 的第 r 个顶点]
       z_i   = P_i 的深度
       res_i = z_i d_i − P_i
       ω_ip  = Σ_r b_ir LBS[f_i 的第 r 个顶点, p]
   - ESMNet 判为不在手上的事件不进入部位节点，整个进手节点的“残差槽”。

⑤ 事件编码 φ（可学习，9,152 参数）
   - 每个事件 12 维输入 → Linear 12→64 → ReLU → Linear 64→128，所有事件共用。
   - 输入构成：
       在手上的事件：[token 7, res/1 cm 3, (z − 0.45 m)/0.1 m 1, 1]
       残差槽的事件：[token 7, 0, 0, 0, 0, 0]

⑥ 部位汇聚 + 几何矩（无参数）
   - 部位节点 p 的输入（156 维）：
       Φ_p（128）：按 ω_ip 加权平均的 φ_i
       几何矩（22）：以 J_p 为原点、在 F_p 下表达，各项是对事件的加权平均
         [log(1+质量), 平均残差 3, 平均力臂 3, 力臂⊗残差 9, 力臂⊗力臂 6]，力臂 = P_i − J_p
       视线方向（3）：相机 z 轴在 F_p 下的表达
       前态（3）：x_{k-1} 中关节 p 的轴角
   - 手节点 Hub 的输入（283 维）：
       全手平均 φ 128、全手几何矩 22（以腕 J_0 为原点、相机系）、残差槽平均 φ 128、
       残差槽占比 1、有无残差事件 1、根旋转 3
   - 所有统计量都是对事件求和，没有 max 池化。

⑦ 节点编码（可学习，357,888 参数）
   - 部位节点：16 个各自独立的线性层 156 → 128。
   - 手节点：线性层 283 → 128。
   - 输出 h^0 ∈ R^{17×128}。

⑧ 状态相关边门控（可学习，4,576 参数）
   - 每条有向边用前态关节几何算一个 128 维的门（10 维 → 32 → 128，sigmoid）。
   - 门随前态（手的姿态与朝向）变化；每次更新算一次，3 轮共用。

⑨ 运动学树传播 P（可学习，245,760 参数）
   - 节点：16 个部位节点（MANO 运动学树：手掌 + 5 根手指 × 3 节）+ 1 个手节点 Hub。
   - 边（62 条有向边，4 种边型）：
       父→子 15 条、子→父 15 条、Hub→部位 16 条、部位→Hub 16 条
   - 3 轮，每轮：
       h_v ← h_v + ReLU( W_s h_v + Σ_t mean_{u→v 属于边型 t} g_uv ⊙ W_t h_u )
   - 同一边型的入边取平均。例如手掌从 5 个一级指节收“子→父”消息；Hub 从 16 个部位收“部位→Hub”消息。

⑩ 局部读出（可学习，144,051 参数）
   - 每个手指关节只读自己的节点，各一套权重：128 → 64 → 3，得到 Δθ_j（j = 1..15）。
   - 平移与根旋转只读手节点：128 → 128 → 6。
   - 手掌节点不直接读出。
   - 不存在把所有节点拼接后统一读出的旁路：一个部位的证据要影响另一个关节，只能经过 ⑨ 的消息传递。

⑪ 加性状态更新（无参数）
   - x_k = x_{k-1} + Δ；本间隔没有事件时 Δ = 0。
   - x_k 输出（经 MANO 得到网格与关节），同时作为下一次更新的前态（闭环）。
